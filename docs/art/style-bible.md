## 1. 방향과 기둥
세계는 먹으로 그린 원고다(로어 바이블 §1). 적은 원고에 번진 먹이 형체를 얻은 **먹귀**라서 검은 덩어리로 그리고, 눈은 종이가 드러난 구멍으로 뚫는다. 주인공 **결**은 종이색 몸에 먹 액센트를 얹는다. 이 **명도 반전**(밝은 아군 / 중간 바닥 / 어두운 적)이 소속을 말한다. 형태는 블랙 스팟으로 깎고, 음영은 망점으로, 선은 붓펜 먹선으로 긋는다. 색은 전투 정보를 전하는 신호 다섯 가지뿐이고, 각 색은 소속에 고정된다.

| # | 기둥 | 규칙 | 검수 기준 |
|---|---|---|---|
| P1 | 명도가 소속을 말한다 | 아군이 가장 밝고, 바닥이 중간, 적이 가장 어둡다 | §4 명도 밴드, §14 흑백 0.3초 판독 |
| P2 | 색은 전투 정보 전용 | 신호색 5종은 소속에 고정하고, 먹테 없이 단독으로 쓰지 않는다 | `palette.test.ts` 소속 테스트 위반 0건 |
| P3 | 실루엣이 역할을 말한다 | stalker △ · charger ▶ · shooter ┳ · warden ■ | 32px 단색에서 역할 구분 100%, 보스는 48px 단색에서 서로 구분 |
| P4 | 무늬가 소속을 말한다 | 사선 해칭은 적 전용(예고와 제어 지대), 청록 망점·바느질 점선은 아군 전용 | 색각 이상 시뮬레이션에서 무늬만으로 구분 |
| P5 | 판정은 그대로, 그림은 판정 위에 | pivot = 판정 원 중심 = 발밑 링 중심. 판정은 알파로 계산하지 않는다 | 판정 오버레이 골든의 앵커 오차 ≤ 3px |
| P6 | 전투는 그림으로 남는다 | 처치·화염·돌진의 흔적은 마른 먹 데칼이고, 붓이 예고를 그려 나간다 | 데칼 상한 48/24/0, 모든 LOD에서 예고 진행률 표시 |

## 2. 시점·카메라·판정 표시

### 2.1 시점
- 3/4 탑다운(위에서 약 35° 부감)이다. 캐릭터는 서 있고, Y-정렬로 겹친다.
- 방향은 좌우 반전으로만 바꾼다. 주인공은 3방향(하·측·상) + 반전, 일반 적과 보스는 1방향 + 반전이다(D2). 주인공은 조준 좌우로 몸을 반전하고, 상하는 이동 방향으로 정한다.
- 자전은 없다. 회전하는 것은 무기·팔·공격 파츠(aimAngle)와 톱니·낫 같은 물체뿐이다(C3).

### 2.2 카메라(팀 결정, TEC-01)
- 세로 900 월드 유닛 고정 시야다. 줌 = 캔버스 높이 ÷ 900이고, 보이는 가로 폭은 최대 1600, 16:9보다 넓은 창은 필러박스다(`src/game/viewPolicy.ts`).
- 1024×720 = 0.8배(주인공 약 51px), 1440×900 = 1.0배(64px), 1920×1080 = 1.2배(약 77px)다. 뷰별 수치는 `docs/decisions/TEC-01-platform-target.md` §3에 있다.
- 줌이 바뀌면(챕터 로드, 창 크기 변경) 아틀라스를 현재 줌·DPR로 한 번 리샘플한 ImageBitmap으로 바꾸고, 전투 중에는 스케일 없는 1:1 blit만 한다. 망점 모아레와 성능 문제를 함께 막는다(v1.0 §7.2).
- 판독 검수는 1.0배와 0.8배 두 배율에서 한다(§14).

### 2.3 판정 표시와 앵커(V4·TEC-03 최종본)
- **시뮬 좌표 = 판정 원 중심 = 발밑 그림자·링 중심이다.** 발은 이 점에 딛고, 몸은 그 위로 솟는다.
- 발밑 그림자는 판정 원과 같은 중심의 타원이다. 폭 = 판정 지름, 높이 ≈ 폭 × 0.42(컨셉 키트 비율), 먹 α 0.3. 이 그림자가 판정을 보여 준다.
- 주인공 발밑 링은 청록 4분할 링이다. 판정 원과 중심이 같고, 호 4개(각 0.7 rad)를 조준 방향으로 돌린다. 크기는 rx 24 / ry 10.3(키트 값, 현행 r41에서 줄임)이다.
- 위험지형은 개체의 중심점으로 판정한다. 그래서 발밑 링의 중심이 경계선을 넘는 순간 효과가 난다. 경계선 두께와 링으로 이것을 보여 준다(ART-06).
- 런타임 앵커는 `pivot`, `muzzle`(포구·발사원), `displayScale` 3종만 쓴다(TEC-03 최종본). 판정은 스프라이트 크기나 알파로 계산하지 않는다.
- 공격 모션(식칼·군도 휘두름 등)이 판정 원 밖으로 나가면, SYS-04에서 실제 판정 모양과 예고를 붙이거나 한눈에 장식으로 보이게 그린다(V4).
- 개발 빌드에는 판정 오버레이 토글(점선 원 + pivot 십자)을 둔다.
- 컨셉 키트는 v1.0 앵커(pivot = 골반, feet = pivot + r)로 그렸다. 가져올 때 변환하는 방법은 §16에 있다.

## 3. 외곽선
- **모든 캐릭터의 외곽선은 기준 굵기 1x 2px 이상의 먹선이며, 원화에 베이크한다**(원화 @2x에서 4px 이상). 붓펜 선이라 그림자 쪽(우하)은 기준의 1.4배로 굵히고, 빛 쪽(좌상)은 기준의 0.7배까지만 가늘게 한다. 긴 윤곽은 2~4획으로 나누고, 빛 쪽에만 틈 1~2곳을 허용한다. 발밑·하단 윤곽은 끊지 않는다. 아래 표의 굵기는 기준 굵기(괄호는 그림자 쪽·빛 쪽)다.
- 소형 티어와 48px 이하 스프라이트는 **소형 전용으로 다시 그린다**. 붓 성질을 줄이고, 균일한 굵은 선 + 실루엣 + 흰 눈만 남긴다. 축소본을 쓰지 않는다.

## 4. 명도

### 4.1 원칙(ART-01)
| 대상 | 규칙 |
|---|---|
| 주인공 | 밝은 종이색 코트 + 검은 먹선 + 청록 목도리·발밑 링. 화면에서 늘 가장 밝은 캐릭터다 |
| 일반 적 | 중·암 명도의 먹 + 챕터 재질 저채도 1색(패치). 늘 바닥보다 어둡고, 눈만 종이 구멍으로 뚫는다 |
| 보스 | 대형 흑면 + 챕터 accent 코어 + 파손 레이어(P2 균열, P3 코어 노출, 광폭화 외곽 펄스) |
| 바닥 | 중간 명도. 주인공보다 어둡고 적보다 밝다 |

### 4.2 명도 밴드(에셋 린트 기준, TEC-03)
휘도 Y는 WCAG 상대 휘도다. ART-01 최종본의 밴드(플레이어 L≈0.90, 바닥 0.35~0.60, 일반 적 0.02~0.30)를 좁혀 제작 목표로 쓴다.

| 대상 | 허용 Y | 쓰는 토큰(§5) | 면적 |
|---|---|---|---|
| 주인공 밝은 면(코트·얼굴·행전) | ≥ 0.69 | paper(0.902) 기본면, paperShadow(0.694) 음영 하한, paperBright(0.996) 하이라이트 | 64px 스프라이트: 흑립 챙 포함 종이 ≥ 50% [확인] / 원화·키아트: 55~60% |
| 주인공 어두운 면(흑립·안감·조끼·장갑·장화) | ≤ 0.06 | ink, inkSoft | 64px 스프라이트 ≤ 40% [확인] / 원화 30~35% |
| 주인공 청록 | — | ally 계열 | 5~10%. 목도리가 몸의 유일한 청록 면이다 |
| 지면 base | 0.38~0.45 (ART-01 밴드 0.35~0.60 안) | env.chN.base | 줄눈·데칼의 국소 대비 ≤ 1.35:1 |
| 적 몸체 | ≤ 0.06 | ink, inkSoft, 중묵(명부) | ≥ 70% |
| 적 재질 패치, 보스 코어·파손 레이어 | ≤ 0.30 | inkMuted, env.chN.deep, 챕터 accent | 몸의 ≤ 20% |
| 적 종이 액세서리(눈·이빨·벽보·부적·가면) | 종이 허용 | 3px 먹테 필수 | 합계 ≤ 10% |
| 보스 얼굴·가면(초점) | 종이 허용 | 굵은 먹테로 액자처럼 두름 | 보스 면적 ≤ 12% |

- 64px 스프라이트의 면적 기준은 컨셉 키트 실측값(흑립 챙 포함 종이 50.3 · 먹 39.2 · 청록 6.2%)에 따른 개정안이다(API-hero §2). 챙 하나가 채움 면적의 약 27%라서 v1.0 기준(종이 55~60 · 먹 30~35)을 스프라이트에서 동시에 맞출 수 없다. v1.0 기준은 원화와 키아트에 그대로 쓴다. [확인]
- v1.0은 적 재질 패치 상한을 Y 0.24로 적었지만, v1.0 자신의 env.chN.deep 값(Y 0.232~0.277)이 이를 넘는다. ART-01 밴드 상한 0.30으로 정리했다.
- 먹 떡짐을 막는 LOD 예외: 적이 120체를 넘으면 소형 적 명부(몸 면적 ≤ 30%)를 #57524B(Y 0.086)로 한 단계 밝힌다. 적 몸체 규칙의 유일한 예외다(v1.0 §12.6).

## 5. 색 예산
캔버스와 CSS는 단일 토큰 소스 `src/game/render/palette.ts`를 쓴다. 이 절의 hex는 **구현값**이며, v1.0 토큰 값과 다르면 구현값이 앞선다. palette.ts에 아직 없는 토큰은 **신규**로 표시했다. 신규 토큰은 palette.ts에 추가한 뒤에 쓴다(BUG-14·UI-01 경로). 예산은 **먹 4계조 + 종이 + 챕터 재질 1~2색 + 신호색 5종**이다.

## 6. 음영과 질감
1. 3계조만 쓴다: 종이 / 톤 / 먹. 톤은 망점 또는 플랫 중간톤(중묵, 종이 그늘)이다. 그라데이션과 에어브러시는 금지한다.
2. 블랙 스팟이 먼저다. 형태 그림자는 디자인한 검정 조각(지그재그, 초승달, 쐐기)으로 파고, 경계는 날카롭게 둔다.
3. 키 라이트는 좌상단에 고정한다. 밝은 주인공은 음영이 우하로 가고, 어두운 적은 좌상단에 중묵 명부를 얹고 윗윤곽에 담묵 1px 비백 림을 준다. 명부와 림이 먹 덩어리끼리 붙어도 개체 경계를 만든다.
4. 망점은 20 / 40 / 60%, 45°, 1x 피치 ≥ 3px이고, 한 파츠에 2단계까지다. 소형 티어·48px 이하 스프라이트와, 스프라이트·움직이는 그림의 펄럭이는 파츠(코트 자락, 목도리)에는 쓰지 않는다. 정지 그림(키아트, 이야기 패널)의 펄럭이는 파츠에는 쓸 수 있다(2026-10-14 결정). 아이콘은 표시 크기 기준으로 피치 = max(8, 3 × 128 ÷ 표시 크기) 마스터 단위다(키트 AD 판정).
5. 사선 해칭은 세상에서 적의 예고와 적 제어 지대만 쓴다. 캐릭터·환경·UI에 선 해칭을 쓰지 않는다. 깊은 그늘은 망점 60% 또는 env.chN.deep 평면으로 칠한다.
6. 녹아웃 헤일로: 모든 적 스프라이트에 1.5px 바닥색(env.chN.base) 외곽을 베이크한다. 적 떼가 한 덩어리로 뭉쳐 보이지 않게 한다.
7. 먹이 흐르는 방향이 소속을 말한다. 주인공은 소매·옷단·동정 끝에서 먹이 위로 스며 오르고, 적은 몸 끝에서 먹 방울 2~3개가 아래로 흐른다.
8. **종이 질감은 정보 뒤에 둔다.** 종이결은 지면과 UI 패널 바탕에만 α ≤ 0.06으로 넣는다. 캐릭터, 투사체, 텔레그래프, 픽업, HUD 수치 위에는 넣지 않는다. 지면 무늬의 국소 대비는 ≤ 1.35:1이다. 키아트와 이야기 패널만 예외이고, 이야기 패널도 종이결은 배경에만 α ≤ 0.06으로 넣는다(인물·얼굴·공백 위에는 넣지 않는다).
9. 발광과 가산 합성은 금지한다. 예외는 세 가지다: 아군 투사체 심의 청록 소프트 글로우(α 0.35, 반경 ≤ 6px), 적 탄의 산호 후광(α 0.3), 보스 광폭화의 백열 눈.
10. 처치 흔적: 사망 연출(쓰러짐·먹 폭발 6프레임, FX-03) 뒤에 마른 먹 자국 데칼을 남긴다. 데칼은 3초에 걸쳐 농묵에서 담묵으로 마르고 30초 뒤 사라진다. 상한은 full 48 / reduced 24 / minimal 0이고, 지면 위·위험지형 채움 아래 층이다.

| warden | 대형 · 28 | ■ | 폭 ≈ 키, 방패가 정면 면적의 40%, 머리는 폭의 20% 이하로 어깨선 아래에 묻힘 | 전방 방패(§8.2) | 방패 호, 디딜 때 스쿼시 |

- 5챕터 모두 같은 리그와 같은 실루엣 계열을 쓴다(V6). 챕터는 오버레이 파츠, 눈 모양, 윤곽 성질만 바꾼다(실루엣 변화 ≤ 25%). 20 프로필의 묘사는 v1.0 §9.3에, 가칭은 로어 바이블 §5에 있다.
- 프레임(ART-03): 1방향 + 반전. move 6, windup·attack 4, hurt 2, death 6.
- **폭탄병(SYS-14)은 소형 접촉의 하위형이다**(2026-10-14 결정, 지시서 `docs/art/briefs/bombers.md`). 판정과 티어는 소형 접촉 그대로다. 실루엣이 추적자 무리 속에서 멀리서도 갈려야 하고, 32px 흑백에서 역할 4종과도 서로와도 갈려야 한다.
  - 심지형(fuse): 둥근 몸 + 위·뒤로 향한 S자 심지 한 가닥, 다리 사이 틈. 몸이 하는 예고는 심은 자세(닿으면 멈춰 웅크리고 심지가 짧아진다)다.
  - 즉시형(burst): 둥근 몸 + 촉발 뿔 + 무릎이 꺾인 달리는 두 다리. 덤벼드는 자세는 두지 않는다. 늘 켜진 겹 고리(§10.1)와 몸의 뿔·균열이 상시 예고다.
  - 프레임: 심지형 idle 1, walk 4, plant 4, blast 1, hit 1. 즉시형 idle 1, walk 4, blast 1, hit 1. 장마다 재질 오버레이만 바꾼다(V6).

### 8.2 warden 방패(팀 결정: 방패안)
- 행동: 정면에서 오는 아군 투사체를 50% 줄인다. 방패 방향은 초당 90° 이하로만 돈다(SYS-02 가드레일). 플레이어가 이동으로 측면을 잡을 수 있게 하는 장치다.
- 몸은 좌우 반전만 하므로, 방패의 실제 방향을 두 가지로 보여 준다(제안). (1) 몸은 방패가 향한 좌·우 쪽으로 반전한다. (2) 발밑 링 바깥에 보호 범위를 나타내는 **방패 호**(먹 3px + 종이 심, 신호색 없음)를 그리고, 실제 방향으로 초당 90° 이하로 돌린다. 호의 각도는 SYS-02 구현값과 같게 한다. [확인]
- 방패에 막힌 타격은 방패 테의 종이 섬광 + 먹 튐으로 보여 준다. 신호색은 쓰지 않는다(가정).

## 9. 주인공 결
- 실루엣 3요소(64px에서도 남아야 하는 것, 우선순위순): ① 흑립 챙(폭 40 × 높이 11~12px, 화면에서 가장 큰 도형) ② 종이색 코트 삼각형(안감은 초묵이라 자락이 날릴 때 블랙 스팟이 된다) ③ 청록 목도리 꼬리(몸의 유일한 청록 면).
- 복식, 무기, 얼굴은 v1.0 §8.3~8.4와 로어 바이블 §2를 따른다. 얼굴 그림자는 대각선으로 떨어뜨린다. 두 눈을 가로지르는 수평 그림자 띠는 금지한다.
- 상태와 프레임(ART-02, FX-01 최종본): 3방향 + 반전. idle 6, run 8, cast 6, hurt 3, death 8, 합계 약 105프레임이다. 투척 팔 + 바늘은 aimAngle로 도는 별도 오버레이 레이어(4프레임, v1.0 §8.6)다. rooted·silenced는 오버레이다. skillBurst는 cast 프레임 + 스킬 VFX로 만든다(가정). 정산용 승리·패배 포즈를 만든다.
- **dash·dodge 상태와 프레임은 만들지 않는다**(G1 최종본, FX-01). 일식 보법은 제자리 방사 베기 + 무적이다(`updateEclipseStep`). cast + 베기 VFX(owner = player)로 그린다. v1.0 §8.6의 dash 4프레임과 키트의 `full('dash')`는 인게임에 쓰지 않는다.
- 침묵(SYS-11 (a)안): 머리 위 원형 타이머 + 자수정 문양, 입에 먹 붓 ✕, 탄띠 바늘이 회색으로 빠진다. 궤도 날과 자석 펄스는 판정이 유지되므로 계속 그린다. 해제되면 준비된 스킬이 0.1초 간격으로 발동하므로, 바늘이 0.1초 간격으로 하나씩 다시 칠해지는 연출을 권장한다(가정).
- 보스나 warden에 가려지면 최상위 층에 청록 X-ray 외곽 2px + 발밑 링을 그린다(BUG-12). 외곽선 바깥의 종이백 여백 테 1.5px는 원화에 베이크한다.
- HUD 초상: 필수 4표정(평상, 피격, 저체력, 각성, ART-02). 키트의 집중·승리 표정은 선택이다.
- 거울 분신: 담묵 선만 있는 채움 없는 사본(α 0.35) + 청록 바느질 점선. 먹빛 유리 분신(유리 주교)과 명도로 구분된다.
- CON-05의 추가 캐릭터도 밝은 코트 + 청록 식별 규칙을 따른다.

## 10. 먹귀와 보스

### 10.1 일반 적(먹귀)
- 몸: 초묵·농묵 70% 이상 + 좌상단 중묵 명부 + 담묵 비백 림 1px + 녹아웃 헤일로 1.5px.
- 눈 = 종이 구멍이다(종이백, 먹 동공, 좌우 비대칭). 눈에 산호를 쓰지 않는다. 눈 모양이 챕터 지문이다: 1장 슬릿 / 2장 열쇠 구멍 / 3장 기포 / 4장 문자판 / 5장 일식 고리.
- 몸에 신호색을 두지 않는다. 예외는 shooter 포구의 호박 예열 링, 정예의 자수정 링·3점 관, 폭탄병 표식뿐이다.
- 폭탄병 표식은 렌더러가 그리고 그림에는 넣지 않는다: 심지형은 호박 점선 고리와 심지 끝의 불꽃, 심은 뒤에는 도달 범위의 호박 원이 가운데부터 차오른다. 즉시형은 박동하는 겹 산호 고리다(감소 모션에서는 멈춘다).
- variant 0~4는 액세서리 위치(벽보 조각, 흠집, 뿔 기울기)만 바꾸고 색은 바꾸지 않는다.
- 상태: spawn(바닥에서 먹이 배어 올라 응고, 0.25초. 판정·접촉 규칙은 그대로, FX-03), move, windup, attack, hurt(캐시한 종이 실루엣 네거티브 플래시, 3단 페이드), stunned, death(6프레임 → §6-10 데칼).
- 5장의 몸 구멍은 종이백으로 칠하지 않고 투명하게 뚫어 바닥이 비치게 한다(3px 먹테 + 망점 번짐). 소형 적(여우, 폭탄병)의 작은 구멍은 game LOD에서 3px 먹테가 메워 보이지 않으며, 그대로 둔다(art LOD에만 보인다; 2026-10-14, K7 검수 Q-A 권장안).

### 10.2 보스
1. 이름 = 소품 = 발사원: 상징물이나 대표 소품이 실루엣의 30~40%를 차지하고, 공격은 그 소품에서 나온다.
2. 얼굴 = 약점 = 조준 초점: 흰 눈빛이 새는 밝은 얼굴·가면 자리 한 곳(면적 ≤ 12%, 굵은 먹테). 레티클과 피격 섬광이 여기 모인다.
3. 몸이 먼저 예고한다. windup 자세가 텔레그래프 1단계이며 지면 예고와 같은 순간에 시작하고, 머리 위에 호박 '!'를 띄운다. windup은 공격 동작보다 먼저, 더 크게 설계한다.
4. 명도와 색: 대형 흑면(초묵·농묵) + 챕터 accent 코어 + 파손 레이어. P2(66%)는 소품·의상에 종이색 균열 + 페이즈 표식 1개, P3(33%)는 블랙 스팟이 흘러내리며 accent 코어가 드러난다. 광폭화는 먹 불꽃(검은 불 + 종이 심) + 백열 눈 + 산호 외곽 펄스 2px다.
5. 자전하지 않는다. 좌우 반전 + 공격 파츠 회전이며, 컷아웃 10~14파츠를 쓴다(TEC-13).
6. 15종을 흑백 48px로 줄여도 서로 구분되어야 한다. 패턴이 같은 4쌍(고리·덫·시계·공백)은 발사원 소품과 예고 도형으로 구분한다(로어 바이블 §3.3).
7. 잉크 도살자의 돌진 레인은 **직선**이다. 리마스터 규칙은 준비 자세에서 방향을 고정하고 유도하지 않는다(BUG-10, `rules.ts`의 `telegraphedDash`). v1.0 §10.3의 '레인 끝 부채꼴'과 키트 `telegraph('dashLane')`의 `fan`은 원작 규칙용이므로 쓰지 않는다(`fan` 0).
8. 크기와 프레임: 필드 보스 100~110px, 라운드 보스 140~160px. 라운드 보스는 파츠 리그 + 핵심 프레임(windup 6, attack 8~12, death 12, ART-04)이고, 필드 보스는 경량 세트(idle·windup·attack·death)다.
9. 등장 타이틀 카드는 칭호 + 이름 + 한 줄이고, 1.2초 동안 화면 중앙 40% 밖에 뜨며 게임을 멈추지 않는다(FX-05). 감소 모션에서는 정지 패널이다. 문구는 로어 바이블 §4에 있다.

## 11. 환경
- 지면은 큰 판석이나 불규칙한 조각으로 만든다. 벽돌 같은 규칙적 줄눈은 금지한다. 줄눈은 env.chN.deep 1.5px·α 0.55로 긋고, 바닥 데칼은 지면보다 L 5~8 낮게만 칠한다.
- 장애물은 3/4 윗면(light) + 전면(base + 망점 20%) + 우하 그림자(망점 40%)로 그린다. 눈이 없어서 적과 구분된다. X자 문양은 덫 기호와 헷갈리므로 지운다. 적 탄 차폐 규칙(SYS-06)이 확정되기 전에는 낮고 납작하게 그린다(정면 ≤ 주인공 키 × 0.45).
- 월드 경계는 챕터마다 다른 가장자리로 그린다(먹 번짐 담장, 철창, 젖은 석축과 먹물, 톱니 울타리, 백지 공허). 카메라가 월드 끝에서 멈출 때 보이는 경계 밖 영역까지 채운다(ART-05).
- 랜드마크는 St3·St7 입장 때 붓글씨 이름 카드로 알린다. 이름과 문구는 로어 바이블 §5.1에 있다.
- 정적 위험지형은 챕터 재질과 무관하게 적 텔레그래프 문법을 따르고, 종류는 내부 기호로 구분한다. 위험지형은 모두 판정과 같은 원이다(trap은 원형 덫 판).
- 5장도 지면 명도 밴드를 지킨다. 어둠은 흑요 장애물, 비네트, 보스에만 준다. 챕터별 묘사는 v1.0 §11에 있다.

### 12.1 소속 분리(자동 테스트 대상)

### 12.2 적 텔레그래프 3단계("붓이 그려 나가는 예고")
| 단계 | 진행률 | 표현 |
|---|---|---|
| preview | 0~65% | 먹 붓 점선 테 2px(α 0.7)를 붓 머리가 그려 나간다(그려진 비율 = 진행률). 안쪽은 호박 성긴 해칭(선 2px, 피치 10px) |
| imminent | 65~100% | 해칭 피치 5px, 테 5px, 방사 눈금 8/12개. 붓이 도형을 닫는 순간 active로 넘어간다 |
| active | 판정 | 산호 채움 α 0.55 + 먹 망점 가장자리, 종이 섬광 0.1초 → 마른 먹 얼룩 1.2초 |

- 시간 계약(V3): 원거리 0.44초, 돌진 0.62초, 충격 0.52초, 박격 0.48초, 페이즈 전환 0.45초.
- 예고 도형: 원(충격·박격·화염·null), 레인(돌진·일식·초침), 콘(부채 붓질), 격자(걸쇠·교차).
- 지속 제어 지대(slow·root·null)는 호박 테 3px + 조밀 해칭 α 0.35 + 내부 기호(물결·사슬·⊘)다. 피해가 없으면 산호를 쓰지 않는다. null 지대는 무늬가 지워진 void.paper 평면 + 호박 점선 테이고, 발동 중에 가는 산호 링 1.5px를 더한다.
- active 단계는 해칭 없는 산호 평면 채움이다. ART-06 최종본의 '산호 해칭 채움' 문구 대신 v1.0·키트 방식을 따른다. 판정 순간을 예고(해칭)와 채움 방식으로 갈라 보여 주는 v1.0 문법이고, 키트가 흑백·색각 검증을 마쳤기 때문이다. [확인]

### 12.3 적 탄과 피드백
- 적 탄: 먹알 코어 + 산호 테 2.4px + 먹 외곽 1px + 종이 점, 속도 꼬리 3px. 종류는 내부 기호로 구분한다(dot 점, ring 속 빈 고리, enemy 짧은 붓 획, saw 먹 톱니 + 산호 날끝, eclipse 초승 흰 획). 청록·보라·마젠타 탄은 쓰지 않는다. 적 탄은 적 몸 위 층이다(§13).
- 가한 피해: 만화 충격 별(종이 + 먹테, ≤ 16px, 동시 24개 상한) + 먹 튐 + 적 네거티브 플래시. 치명타 숫자는 반전 태그(먹 바탕 종이 숫자)이며 산호를 쓰지 않는다. 산호 숫자는 받은 피해에만 쓴다.
- 아군 스킬 17종의 전장 표현은 v1.0 §12.3을 따른다. 모두 owner = player 스타일이다(FX-06, FX-07).

### 12.4 UI·아이콘(요약)
- UI는 v1.0 §13 '한지 위의 만화 칸'을 따른다. 최소 글자 13px, HUD 수치 14px, 텍스트 대비 4.5:1(V5 최종본).
- 스킬 아이콘 17종은 64/128px 마스터, 먹 + 망점이고, 액티브에만 청록 한 점을 둔다. 패시브에는 청록이 없다. 산호·호박·자수정은 아이콘에 쓰지 않는다(API-icons).
- HUD 스킬 슬롯 수는 v1.0 §13.2의 '액티브 6 + 패시브 6' 대신 D14 가안 '액티브 6 + 패시브 4'를 따르고, R3 A/B 결과로 확정한다.

## 13. 레이어와 LOD
- 층 순서(TEC-12 계약): 바닥·데칼 < 위험지형 채움 < 발밑 그림자·판정 링 < 장애물 하단 < Y-정렬 캐릭터(적·보스·주인공·장애물 상단 파츠) < 아군 투사체 < 적 탄 < 텔레그래프 외곽(imminent) < 주인공 X-ray 외곽·판정 링 < 파티클 < 데미지 숫자 < 화면 공간 UI. 체력바는 별도 일괄 패스로 그린다. 보스의 공중 탄은 장애물 위 층에 지면 그림자와 함께 그린다(SYS-06).
- 위협 정보(적 탄, imminent 텔레그래프)와 주인공 판정 링은 어떤 스프라이트에도 가려지지 않는다(V3·V4). 검은 먹 파티클은 주인공을 덮지 않게 주인공 층 아래로 내린다(v1.0 §7.4). 이 부분의 최종 순서는 TEC-12 계약 테스트에서 정한다. [확인]
- LOD는 보이는 적 수로 정한다(FX-01): full < 80, reduced 80~159(데칼 망점 생략, 데칼 상한 24, 애니메이션 fps 절반), minimal ≥ 160(정지 프레임 + 외곽 + 흰 눈 + 신호색). 명부, 녹아웃 헤일로, 흰 눈은 모든 LOD에서 유지한다.
- 감소 모션은 LOD와 분리한다. 프레임 애니메이션, 예고 무늬, 데칼은 유지하고, 흔들림·펄스·회전·패널 찢김만 페이드로 바꾼다.

## 14. 흑백 0.3초 판독 테스트

| 항목 | 내용 |
|---|---|
| 목적 | 색 없이 명도와 실루엣만으로 주인공, 역할 4종, 보스를 0.3초 안에 알아보는지 확인한다(P1, P3) |
| 시점 | R0 종료(실루엣 시트), R1 종료(Ch1 실제 에셋과 게임 화면), R2 챕터 롤아웃마다(해당 챕터) |
| 참가자 | n ≥ 8. 이 게임을 처음 보는 사람과 해 본 사람을 섞는다(가정: 절반 이상은 처음 보는 사람). 재시험에는 새 참가자를 쓴다(가정: 학습 효과 배제). 색각 이상 여부, 기기, 화면 크기를 기록한다 |
| 합격 | 주인공, stalker, charger, shooter, warden, 보스 **각각** 정답률 ≥ 90%. 32px 단색 실루엣에서 역할 4종 구분 100%. 보스는 48px 단색에서 서로 구분 |

재료:

| 세트 | 내용 | 만드는 법 |
|---|---|---|
| A. 실루엣 카드 | R0: 주인공 3안, Ch1 4역할 + shooter 2크기(소·중), Ch1 보스 1종(ART-01 실루엣 시트). R1부터: 해당 챕터의 전 역할과 보스. R5부터 폭탄병 둘(심지형·즉시형)을 32px 세트와 A 과제 답안에 더한다 | 단색 먹 실루엣. 적 32px, 보스 48px, 그리고 1x 실제 크기. 종이 바탕 |
| B. 흑백 전투 장면 | 무작위 전투 화면 10장. 일반 밀도, 고밀도(적 200 + 적 탄 120 + 아군 탄 150), 보스 겹침(보스 위의 결), LOD reduced·minimal, 0.8배 화면(1024×720)을 각각 1장 이상 넣는다(가정: 구성 비율) | 1440×900 1x 캡처(0.8배 장면은 1024×720 캡처)를 상대 휘도 Y = 0.2126R + 0.7152G + 0.0722B(선형 sRGB)로 흑백 변환한 정지 이미지. R0에는 게임 에셋이 없으므로 그레이박스·목업 장면을 쓴다 |
| 마스크 | 자극 뒤에 띄우는 종이 노이즈 이미지 | 잔상으로 답하지 못하게 한다 |

절차:
1. 원격 웹 설문(정적 이미지)이나 현장 화면으로 진행한다. 결과는 외부 전송 없이 파일로 받는다(플레이테스트 리스크 완화안, backlog-roadmap.json risks).
2. 연습 3회(가정)로 응답 방식을 익힌다. 연습은 채점하지 않는다.
3. 한 시행은 고정점 0.5초(가정) → 자극 **0.3초** → 마스크 0.5초(가정) → 응답(시간 제한 없음) 순서다.
4. A 과제: 실루엣 하나를 보고 '주인공 / stalker / charger / shooter / warden / 보스' 중 하나를 고른다. 대상마다 5회(가정).
5. B 과제: 장면을 본 뒤 질문 하나에 답한다. 질문은 '주인공이 있던 칸(3×3 격자)', '표시한 적의 역할', '보스가 있던 칸', '예고(빗금) 영역이 있던 칸' 중에서 무작위로 고른다(가정: 격자와 질문 종류).
6. 자극 순서는 참가자마다 섞고, 같은 대상을 연속으로 내지 않는다.
7. 채점: 대상별 정답률 = 정답 시행 ÷ 전체 시행. shooter는 소·중을 합산하고 따로도 기록한다. 한 대상이라도 90% 미만이면 불합격이다.
8. 불합격하면 혼동 행렬(무엇을 무엇으로 착각했나)을 붙이고, 실루엣·명도를 고친 뒤 새 참가자로 다시 시험한다.

기록('캡처 + 수치 + 리포트', C17): 테스트 id, 날짜, 에셋 버전(매니페스트 해시), 자극 목록과 파일, 참가자 코드(개인정보 없음), 기기와 화면 크기, 대상별 정답률, 혼동 행렬, 판정. 보관 경로는 [확인].

## 17. 제출과 검수
- 컨셉 제출물마다 1x 실제 크기 크롭, 흑백 변환본, 판정 원 오버레이본을 붙인다. 적·보스는 단색 실루엣 32px(적)·48px(보스) 한 줄을 붙인다(v1.0 §16.2).
- R1 승인 게이트(v1.0 §16.3): 색 제거 실루엣, 그레이스케일 소속, 고밀도 목업(적 200 + 적 탄 120 + 아군 탄 150, 1440×900 1x), 보스 겹침, 색각 시뮬레이션, 판정 정합(앵커 오차 ≤ 3px, 그림자 폭 = 판정 지름), 성능, 토큰 교차 사용 0건. 성능 수치는 TEC-04 게이트를 따르고, v1.0의 '적 200체 렌더 p95 ≤ 7ms(1440×900 DPR1)'는 참고치로 둔다.
- 에셋 린트(TEC-03)는 CI에서 크기 규격(§7), 앵커 존재(§2.3), 신호색 화이트리스트(§5.3), 흑백 명도 밴드(§4.2)를 검사한다.
- 발주 순서(v1.0 §16.1): 공통 키트(붓 스캔, 망점 프리셋, 토큰 스와치) → 결 → Ch1 4역할 → Ch1 보스 3종 → Ch1 환경 → 텔레그래프·FX → HUD 목업. Ch2~5는 R1 게이트를 통과한 뒤에 시작한다.

## 4. 지시서 대비
**반영한 것**
- **§1 공통 계약**: 박스·피벗·r76·발 y328·킷 그림자·`hitbox`·`mono`·`halo`·옵션 우선순위(pose가 windup보다 앞섬)·META를 지시서대로 했습니다.
- **§1.1 층 구성**: 얼굴판은 거친 먹선 필터 밖의 `face` 층에 둡니다. 얼굴 앞을 지나는 모자는 `top` 층입니다.
- **§1.6 선·드립**
  - 외곽선 보이는 폭은 game 7입니다. 그림자 쪽 굵기 복제는 (1.15, 1.45)×배율로 잡아 +40%에 맞췄습니다.
  - 드립은 방울 끝을 y 331 위로 잘라, 발이 땅에 선 채로 보이게 했습니다.
- **§2 얼굴**: 한 시점을 `plane()`과 `wrap()`으로 계산해 그렸습니다(`W.at` 데칼 포함). 판마다 그림자 덩어리 하나와 액센트 하나이고, 경계는 곡선입니다. 수평 띠·직선 다각형 그림자·정면 판·글자 같은 기호는 없습니다. 크기별 남길 것은 API 문서 표에 적었습니다.
- **§3 보스별**: 상태 7장과 페이즈 2 표식을 다 그렸습니다. 처치 3의 웅덩이는 모두 (192,328), rx 100, ry 42입니다.
- **§4 fx**: 4종 모두 그렸습니다(선택 과제).
- **§9 열린 질문**: 메모대로 기본안을 따랐습니다. 규칙 변경 없음, 광폭화 그림 없음, 탄 모양은 fx 참고 그림만, 심판관 모자는 날개 없는 원통입니다.

**시작값에서 옮긴 것** (자세한 이유는 API 문서 "지시서 시작값에서 옮긴 것" 표)
- **관리자 고리·창**: 시작값이면 고리 앞 호가 창(얼굴)을 가로지릅니다.
  - 고리 중심 (150,150) → (156,128), 기울기 32° → 20°
  - 창은 함 앞면 아래쪽 (162.4,189.6)으로 내렸습니다.
- **장교 군도**
  - 길이 150 → 116: 손을 허리에 두고 칼끝을 (110,318)에 두려면 이보다 길 수 없습니다.
  - 준비 자세 칼 x 236 → 242, 몸 12°: 236이면 단색 실루엣에서 칼이 외투에 묻혔습니다.
  - 공격 자세: 팔이 땅까지 닿지 않아 "자루까지 박힘" 대신 날 92 중 62가 박힌 그림으로 대신했습니다.
- **집행관**
  - 도끼를 한 직선에 놓았습니다. 날 (116,114), 균형추 (218,240)이고, 날을 밖으로 빼야 32px에서 갈고리 두건과 섞이지 않았습니다.
  - 준비 자세에서 손이 머리 위가 아니라 두건 옆에 있습니다. 이 비례에서는 팔이 머리 위까지 닿지 않습니다.
  - 시침은 3시입니다. 10시 쪽이면 가까운 눈 구멍을 가립니다.
- **초상과 앵커**: 초상 값을 §1.5 규칙(판 35~55%, 눈높이 40~50%)에 맞게 다시 계산했습니다. 앵커는 실제로 그린 자리에서 계산합니다.
- **장교 가면·집행관 처마의 art 그림자**: 40% 망점 대신 평면(ink300 / paper300)으로 칠했습니다. 판 폭이 3~10이라 피치 4.4 망점이 물방울 무늬로 읽혔습니다. 바이블 §2.4 "그림자(ink300 평면 또는 40% 망점)" 안의 선택입니다.
- **`plane()`에 약한 원근 `persp 0.1`을 더했습니다.** 정사영으로는 판 위 두 눈이 같은 폭이 되어 "먼 쪽 구멍이 더 좁다"를 지킬 수 없습니다. 판의 바깥 테 자리는 지시서 공식과 같습니다.
- **심판관**
  - 모자 띠 실 땀: X 셋이 나란하면 글자처럼 읽혀서 비스듬한 홑땀으로 바꿨습니다. 입의 X 실 땀은 지시대로 X입니다.
  - 준비 자세 `muzzle`은 붓끝입니다. 이때 의사봉은 허리 뒤에 있고, null 지대를 예고하는 것은 붓입니다.
- **`top` 층**: 그림자 쪽 굵기 복제를 붙이지 않습니다. 붙이면 모자 띠 아래로 먹이 내려와 심판관 눈썹을 덮었습니다.

## 6. 알려진 한계 (사람 원화가 몫, §15)
- **다섯 공통**: 최종 외곽선과 블랙 스팟은 사람이 그어야 합니다. art의 붓 느낌은 필터와 비백 몇 획뿐입니다.
- **장교**: 30° 돌린 얼굴이라 회벽 껍질이 좁습니다(가로 약 10). 게임 크기 밝은 면은 흰 슬릿이 거의 전부이고, 외투 비례도 뭉툭합니다.
- **관리자**: 굽은 몸의 해부가 단순한 먹 덩어리입니다. 고리 앞뒤 겹침 순서는 근사입니다.
- **설계자**: 망토에 접힘이 없습니다. 처치 1의 접힌 다리도 손으로 다시 그려야 합니다.

## 3. 작업자가 1차 값과 다르게 한 곳과 판단 요청

1. **F2 땀 기울기 '한쪽 불규칙'(J.LEAN): 채택.** '±10° 번갈아'로 그리면 이웃 땀이 V·Λ로 짝지어 지그재그가 된다. 이는 1차 합격 기준이 금지한 모양이고, 모이는 끝 간격(0.4)도 1.5 기준에 못 미친다. 한쪽으로 3~10° 불규칙하게 기울이면 손으로 꿰맨 땀으로 읽힌다. 1차 지시를 이 값으로 대신한다.
2. **F3 눈 지름 10.6(35%): 채택.** 1차에 적은 game r5 + 1.4는 지름 12.8(43%)이라 내가 정한 기준 36%와 모순이었다(내 실수). 기준을 앞세운 판단이 맞다. 먹 원 3.0(game)이 남아 "판 위 어두운 이목구비 4 이상"도 지켜진다. 먼 광대를 1.2 내민 것(윤곽 221.6)도 채택한다.
3. **F4 시침 4시(game)와 '구멍 둘레 3' 미달: 채택.**
   - 3·9시 눈금 1.8~2.2, 꼬리 추 1.6, 축 2.5가 3 미달인 것은 내가 같이 지시한 "눈금 4 유지", "꼬리 6·r1.6"과 부딪친 결과다.
   - 기준을 "어떤 먹도 구멍에 닿거나 이어지지 않는다"로 바꾼다. 8×에서 모든 간격이 1.6 이상이라 충족한다.

   - art 3시와 game 4시가 서로 다른 것은 클린업으로 넘긴다(6절).
4. **F1 먼 눈 슬릿이 밝은 쪽에 약 40% 걸침: 그대로 둔다.**
   - 챙 그림자 경계가 먼 눈을 지나는 것은 형태상 자연스럽다.
   - 밝은 쪽에 걸친 부분이 오히려 먼 눈을 '빛 없는 구멍'으로 읽히게 한다(k2r2-cmd-shell).

5. **R1 공격 자세 틈 약 4: 채택.** 준비 자세(예고 포즈)는 y 261 아래에서 7~13으로 6 이상을 지킨다(k2r2-cmd-gap-windup). 공격은 y 280~295에서 약 4(1×에서 2px)이고, 0.25초 프레임이라 받아들인다(k2r2-cmd-gap-attack).

## 4. 얼굴 (최우선 과제) 2차 결론 (확인)

- 다섯 얼굴 모두 한 시점이 유지된다. 1차에서 남았던 다섯 문제(세로 띠 쪼갬, 글자 같은 기호, 과대한 눈과 잘린 먼 눈, 판 위 두 번째 얼굴, 실금 흰자)가 모두 해소됐다.

- **설계자**: 렌즈가 1×에서 읽힌다.
- **관리자**: 1차 그대로 합격이다.

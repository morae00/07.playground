# 사람 클린업 목록

출시 그림(컨셉 킷 출력)을 사람이 손볼 곳을 한곳에 모은 살아 있는 목록이다. 스타일 바이블 §15(2026-10-23 개정)에 따라 사람 클린업은 권장하고 **출시를 막지 않는다**. 예외는 A4 판독 시험 하나다. 이것은 클린업이 아니라 §14의 출시 조건이지만, 원문 목록에 있었으므로 여기에도 둔다.

| 항목 | 내용 |
|---|---|
| 출처 | 전체 점검(2026-10-23, art-director, remaster/r2 68ba0af)의 '출시 전 사람 클린업'. 납품·검수 기록에 흩어진 사람 몫을 모아 우선순위로 묶은 것이다 |
| 묶음 읽는 법 | 원문은 "사람 클린업을 마치고 출시한다"(P1-2 (a)안)를 전제로 A를 '출시 전 필수'라 불렀다. §15 개정으로 (b)안이 정해졌으므로 A는 **최우선**, B는 **권장**, C는 **출시 뒤로 미뤄도 됨**으로 읽는다 |
| 쓰는 사람 | 메인 세션이 고친다. 담당이 정해지면 '담당'을, 일이 움직이면 '상태'(열림 / 진행 / 끝 / 보류)를 고친다. 끝난 항목은 지우지 않고 '끝'과 커밋을 적는다 |
| 끝낸 뒤 | 클린업한 원화를 같은 슬롯 키로 구우면(`docs/art/pipeline.md` '최종 원화로 교체하기') `docs/art/provenance.md`의 해당 줄('사람이 한 작업', 굽기 커밋)도 고친다 |
| 담당 | 사람 원화가는 아직 정하지 않았다. 아래 '미정'은 모두 같은 뜻이다 |

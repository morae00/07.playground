## 1. 공통 계약

### 1.1 모듈·로드·이름공간
- **로드 순서**: `lib.js`와 `k-env.js` 뒤에 읽힌다. 리뷰 시트는 이름순으로 자동으로 읽는다. 굽기는 메인 세션이 `scripts/build-atlas.mjs:11`의 `KIT_FILES`에 `k-env.js` 바로 뒤로 넣는다.
- **`PN.env`는 읽기만 한다.**
  - 장 색(`PN.env.CH[ch]`)과 순수 기하 도우미는 써도 된다: `E.ribbon`, `E.cr`, `E.crPath`, `E.jag`, `E.ellPts`, `E.P`, `E.f`.
  - `E.uid`, `E.mix`(토큰 밖 색을 만든다), `PN.env.hazard`는 부르지 않는다.
- **결정성**:
  - `Math.random`과 `Date`를 쓰지 않는다.
  - `layout()`·`paths()`는 **`SPEC.jit`만** 쓴다(렌더러가 TypeScript로 똑같이 옮긴다). 식은 API-skills-vfx §6 `jit`와 같다: `((Math.imul(seed*31 + i, 2654435761) >>> 0) % 1000) / 1000`.
  - 조각 안의 들쭉날쭉함(구운 그림)은 고정 seed의 `E.rng`를 써도 된다.
- **id**: 모듈 카운터로 `hzd<n>_`를 붙이고 되감지 않는다. `<defs>`는 호출마다 따로 갖는다. 쓰지 않는 패턴·필터를 `<defs>`에 넣지 않는다(`k-env.js:1905`처럼 청록 패턴이 남으면 C6에서 걸린다).
- **중복 속성 금지**: 한 태그에 같은 속성을 두 번 쓰지 않는다(`--check`가 잡는다).

### 1.2 호출 형식

```
PN.hazards = {
  version: '1.0',
  K,        // 토큰(§1.9)
  kinds,    // ['fire','shock','slow','water','root','trap','null']
  groups,   // kinds + ['hero','mob']
  states,   // {fire:['burn','ignite','gutter','soot'], shock:['telegraph','burst','decal'], slow:['static'], water:['static'],
            //  root:['emerge','static','wither','faded'], trap:['armed','spring','shut'], null:['erase','static','restore']}
  META,     // 종류별 owner('hostile'|'neutral'), 게임 반경 범위, 상태별 시간 창
  SPEC,     // 렌더러가 그리는 매개 도형과 배치 상수(§1.5). 숫자와 토큰 이름만(함수·한글 금지) → 매니페스트에 그대로 싣는다
  jit,      // jit(seed, i)
  parts(group),                                 // → [{part, frames, drive, fps, seconds, still, box, anchor, layer, z, lod, flash, ch}]
  stamp(group, part, { frame }),                // 굽는 조각(로컬 박스)
  layout(kind, r, seed, { lod, ch }),           // → [{part, x, y, flip, phase, z, prio}]  물건 조각 배치(§1.6)
  paths(kind, r, seed),                         // → { cracks | ghost | jag: [[x,y],…][] }  매개 선(§1.6)
  draw(kind, state, { r, ch, t, p, seed, lod, reduced }),   // 참고 합성(리뷰·골든). 원점 = 지형 중심
  overlay(group, layer, { t, p, r, facing, reduced }),     // 'hero': back|front|embers|bind-back|bind-front, 'mob': front. 원점 = 발(판정 원 중심)
};
```

**옵션 기본값**

| 옵션 | 기본값 | 뜻 |
|---|---|---|
| `r` | 74 | 판정 반경 |
| `ch` | 1 | 장 |
| `t` | 0 | 초. 반복 조각과 슬롯의 시계 |
| `p` | 0 | 상태 안의 진행률(0~1) |
| `seed` | 1 | 게임에서는 `Hazard.id` |
| `lod` | `'full'` | `'full'`, `'reduced'`, `'minimal'` |
| `reduced` | `false` | 감소 모션 |
| `facing` | 1 | −1이면 x를 반전한다 |

- **`draw`는 렌더러가 그릴 결과의 기준 그림(골든)이다.** 자기 `layout`·`paths`·`SPEC`를 써서 렌더러와 같은 순서(§1.4 z)로 합성한다.
- **잘못된 호출**은 빈 `<g/>`를 돌려주고 `console.warn`을 남긴다(K7과 같은 문법). 해당하는 경우는 다음과 같다:
  - 모르는 kind·state·group·layer
  - `ch`가 1~5 밖일 때
  - `r` ≤ 0일 때

### 1.3 단위·좌표·판정 (바꾸지 않는다)
- **단위**: 월드 단위 = 1440×900, 줌 1.0의 1x px다. 조각은 `scale: 1`로 @2x에 굽는다.
- **원점과 판정 원**: 지형 중심 = 시뮬 (x, y) = `draw` 원점이다. **판정 원은 `Hazard.radius` 그대로**이고 테의 중심선이 r에 온다. 킷은 원을 늘이지 않고, 렌더러는 조각을 늘이지 않는다(V4, §7.2).
- **게임 반경**:

  | 종류 | 반경(출처) |
  |---|---|
  | fire | 50 불길 레인 · 60~98 맵 · 68·150 원형 붕괴 · 74 용광로 기본 |
  | shock | 190 |
  | slow | 86·150 보스 · 145~270 맵 |
  | water | 145~270 |
  | root | 50·52 |
  | trap | 60~98 |
  | null | 120·130·170 |

- **조각 박스**:
  - 로컬 박스는 [0,w]×[0,h]다. `anchor`가 배치점(x, y)에 놓인다.
  - 불·덩굴·기포의 앵커는 땅에 닿는 밑동이고, 바닥 얼룩(z `ground`)의 앵커는 중심이다.
  - 칠한 영역은 박스 가장자리에서 3단위 안쪽이다(C7).
- **방향**: 불·덩굴은 회전하지 않는다. 좌우 반전(`flip`)만 한다. 불길은 언제나 화면 위쪽으로 솟는다.
- **원 안에 머물기**:
  - 불·덩굴·기포(z `flame`)의 밑동은 테에서 6 이상 안쪽이다.
  - 바닥 조각(z `ground`)은 내접 타원 전체가 r − 2 안이다.
  - 불길이 먼 테(위쪽 테) 위로 솟는 것은 6단위까지만 허용한다(3/4 시점의 높이, C7).
- **3/4 시점**: 바닥 얼룩·물결·웅덩이는 납작하게(ry ≈ 0.42·rx) 그린다. 판정 원 자체는 참 원이다(§7.2).

### 1.6 layout과 paths 규칙

**공통**
- J(i) = jit(seed, i)다. 후보를 차례로 뽑고 조건에 맞는 것만 받는다(시도 수 고정).
- 출력은 z `ground` 항목들(y 오름차순) 다음에 z `flame` 항목들(y 오름차순) 순서다.
- 항목 필드:

  | 필드 | 뜻 |
  |---|---|
  | part | 조각 이름 |
  | x, y | 배치점. 중심 기준 |
  | flip | 좌우 반전 |
  | phase | 0~1 |
  | z | ground / flame |
  | prio | 0 = 끝까지 남김, 클수록 먼저 버림 |

**fire** (size s/m/l, 장 높이 H = 그 크기 무더기 앵커 y)

| 항목 | 개수(full / reduced / minimal) | 배치 |
|---|---|---|
| 무더기 `cluster-<size>-<a\|b>` | n_c = clamp(round(r/24), 2, 8) / 같음 / min(n_c, 3) | 후보 k = 0..39: 각 2π·J(k), 거리 0.62r·√J(k+40). 거부 조건은 두 가지다. ① 먼 테: y − H < −√(r² − x²) − 6. ② 간격: 받은 것과 hypot(dx, 1.3·dy) < r·(n_c > 4 ? 0.42 : 0.58). 변형 a/b는 J(k+80) < 0.5, flip은 J(k+120) < 0.5, phase는 J(k+160). prio 0. 하나도 못 받으면 (0, 0.2r)에 하나 둔다 |
| 불길 치마 `skirt-a`/`-b`/`-low` | n_s = round(2π(r−9)/pitch), pitch는 s·m 30, l 38 / 짝수 번째만 / 0 | i = 0..n_s−1. J(i+500) < 0.2이면 건너뛴다. 각 = 2π(i + 0.5 + (J(i+540) − 0.5)·0.6)/n_s, 거리 = r − 9 − 3·J(i+580). 끝이 먼 테 + 6을 넘으면 `skirt-low`로 바꾸고, 그래도 넘으면 버린다. 그 밖은 J(i+620)로 a/b. flip J(i+660), phase J(i+700). prio 2 |
| 그을음 `char-<a..d>` | n_ch = clamp(round(r²/1800), 2, 10) / ⌈n_ch/2⌉ / 2 | 후보 k: 각 2π·J(k+1000), 거리 (r − 24)·√J(k+1040). 간격 r·0.35. 변형 ⌊J(k+1080)·4⌋, flip J(k+1120). prio 1 |

불티(렌더러와 `draw`가 시간으로 계산한다. layout 출력에는 없다):
- 슬롯 j = 0..E−1, E = clamp(round(r/14), 3, 8)이다. reduced는 ⌈E/2⌉, minimal과 감소 모션은 0이다.
- 슬롯 j는 무더기 (j mod 받은 수)에 붙는다. 시작점 = 무더기 밑동 + (−8 + 16·J(j+1200), −(4 + 8·J(j+1240)))이다.
- 주기 T = 0.7·(0.8 + 0.4·J(j+1280)), 위상 φ = J(j+1320), u = frac(t/T + φ)다.
- 위치 = 시작점 + (±8·u, −34·u)이다. 부호는 J(j+1360) < 0.5이면 −다.
- 장 = min(5, ⌊6u⌋), 조각은 j가 짝수면 `ember-a`, 홀수면 `ember-b`다.

**paths**
- `paths('shock', r, seed)` → `{cracks}`:
  - 팔 i의 출발 각 = 2π(i + (J(2000+i) − 0.5)·0.6)/7이다. 반지름 10에서 출발한다.
  - 마디 길이는 22·(0.7 + 0.6J)이고, 진행 방향을 ±0.5 rad 흔든다. 법선 방향으로 ±(3 + 2J)를 번갈아 민다.
  - 반지름 0.88r을 넘지 않는다. 55% 지점에서 ±0.6 rad 가지가 나간다(팔 길이의 30%, 3마디).
  - 전체 길이로 돌려준다. 렌더러가 grow(p)로 자른다.
- `paths('null', r, seed)` → `{ghost, jag}`:
  - 유령 선 L줄: 각 π·J(2200+i), 중심에서의 거리 (J(2240+i) − 0.5)·1.2r(±0.8r로 자름). 반지름 r − 6 원과 만나는 현이다.
  - jag: 12점, 반지름 배수 1 − (6/r)·J. 지우는 동안 렌더러가 진행률만큼 키운다.

**검증 벡터**: C9가 대표 경우의 `layout`·`paths`를 숫자로 찍는다. 메인 세션은 이것을 매니페스트에 싣고 TypeScript 이식이 같은 값을 내는지 단위 시험한다.

### 1.9 그림 규칙

**외곽선**
- 불길: 먹 바깥 실루엣이 옆면과 밑동에서 1x 2px 이상, 끝에서 1.2px 이상이다. 합친 무더기에는 실루엣 안쪽 이음선이 없다(먹 → 산호 → glow 순으로 무더기 전체를 칠한다).
- 덩굴: 붓 테이퍼 4 → 1px.
- 웅덩이 외곽은 2px이다.
- 덫 기계: 바깥 2~3, 안쪽 1~1.5.
- 바닥 얼룩(char)은 외곽선 없이 들쭉날쭉한 평면이다(부드러운 가장자리 금지).

**명도**(흑백에서)
- 결이 언제나 가장 밝다.
- 불: 바닥 평균 Y 0.12~0.22(불길 제외).
- 불 무더기 면적: 먹 ≥ 40%, 산호 ≤ 45%, glow ≤ 12%, p50 ≤ 3%(밑동 열점에만).
- null Y 0.71, 물 0.23~0.26, 덫 판 0.14~0.15.
- 먹물 웅덩이(ink700)는 감속 원 면적의 25~35%다.

**색**(토큰 표. 섞은 색은 금지이고, 톤은 토큰의 α로만 만든다)

## 2. 불(fire) — 가장 중요하다

### 2.1 개념
- 번진 먹이 불붙은 원고다. 바닥이 그을리고, 금 사이로 숯불이 빛나고, 먹 불꽃(검은 불) 무더기의 심장이 산호로 탄다.
- 용광의 입 묘사(v1.0 §10.3: "검은 불꽃 + 산호 판정 코어, 꺼진 뒤 무해한 그을음")를 장판 전체로 넓힌 것이다.
- 색의 뜻은 다음과 같다:
  - 산호 = 피해(§5.3 '화염 코어')
  - 먹 = 외곽과 형태
  - glow = 밑동의 열

### 2.2 바닥과 그을음 조각
- 원판(SPEC 먹 α0.30)과 테(먹 5 + 산호 2.4 + glow 0.8)는 렌더러가 그린다.
- **`char-a`~`d`(뜨거운 것)**:
  - 납작하고 들쭉날쭉한 얼룩(칠한 크기 ≤ 40×18)이다. ink7 평면에 숯덩이 2~4개(먹 쐐기)를 둔다.
  - 긴 축을 따라 빛나는 금을 1~2줄 긋는다(ink 2.6 / host 1.2 / hostG 0.5 심).
  - 재 부스러기(ink3)는 3개 이하다. 둥근 모양은 쓰지 않는다.
  - 그을음 조각이 원판의 15~30%를 덮는다.
- **`char-cold-a`~`d`**: 같은 자리에 쓸 식은 판이다. 금은 ink3 1.2(재색)이고 산호는 없다. 재 부스러기를 늘린다.

### 2.3 불 무더기(cluster)
- **구성**:
  - 혀 3~5개를 **한 실루엣으로** 합친다. 가장 높은 혀는 가운데 뒤에, 하나는 바깥으로 기울게 둔다.
  - 이웃 혀의 높이는 15% 이상 다르다(왕관·톱니처럼 고르면 안 된다).
  - 떨어져 나간 불꽃 끝 하나가 루프 6장 중 2~3장에서 위로 뜬다(틈 ≥ 3).
- **층**:
  - 먹 바깥 실루엣.
  - 산호 몸: 옆면 2 이상, 끝 3 이상 안쪽으로 들인다.
  - glow 심: 밑동 높이의 35% 안, 무더기 면적의 12% 이하.
  - 밑동 열점 p50: 3% 이하.
- **숯불 바닥**(무더기 조각의 맨 아래):
  - 납작한 불규칙 타원이다(ry/rx 0.35~0.45, 폭 = 무더기 폭 × 0.9~1.1).
  - 산호 채움 + 먹 테 2 + 안쪽 glow 줄(바닥의 20% 이하) + 먹 숯덩이 2~3개.
  - 앵커 아래로 2 이상 내려가지 않는다.
- **크기**:

  | 크기 | 칠한 높이 | 칠한 폭 | 쓰는 원 |
  |---|---|---|---|
  | s | 20~26 | 22~28 | r < 62 |
  | m | 30~36 | 28~34 | 62 ≤ r < 110 |
  | l | 40~48 | 36~44 | r ≥ 110 |

  변형 a는 가운데 왼쪽이 높고, b는 봉우리가 둘이다.
- **루프 6장 @12fps(0.5초)**:
  - 혀 끝이 ±2 흔들리고 높이가 ±12% 맥동한다. 밑동 glow 면적은 ±20%다.
  - **밑동과 숯불 바닥은 움직이지 않는다**(앵커 ±1).
- **ignite 4장(0.25초)**:

  | 장 | 모습 |
  |---|---|
  | 0 | 불티와 숯불 바닥만(바닥 60%) |
  | 1 | 혀 40% |
  | 2 | 혀 80%, 혀 하나가 솟음 |
  | 3 | 110%로 한 번 치솟음. 그다음 루프로 넘어간다 |

- **gutter 4장(0.5초)**:

  | 장 | 모습 |
  |---|---|
  | 0 | 80%, 혀가 갈라진다 |
  | 1 | 50%, glow 심이 꺼진다 |
  | 2 | 25%의 낮은 불길 + 연기가 시작된다 |
  | 3 | 숯불 바닥이 바닥의 30% 이하의 작은 빛 점으로 줄고 연기 한 가닥만 남는다 |

### 2.4 불길 치마(skirt)
- 테 바로 안쪽을 도는 낮은 불길이다. **혀 2~3개를 합친 무리 하나**를 한 조각으로 그린다. 혀 하나짜리 조각은 1x에서 물방울로 읽혀서 금지한다.
- 높이: `skirt-a`·`-b` ≤ 16, `skirt-low` ≤ 10(먼 테용).
- 층은 무더기와 같다(먹 / 산호 / glow). 숯불 바닥 대신 작은 그을음 자국을 둔다.
- 루프 6장 @12fps다. ignite·gutter 장은 없다(렌더러가 α로 넣고 뺀다).

### 2.5 불티·연기
- **불티 `ember-a`·`-b`**(cycle 0.7초, 1x 4~7px):

  | 장 | 모습 |
  |---|---|
  | 0 | 밝은 불똥(glow 심 + 산호 + 먹 테 1.5) |
  | 1~3 | 구르는 산호 조각. 마름모 → 물방울 → 쉼표로 모양이 바뀐다 |
  | 4 | 어두워짐(hostD 심) |
  | 5 | 재 점(ink3, 먹 테 없음) |

  - **둥근 원판으로 그리지 않는다**(적 탄·픽업과 혼동). 먹 테 1.5는 아군 투사체(먹 1.5)와 같은 예외다(§11 Q11).
- **연기 `smoke-a`·`-b`**(cycle 1.0초):
  - ink3 평면(α 0.55~0.7) 한 가닥이 오르며 넓어지고, 두 조각으로 갈라져 사라진다.
  - gutter·soot의 처음 0.6초에만 쓴다(deco).

### 2.6 상태

| 상태 | 언제(렌더러) | 무엇이 보이나 | 그리는 것 |
|---|---|---|---|
| ignite | 나이 < 0.25초(수명 있는 불) | 테는 첫 프레임부터 100%. 무더기가 솟고 불길 치마가 들어온다. 안쪽 glow 띠가 0.12초 번쩍인다 | `cluster-*-ignite`, 치마 α 경사, `fire.ignite.flash` |
| burn | 그 사이, 그리고 맵 불(수명 무한) 전부 | 위의 완성된 불 | 루프 조각, char, 불티 |
| gutter | 남은 수명 < 0.5초 | 무더기가 잦아들고 치마가 빠지고 연기가 오른다. **테는 100%**(아직 피해가 있다) | `cluster-*-gutter`, `char` → `char-cold` 교차(마지막 0.2초), 연기 |
| soot | 지형이 사라진 뒤 1.5초(렌더러 기억) | 테 없는 담묵 그을음과 식은 판. 대비 1.34~1.36:1로 무해하게 읽힌다 | `fire.soot`, `char-cold` |

### 2.7 판정과 맞추기
- 테 중심선 = r이다. 원판·그을음 조각은 원 안에 있다.
- 무더기·치마의 밑동은 r − 6 안쪽이다. 불길이 먼 테 위로 솟는 것은 6 이하다(C7).
- 가까운(아래쪽) 테는 어떤 조각도 덮지 않는다. 먼 테는 불길이 일부 가릴 수 있지만, 둘레의 80% 이상이 보여야 한다(T2-d).
- 불이 여럿 겹칠 때(불길 레인 3줄 × 7개, 반경 50): 렌더러는 두 번에 나눠 그린다. 먼저 모든 불의 원판·그을음·테, 그다음 모든 불의 불길 조각을 월드 y 순으로 그린다(§9).

### 2.8 무엇과 갈려야 하나

| 상대 | 가르는 점 |
|---|---|
| 적 탄(먹알 + 산호 테 원, 14~30px) | 불은 원형 탄이 없다. 세로로 솟는 혀이고 밑동이 땅에 붙는다. 불티는 각진 조각 ≤ 7px다 |
| 폭탄병 심지 불꽃·보스 광폭화 먹 불꽃(검은 불 + 종이 심) | 지형 불은 산호 심이고 땅의 숯불 바닥에서 솟는다. 몸에 붙은 불꽃이 아니다 |
| 감속·속박 지대 | 해칭·호박 테가 없다. 테가 먹 + 산호 실선이다(색각 이상에서도 무늬로 갈린다) |
| 아군 지대(청록·종이·바느질) | 청록·바느질이 없다. 불 원판은 어둡다(아군은 밝은 종이 α0.25) |
| 타격 별·처치 연출 | 규칙적인 별·종이 섬광 별을 쓰지 않는다 |

## 3. 주인공·적이 불 위에 있을 때

### 3.1 조건 (렌더러)
- **불길**: `burning` = 시뮬 위치(`world.player.x/y`, 보간 전)가 불 지형 원 안이다. 게임 판정 `GameEngine.ts:2206`과 같은 식이다.
- **물듦·불티**: `damaging` = burning이고, shield ≤ 0이고(`damagePlayerOverTime`은 방패에서 멈춘다), hp > 0이다.
- 불 안에 있지만 방패가 있으면 발밑 불길만 보인다. 철골 프레임 격자가 따로 보이므로 "불 속이지만 막혔다"로 읽힌다.
- **피격 자세(hurt)는 쓰지 않는다.** 네거티브 플래시가 0.5초마다 번쩍이면 섬광이 되고 결의 실루엣이 사라진다. 피격 자세는 직접 맞을 때만 쓴다.

### 3.2 산호 물듦(tint)

| 항목 | 값 |
|---|---|
| 방법 | 현재 주인공 프레임의 오려내기(`worldRenderer.ts:2110` `silhouette(frame, SIGNAL.hostile, cache)`)를 주인공 위에 `globalCompositeOperation = 'multiply'`로 그린다. 곱하기라서 먹 덩어리는 검게(Y ≤ 0.035), 목도리는 청록으로 남는다. 덮기(source-over)는 목도리를 회청으로 죽인다 |
| 세기 | α 0.30(0.25초) ↔ 0.12(0.25초), 2Hz |
| 코트 명도 | 0.30 → Y 0.62, 0.12 → 0.78, 평상 0.90(구현 종이 `#f4f4ef`, C10). 최고점에서도 불 바닥(Y 0.21) 대비 2.58:1로 결이 가장 밝다 |
| 깜빡임 안전 | 2Hz라 초당 3회 섬광 기준 아래다. 면적도 결 한 명(약 40×64px)이라 작다 |
| 섬광 감소 또는 감소 모션 | 깜빡이지 않고 α 0.20(Y 0.705)으로 둔다. `motionPolicy.beat`가 false일 때와 같다 |
| 들어오고 나가기 | 들어올 때 0.1초에 걸쳐 오르고, 나갈 때 0.15초에 걸쳐 빠진다(경계에서 깜빡거림 방지) |
| X-ray | 가려져서 다시 그릴 때 물듦도 α × 0.6으로 함께 그린다 |
| 그리지 않을 때 | 쓰러짐(death 기울기), 정산 |
| 다른 캐릭터(CON-10) | 같은 방법으로 그 캐릭터의 프레임을 쓴다 |

### 3.3 발밑 불길 (hero `back`·`front`)
- **`back`**(body-back, 주인공 바로 앞에 그림): 장화 뒤로 몸보다 넓게 퍼지는 혀 2~3개다. 칠한 범위는 x −20~20, y −14~+2다(발 기준, 오른쪽 보기).
- **`front`**(body-front, 주인공·물듦 뒤에 그림): 장화와 코트 자락 앞의 혀 3개다.
  - 칠한 범위는 x −18~18, y −15~+3이다.
  - 모든 장에서 장화 먹 면적의 40% 이상이 보인다.
  - 흑립 챙·코트 삼각형·목도리(§9 실루엣 3요소)는 건드리지 않는다.
- **청록 발밑 링과 판정 링을 가리지 않는다.** 링은 rx 24 · ry 10.3이고, x ±18에서 링의 y는 +6.8이다. `front`의 아래 끝 +3이 그 위에 있다.
- 층은 산호 무더기와 같다(먹 / 산호 / glow). 루프 6장 @12fps다. 오른쪽을 볼 때 그리고, 왼쪽을 볼 때는 렌더러가 반전한다.

### 3.4 몸에서 오르는 불티
- `SPEC.hero.embers`대로 슬롯 4개를 둔다.
  - 시작점은 (−18,−12), (−22,−28), (24,−10), (22,−24)다.
  - 0.6초마다 30 오르며, 몸 바깥쪽으로 6 흘러간다.
- 조각은 `ember-a`·`-b`를 쓰고, 주인공 바로 뒤(body-front)에 그린다.
- **얼굴 금지 구역 [−8,−58]–[18,−34]을 지나지 않는다.** C7에서 바깥쪽 흐름으로 0건을 확인했다(`b6-test-c7b`).
- 감소 모션과 minimal에서는 그리지 않는다.

### 3.5 적이 불 위에 있을 때 (`mob/front-12·19·28`)
- terrainOnEnemies 규칙에서 보스가 아닌 적이 불 원 안에 있으면 발밑 앞에 산호 불길을 그린다. 렌더러에 `RenderWorld.terrainOnEnemies`가 필요하다.
- **몸 물듦·불티는 없다.** 바이블 §10.1과 V2는 적 몸에 신호색을 금지한다. 발밑 불길은 지형 불의 그림이지 몸 색이 아니다(§11 Q5).
- 칠한 범위(발 기준):

  | 크기 | x | y |
  |---|---|---|
  | 12 | ±12 | −11~+2 |
  | 19 | ±17 | −14~+2 |
  | 28 | ±25 | −18~+2 |

  모두 눈 높이보다 아래다.
- 그리는 수는 주인공에게 가까운 순으로 24 / 12 / 0(full / reduced / minimal)이다. 보스는 면역이라 그리지 않는다. 벡터 몸 적도 그리지 않는다.
- 루프 4장 @12fps다.

### 3.6 속박 (hero `bind-back`·`bind-front`)
- 주인공이 root 지형 안에서 묶였을 때(`player.root > 0`) 발목에 먹 덩굴이 감긴다.
- 4장 prog 0.2초로 감고, 마지막 장을 유지한다.
- 칠한 범위: back x ±20, y −16~+2 / front x ±18, y −15~+3. 링 조건은 §3.3과 같다.
- 덫에 묶일 때는 덫 판의 `shut` 그림이 대신하므로 그리지 않는다.

## 4. 다른 종류

### 4.1 충격(shock) — 균열 장교의 군도 자리
- **예고 테는 현행 그대로** 둔다(사용자 요청). 가운데 '깨진 별' 기호만 없앤다.
- **균열**(SPEC `shock.cracks`, 렌더러):
  - 보스가 군도를 꽂은 중심에서 번개 같은 금 7줄과 가지가 뻗는다.
  - 예고 진행률 p를 따라 자라서 p 0.85에 0.88r까지 닿는다. 붓이 테를 그리는 동안 땅이 갈라져 나간다.
  - 색: preview는 먹 + 호박, imminent는 먹 + 호박 + warnGlow 심(예고 색)이다.
  - 금은 테 아래에 그린다.
  - 아군 백색 연쇄(청록 같은 굵기 꺾은선)와 달리, 땅에 붙어 가지 치고 끝으로 가늘어진다.
- **`pebble-a`·`-b`**(imminent, deco): 금 위 6곳의 먹 조각이 2px 들썩인다.
- **터짐**(새 표시 목록, 0.25초):
  - §12.2 active 문법이다. 산호 채움 α0.55를 0.1초, 먹 망점 가장자리 띠 14, 종이 섬광 0.1초를 그린다.
  - 균열이 산호 + hostileGlow로 빛난다.
  - `core`: 중심의 땅 터짐이다. 들린 판석 조각 + glow·종이 섬광 + 금 속 산호 빛, 칠한 크기 ≤ 66×66, `flash: true`다.
  - `shard-a/b/c`: 금 위 8곳(0.3~0.9r)의 돌 조각이 바깥으로 14, 위로 10 튀며 돈다.
  - `dust-a/b`: 테 안쪽 8곳의 담묵 먼지다.
- **자국**(1.2초, 데칼 층): 담묵 균열 + 가운데 먹 α0.2 웅덩이다. 테는 없다.
- 터짐은 몸 아래 층에 그린다. 폭탄병 터짐 그림(`worldRenderer.ts:936-947`)처럼 결을 덮지 않게 한다(V4·BUG-12).

### 4.2 감속(slow) — 먹물 웅덩이
- 제어 지대 문법(호박 테 3px + 해칭)은 그대로 두고, 물결 기호를 없앤다.
- **`mire-*`**:
  - 끈적한 먹물 웅덩이다. ink7 몸 + 먹 테 2 + 좌상 가장자리에 ink5 초승 윤기(1.5~2px)를 둔다.
  - 둥근 엽(lobe) 모양에 작은 방울 1~2개가 딸린다.
  - **웅덩이 안에 점·종이 하이라이트를 두지 않는다**(눈으로 읽힌다).
  - 칠한 크기: s ≤ 30×14, m ≤ 46×22, l ≤ 70×34.
- **`bubble-*`**(cycle 0.9초, 웅덩이 위):

  | 장 | 모습 |
  |---|---|
  | 0 | 작은 혹 |
  | 1~2 | 부푸는 돔(ink5 초승 윤기, 점이 아니다) |
  | 3 | 늘어난 돔 |
  | 4 | 터진 먹 고리 + 방울 3 |
  | 5 | 사라지는 ink3 고리 |

  감소 모션에서는 2번 장에서 멈춘다.
- **순서**: 해칭 → 웅덩이 → 기포 → 테.
- **4장(시계 무덤)**: 웅덩이 대신 SPEC 다이얼을 그린다(바이블 v1.0 §11 '호박 눈금 원'). 눈금이 채워지고 초침 하나가 원을 쓸고 지나가며 "시간이 늘어진다"를 보인다. 바늘 가운데 기호는 쓰지 않는다.

### 4.3 물(water) — 물결
- 중립이다. 신호색·해칭이 없고, **청록은 어떤 물에도 쓰지 않는다**(§5.2).
- 바닥은 렌더러가 담묵 원판(먹 α0.24)과 젖은 가장자리(먹 2.6 + p300 1.2)로 그린다.
- **`ripple-*`**(cycle 1.6초):
  - 납작한 고리가 rx 3에서 16으로 퍼진다. 고리 둘이고 안쪽이 늦게 퍼진다.
  - p300 1.6→0.8, 아래에 ink3 0.8 그늘선을 둔다.
  - 6~7번 장에서 끊기며 사라진다. 감소 모션에서는 3번 장에서 멈춘다.
- **`flow-*`**(루프 6장 @6fps): 끊긴 짧은 가로 물줄 둘(p300 1.4, 길이 10~18)이 오른쪽으로 2씩 흐른다. 3장 운하는 가로로 흐른다.
- **`glint`**: p50 짧은 획(≤ 6×2) 하나가 늘었다 줄었다 한다. 별 모양은 쓰지 않는다.
- 흑백에서 '밝은 동심 고리'가 있는 것은 물뿐이다. 감속(해칭 + 검은 웅덩이)과 이것으로 갈린다.

### 4.4 속박(root) — 먹 덩굴
- 제어 지대 문법(호박 테 + 해칭)은 그대로 두고, 사슬 기호를 없앤다.
- **`vine-*`**:
  - 땅 균열(먹 쐐기)에서 나온 먹 덩굴이다.
  - 땅에 낮게 감기다가 끝 하나가 갈고리처럼 일어나 안쪽(+x, 배치에서 중심 쪽)으로 말린다.
  - 바깥 면에 가시 쐐기 2~3개를 두고, 좌상 가장자리에 ink5 1px 윤기를 준다.
  - **높이 ≤ 16**, 덩굴 먹 면적은 원의 18% 이하다.
  - **둥근 끝·혹 금지**(머리·눈으로 읽힌다). 종이·신호색은 쓰지 않는다.
- **상태**:

  | 상태 | 모습 |
  |---|---|
  | emerge(4장 0.25초) | 균열 → 끝이 뚫고 나옴 → 일어섬 → 한 번 더 감김 |
  | static(루프 4장 @6fps) | 끝이 ±2 흔들린다 |
  | wither(4장 0.4초) | 처지고 두 토막 나서 균열로 가라앉는다 |
  | faded | 렌더러가 α 0.35로 그리고 흔들림을 멈춘다 |

- 덫(쇠붙이, 중립색)과 덩굴(유기적 먹, 호박 해칭 안)이 흑백에서도 갈린다.

### 4.5 덫(trap) — 원형 덫 판
- 중립이다. 신호색·해칭이 없다(`palette.test.ts:47`).
- **판 = 판정 원**이다. 렌더러가 SPEC으로 다음을 그린다:
  - 먹700 α0.5 원판
  - 먹 테 3.4
  - 안쪽 홈
  - 바퀴살 6
  - p300 네모 리벳(둥근 밝은 점은 눈이라 쓰지 않는다)
- **가운데 기계 조각**(칠한 크기 ≤ 76×56, 장별):

  | 장 | 기계 |
  |---|---|
  | ch1 | 쥐덫 이빨 고리(먹 위 p300 이빨, 용수철, 압력판) |
  | ch2 | 쇠사슬 올가미 고리 + 말뚝 |
  | ch3 | 젖은 쇠그물 덫(쇠고리 + 고르지 않은 그물코 + 물방울. 평행선 3줄 금지) |
  | ch4 | 톱니 덫(ink7 톱니, 바퀴통에 4장 spot 평면, p300 날 가장자리) |

- **상태**:

  | 상태 | 모습 |
  |---|---|
  | armed | 벌어진 기계 |
  | spring(3장 0.15초) | 물림·조임·닫힘·물어뜯기 + 먼지 |
  | shut | 닫혀 굳은 모습. 무해하게 보이도록 금·먼지를 두고, 렌더러가 판 α 0.7로 그린다. 마지막 0.6초에 사라진다 |

- 5장(무한 모드에서만 보임)은 1장 그림을 쓴다.

### 4.6 무음(null) — 지워진 바닥
- 원 안은 지면 무늬가 지워진 void.paper 평면이다(렌더러, §5.1).
  - **지운 원고의 유령 선**: 줄눈이 있던 자리에 ink300 1px 점선 4~6줄을 SPEC으로 그린다.
  - 테 안쪽에 지우개 부스러기 `crumb-*`를 둔다(voidp 채움 + ink300 0.8 테, 말린 조각).
- 테는 현행 호박 점선이고, 바이블대로 0.9r에 산호 1.5 링을 둔다(SPEC `active.on`, §11 Q3).
- **상태**:

  | 상태 | 모습 |
  |---|---|
  | erase(0.3초) | 가운데부터 지우개질이 퍼진다. 들쭉날쭉한 가장자리(jag)가 진행률만큼 커진다. 테는 첫 장부터 100%다 |

## 5. LOD·감소 설정·성능

### 5.1 LOD (보이는 적 수, 바이블 §13)

| LOD | 지형 |
|---|---|
| full(< 80) | 모든 조각, 루프 12fps |
| reduced(80~159) | 루프 fps 절반. 불길 치마 짝수 번째만, 그을음 조각 절반, 불티 절반. 물결·흐름·웅덩이 절반, 기포·부스러기 0. 그을음 데칼 상한 6 |
| minimal(≥ 160) | 루프는 phase 장에서 멈춘다. 불은 무더기 ≤ 3 + 그을음 조각 2, 치마·불티·연기 0. 감속 웅덩이 큰 것 3. 물결 1(멈춤). 덩굴·덫 기계·균열은 그대로(info). 데칼 0, 적 발밑 불길 0 |
| 모든 LOD | 테·원판·해칭·다이얼·균열은 그대로 그린다. 주인공의 물듦·`front`도 남긴다(info). minimal에서 `front`는 멈춘다 |

### 5.2 감소 모션·감소 섬광

| 설정 | 처리 |
|---|---|
| 감소 모션(`motionPolicy.reduced`) | 루프는 인스턴스마다 phase 장에서 멈춘다(제각각 다른 장). prog 조각(ignite·gutter·emerge·spring·burst)은 재생한다. 불티·연기·흐름·반짝임은 그리지 않는다. 물결 3번 장, 기포 2번 장에서 멈춘다. 물듦은 α 0.20 고정. 다이얼 바늘은 눈금 단위로 뛴다. 흔들림·회전·펄스 없음 |
| 감소 섬광(`flashStrength` 0.5) | `flash: true` 조각과 SPEC flash 층(불 시작 띠, shock 종이 섬광·core)은 α × 0.5. shock의 산호 판정 채움은 정보라서 남기고 α × 0.5로 그린다. 물듦은 α 0.20 고정 |

### 7.1 판독 시험

**T1 · 글리프 없는 종류 판독 (C5, 흑백·적록·청황)**
- 기호 없이 일곱 종류를 모두 이름 댄다.
- 다음 쌍이 흑백에서 모양·무늬만으로 갈린다: fire↔slow, slow↔root, water↔slow, water↔null, trap↔fire, shock 예고↔slow.
- 어느 칸도 적, 적 탄, 픽업, 아군 지대로 읽히지 않는다.

**T2 · 장면 (C2a·C2b·C2c, `--scale 1`과 `0.8`, 색과 흑백)**

|---|---|

### 12.2 반영 때 바꿀 것
- 주인공: 덮기 물듦 → §3.2 곱하기 물듦(목도리 청록이 남는다). 산호 테와 원 불티 → §3.3 발밑 불길과 §3.4 불티 조각. 물듦은 `player.shield <= 0`일 때만 그린다(§3.1; `player.burn`은 방패가 있어도 켜진다). 0.3초 꼬리가 §3.2의 나갈 때 0.15초를 덮으므로 조건은 `player.burn > 0`으로 쓴다.
- 적: 몸 물듦·테·불티를 걷고 §3.5 발밑 불길만 둔다(Q5, 바이블 V2). 적 쪽 조건은 `Entity.burn > 0`이 이미 RenderWorld에 있으므로 §9-4의 `RenderWorld.terrainOnEnemies`는 필요 없으면 더하지 않는다.
- 화면 가장자리 산호 빛: Q4의 틱 숫자를 넣은 뒤 `test:visual` 캡처로 보고 남길지 정한다.
- 팩이 없을 때(TEC-10 대체 그림)는 FX-03 그림을 그대로 둔다.

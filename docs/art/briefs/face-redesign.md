## 1. 진단: 왜 피카소처럼 보이나

**한 줄 요약: 한 얼굴 안에 회전각이 둘 이상이다.** 눈은 약 40° 돌린 얼굴인데, 코·코밑·입·턱은 옆얼굴(90°) 윤곽에 붙어 있다.

1. **먼 윤곽이 옆얼굴 선이다.**
   - `FACE_PTS` 4~18번(`art/concept-kit/k-hero.js:176-178`)은 이 순서로 놓인다: 관자 → 눈썹뼈 → 눈확 → 광대 → 코끝 (34.4, 7.8) → 코밑 (32, 9.6) → 콧방울 (29.6, 11.2) → 윗입술 (30.6, 13.8) → 입꼬리 (29.2, 16.8) → 아랫입술 (29.8, 19) → 턱 홈 (27.6, 23.6) → 턱 (27.2, 29).
   - 광대 아래에 혹이 넷(코·윗입술·아랫입술·턱) 있다. 이것은 옆얼굴의 표지다.
   - 30° 3/4라면 입술은 먼 윤곽에서 약 2u 안쪽에 있다. 윤곽은 광대 → 뺨 → 턱을 잇는 부드러운 한 줄이다. AD 모형(결)의 먼 윤곽 x는 y 0에서 27.3, y 20에서 21.5, y 30에서 15.3이다(`ad-numbers.png`).
   - 게다가 윤곽 붓은 이 혹 구간에서 가장 굵다(2.2 → 4.2, `:220-222`). 그래서 옆얼굴 선이 얼굴에서 가장 강한 선이 된다.
2. **코가 옆얼굴 코, 그것도 '부리'다.**
   - 콧뿌리(정중선 x 20)에서 코끝 x 34.4까지 가로로 14.4u다.
   - 코끝이 옆으로 밀리는 양은 코가 얼굴 앞으로 튀어나온 깊이를 넘지 못한다. 90° 옆얼굴에서도 4~8u가 한계다(AD 모형 4.8u, 30°에서는 2.3u). 14.4u는 어느 각도에서도 나올 수 없다.
   - 코밑 (32, 9.6)도 윤곽 위에 있다. 코밑과 콧뿌리는 깊이가 같아서 머리를 돌려도 x가 거의 같아야 하는데, 12u나 떨어져 있다.
3. **정중선이 아래로 갈수록 옆으로 꺾인다.**
   - 콧뿌리 20 → 코밑 32 → 인중 26 → 입 중심 24.6 → 턱 21.5.
   - 한 각도의 머리라면 콧뿌리·코밑·입 중심·턱 끝의 x는 ±1u 안에 든다. AD 모형 30°에서는 16.3 · 16.2 · 16.1 · 15.7이다.
   - 즉 아래 얼굴만 더 돌아가 있다.
4. **두 눈이 같은 정면 아몬드를 크기만 바꾼 것이다.**
   - 결은 `:270`, 7명은 `k-characters.js:1186` · `:1217` · `:1252` · `:1286`이다. 홍채는 아몬드 가운데에 있다.
   - 두 눈 사이 간격 약 17u는 AD 모형(눈동자 간격 22.6u) 기준으로 약 40° 회전에 해당한다.
   - 제대로 돌린 3/4라면 먼 눈은 바깥쪽이 눌리고, 두 홍채가 모두 보는 방향(화면 오른쪽)으로 치우친다.
5. **결은 밝게 드러난 쪽이 옆얼굴 쪽이다.**
   - 챙 그림자(`SHADOW`, `:184-189`)가 가까운 눈을 덮고 먼 눈만 온전히 그린다.
   - 그래서 보이는 이목구비는 먼 눈 + 부리 코 + 윤곽 위의 입술·턱, 곧 옆얼굴 하나다.
   - 그 왼쪽 먹 면에 눈빛이 떠서 '뺨에 눈이 하나 더' 있는 것처럼 읽힌다(`hero-portrait-calm.png`).
6. **면이 형태와 빛을 따르지 않는다.**
   - `NOSE_TONE`(`:196`)은 빛을 받는 쪽(가까운 쪽) 콧등 옆을 종이 그늘로 칠한다. 이 긴 사선 쐐기가 두 번째 옆얼굴 코처럼 보인다.
   - 가까운 옆면 띠(`SIDE_TONE` `:192`, B2 §5.2의 곡선 띠)는 귀 앞의 세로 면이라 얼굴을 판자처럼 쪼갠다.
   - 키 라이트(좌상)를 따르면 그늘은 정중선 너머 먼 쪽에 와야 한다.
7. **초상 구도가 오류를 키운다.**
   - 원 중심을 가까운 눈(뺨)에 맞추므로(`:1599`, B2 §5.5) 옆얼굴 윤곽이 원 오른쪽 가장자리에 선다. 84 px에서 '옆얼굴 + 떠 있는 눈'이 된다(`ad-sheet3-84px.png` 첫 열).
   - 7명은 결의 FACE를 복사하고 1~3u만 덮어쓴 것이라(`k-characters.js:1183` · `:1214` · `:1249` · `:1288`의 `pf.over`) 같은 오류를 그대로 가진다. 입 끝 x 29.2~29.6이 윤곽 위에 있다(`:1190` · `:1224` · `:1263` · `:1314`).
8. **스프라이트는 괜찮다.** 64 px 머리는 옆모습 + 눈 표식 하나라서 시점이 하나다(`hero-sprite-head-12x.png`). 문제는 초상, 그리고 `head34`를 쓰는 전신·키아트·이야기 패널이다.

**R4 처방이 왜 못 고쳤나.** R4 H1은 옆얼굴 틀은 그대로 둔 채 두 눈만 콧등 양쪽으로 옮긴 2D 점 수정이었다. 윤곽의 입술·턱 혹, 14u 코, 정면 아몬드 눈은 남았다. 그 위에 B2 §5.1이 이 점열과 가로선을 '바꾸면 안 되는 것'으로 묶어 8명에게 복제했다. 하나의 회전각에서 만든 구조가 아니라 옆얼굴 위의 덧칠이었다.

**처방 원칙(세 방향 공통).** 이목구비를 모두 3D 머리 모형의 점으로 두고, 회전각 하나로 투영한다. 2D에서 점을 따로 옮기지 않는다. 부록 A는 이 방법을 AD가 그려서 확인한 코드다.

## 2. 재디자인 방향 셋

### 2.1 공통 (세 방향 모두)

- **구조**: 3D 점 + 한 각도의 투영(§3.2). 눈선·코선·입선은 수평 직선이다. 카메라 높이를 눈높이로 둔다.
- **빛과 명도**: 좌상 키 라이트를 그대로 쓴다. 얼굴 안은 종이 · 종이 그늘(`#D8D0C0`) 평면 · 먹 악센트의 3단이다. 그늘은 빛 반대쪽(먼 쪽, 아래쪽)에만 둔다.
- **윤곽선**: 그림자 쪽 2.6~2.9, 빛 쪽 1.3(바이블 §3의 1.4배 / 0.7배 비율). 턱과 목의 경계는 목 그림자 띠가 맡는다.
- **유지할 것**: 의상, 소품, 청록 서명은 지금 디자인 그대로다(B2 §6).
- **매력 공통 비례**
  - 머리 높이(정수리~턱 끝)에서 눈선 위치: 0.53~0.56. 독만 0.51~0.52.
  - 아래 얼굴(코밑~턱)은 가운데 얼굴(눈썹~코밑) 이하. 독만 1.05배.
  - 머리카락은 큰 덩어리 + 결을 따르는 종이 윤기 획 2~3개(폭 1.8u 이상, B2 R3).
  - 얼굴 가장자리를 넘어오는 머리 가닥을 1개 이상 둔다. 헬멧형 머리는 금지다.

### 2.3 남자 얼굴 기준 (결·독. 단·서리·휘를 확장할 때 참고)

- 공통: 홍채 지름은 눈 폭의 0.50~0.58.
- **결**
  - 좁은 얼굴, 날카로운 턱(ws 0.93, jw 0.90).
  - 곧은 눈썹 2.3u, 꼬리만 살짝 든다.
  - 눈 높이/폭 0.42, 쌍꺼풀 없음.
  - 가까운 뺨(오른뺨)의 흉터는 빛 속에 둔다.
- **독**
  - 넓은 사각 턱(ws 1.04, jw 1.10, ky 1.03). 굵고 낮은 눈썹 3.6u.
  - 작은 눈(높이/폭 0.33), 큰 코 1.18, 넓은 입(cw 8.6).
  - 팔자 주름과 수염 자리 종이 그늘 면을 허용한다. 해칭은 금지다.

### 2.4 방향 A — 정통 3/4 극화 (θ 30°, 권고)

**정의.** 머리를 30° 돌린다. 조선 초상화가 즐겨 쓴 칠분면에 가까운 각이다. 두 눈이 모두 보이고, 먼 눈은 가까운 눈의 0.55~0.65배로 눌린다.

**구조 확인값 (결, `ad-numbers.png`)**

| 항목 | x (y) |
|---|---|
| 가까운 눈 | −1.2 ~ 9.7, 홍채 5.5 |
| 먼 눈 | 18.0 ~ 24.6, 홍채 23.8. 폭 비 0.61 |
| 콧뿌리 | 16.3 |
| 코끝 | 18.6 (y 11.3) |
| 코밑 | 16.2 |
| 입(가까운 끝 / 중심 / 먼 끝) | 8.3 / 16.1 / 19.3 (y 18.5) |
| 먼 윤곽 | y −8: 28.0 · y 0: 27.3 · y 10: 25.2 · y 20: 21.5 · y 30: 15.3 |

**명도**
- 먼 쪽에 종이 그늘 면. 명암 경계는 먼 눈썹 머리 → 먼 눈 안쪽 → 먼 콧방울 너머 → 먼 입꼬리 바깥 → 턱 끝 쪽으로 간다.
- 코의 먼 옆면은 그늘, 코밑은 먹 쐐기. 아랫입술 그늘, 목 그림자 띠.
- **결의 챙 그림자는 '빛 판'을 권고한다.** 이마와 먼 눈을 덮고(먼 눈은 눈빛 한 점), 가까운 눈은 빛 속에 둔다(`ad-sheet3.png` 넷째 열, `ad-gyeol-A-light-6x.png`).
- 바이블 판(가까운 눈을 덮는 판)은 비교용으로 함께 그린다(`ad-sheet3.png` 첫 열).

**84 px에서**: 가까운 눈 7 px 이상, 먼 눈 4 px 이상. 두 홍채가 모두 오른쪽으로 치우친다. 그늘 면은 얼굴의 30% 이하.

**64 px 스프라이트**: 지금 옆모습 스프라이트를 그대로 쓴다(눈 표식 하나, 먼 눈 점 없음). 초상과는 눈 모양과 머리 실루엣만 맞춘다.

**장점**
- 3/4 몸, 키아트, 이야기 패널, 오른쪽을 보는 스프라이트와 시점이 이어진다. 지금 자산을 가장 적게 버린다.
- 두 눈과 입 전체가 보여 표정 6종이 읽힌다.
- 면 나누기가 입체감을 준다.

**단점**
- 구성이 가장 어렵다(먼 눈의 단축). 3D 방법 없이 손으로 점을 옮기면 다시 입체파가 된다.
- 84 px에서 먼 눈이 작다.
- 결의 '가까운 눈 그림자' 서명을 바꿔야 한다(Q2).

**의상을 다듬을 여지**
- 깃의 V가 3/4에서 곡선으로 넘어가게 한다.
- 여자는 목을 8~8.5u로 가늘게 한다.
- 청록 서명을 얼굴 가까이 둔다: 결의 매듭은 턱 아래, 독의 멜빵은 가까운 어깨, 월의 댕기는 가까운 귀 뒤로 흘러내리게.

### 2.5 방향 B — 정면 흉상 (θ 0°, 몸은 30° 돌림)

**정의.** 얼굴은 0°로 대칭이다. 어깨와 옷깃은 30° 돌린 3/4이고, 시선만 화면 오른쪽으로 8° 둔다. 머리 기울기(roll)는 ±3°까지 허용한다.

**명도**
- 보는 사람 기준 오른쪽 옆면을 종이 그늘로 칠한다. 경계는 관자 → 광대 바깥 → 광대 아래로 파고들었다가 → 턱으로 간다.
- 코의 오른쪽은 그늘, 코밑 쐐기는 오른쪽 아래로. 아랫입술 그늘, 목 띠.
- 결: 챙 바로 아래에 0~2u 먹 띠만 두고 두 눈은 빛 속에 둔다. 대각 그림자로 한쪽 눈을 덮으면 어느 쪽으로 기울이든 안대처럼 읽힌다(`ad-sheet3.png` 둘째 열, 넷째 열 둘째 줄에서 확인).

**84 px에서**: 두 눈 각각 7 px 이상, 입 6 px 이상.

**64 px 스프라이트**: 정면 스프라이트는 없다(오른쪽 보기 고정, 바이블 §2.1). 스프라이트는 지금 그대로 두고, 초상과는 머리·모자 실루엣으로만 이어진다.

**장점**
- 표정이 가장 잘 읽힌다(두 눈이 같은 크기, 입이 온전히 보임).
- 대칭이라 구성이 가장 쉽다.
- 흑립의 띠, 고깔의 세모, 정자관의 계단이 아이콘처럼 선명하다.

**단점**
- 초상은 플레이어를 보는데 몸과 스프라이트는 오른쪽을 본다. 시점 둘을 따로 설계해야 한다.
- 정면 얼굴은 납작하고 증명사진처럼 굳기 쉽다.
- 흑립 챙이 원 위쪽을 가로로 다 덮는다.
- 결의 '그림자 속 눈빛' 서명이 초상에서 사라진다.

**의상을 다듬을 여지**: 두 어깨와 깃 V 전체가 보이므로 깃 여밈, 동정, 청록 서명을 정면 대칭으로 다듬을 여지가 크다.

### 2.6 방향 C — 옆얼굴 수묵 인물화 (θ 90°)

**정의.** 눈 하나만 그린다. 눈은 앞이 열린 '<' 쐐기이고 홍채는 앞 가장자리에 있다. 이마-코-입술-턱 윤곽이 그림의 주인공이다.

**확인값 (결)**: 눈 x 23.4(바깥 눈꼬리) ~ 29.7(앞), 콧뿌리 32.6, 코끝 37.2(y 11.3). 입술은 코끝-턱 선(E선)보다 1.0~2.1u 안쪽, 귀 중심은 x ≈ −1.

**명도**
- 얼굴은 대부분 빛이다. 눈확 그늘 한 조각, 윗입술 위의 코밑 그림자, 목 띠만 둔다.
- 결은 바이블 판이 자연스럽다. 챙 그림자가 눈을 덮고 눈빛 한 점만 남는다(`ad-sheet3.png` 셋째 열 첫 줄).

**84 px에서**
- 눈 4 px 이상. 옆얼굴 윤곽의 꺾임이 1 px 이상으로 보인다.
- 뒤통수 서명(쪽, 말총, 땋은 머리, 갈기)이 원 안에 들어와야 한다. 그래서 머리 배율을 1.42로 줄인다(A·B는 1.58). 얼굴이 작아진다.

**64 px 스프라이트**: 초상과 같은 시점이다. 셋 중 가장 일관된다.

**장점**
- 눈이 하나라서 시점 섞임이 원리적으로 일어날 수 없다.
- 흑백 실루엣과 붓 윤곽이 가장 '먹극화'답다. 모자와 머리 실루엣이 가장 강하다.
- 스프라이트와 시점이 같다.

**단점**
- 표정이 눈 하나와 입 반쪽에 실린다. hurt, lowhp, focus를 구분하려면 모양 차이가 더 커야 한다.
- 8명이 모두 오른쪽 옆얼굴이라 같아 보이기 쉽다. 코·입술·턱 윤곽을 인물마다 확실히 달리 해야 한다.
- 윤곽이 얼굴의 전부라서 '부리 코'가 가장 큰 위험이다.
- v1.0 §8.1의 3/4 얼굴 묘사를 고쳐야 한다.

**의상을 다듬을 여지**: 등 쪽 소품(지게, 보따리, 전동, 쪽)이 서명이 된다. 초상 구도에 뒤통수와 등을 넣는다.

### 2.7 권고

**A를 권하고, 결은 빛 판으로 한다.**
- 몸·스프라이트·키아트와 시점이 잇닿는다.
- 표정이 읽힌다.
- 3D 방법을 쓰면 다시 입체파가 될 위험이 없다.

C는 더 강한 느와르 정체성이 필요할 때의 대안이고, B는 표정 판독이 무엇보다 앞설 때 고른다.

### 3.2 구조 규칙 (핵심, 부록 A 코드 그대로)

1. **좌표.** 머리 좌표(u)는 셋이다.
   - s: 가로. + 쪽이 인물의 왼쪽이고, 0°에서는 화면 오른쪽이다.
   - y: 아래로 +. 눈선이 0이다.
   - d: 앞(코 방향)으로 +.
   - 원점은 귀 구멍 평면 위의 회전축이다. 결의 흑립을 쓸 때는 `PN._hk.hat34`를 `translate(−sinθ, 3.5)` 안에 넣는다. 그러면 챙 중심이 y −30.5에 놓인다.
2. **투영.** x = s·cosθ + d·sinθ, y는 그대로다.
   - 표정의 머리 기울기는 머리 묶음 전체를 목 점 (3·sinθ, 22) 둘레로 돌려서 낸다. 기존 EX 표(`k-hero.js:1571-1578`)의 rot을 쓴다.
   - 고개를 돌리는 표정(±5°)은 θ를 바꿔서 다시 투영한다.
   - **2D에서 점을 따로 옮기지 않는다.**
3. **얼굴 부피.** y −26부터 32.6까지 1.3마다 단면을 만든다.
   - 단면 점: s = S·u, d = Ds + (Df − Ds)(1 − u^p). u ∈ {0, .15, .3, .45, .58, .7, .8, .88, .94, 1}.
   - 키프레임 S(y), Ds(y), Df(y), p(y)는 부록 A의 BASE이고, y 방향은 Catmull-Rom으로 잇는다.
   - 인물 보정: S에 ws를 곱하고, y > 8에서는 턱 계수 1 + (jw − 1)·min(1, (y − 8)/12)를 더 곱한다. y > 0인 점은 y에 ky를 곱한다.
4. **윤곽.**
   - 단면마다 ±s 점의 최대 x가 먼 윤곽, 최소 x가 가까운 쪽 경계다.
   - 코 점(뿌리·콧등·끝·끝 아래·콧기둥·코밑)은 그 높이의 윤곽보다 0.4 이상 나올 때만 윤곽에 넣는다. 30°에서는 들어가지 않는다.
   - 얼굴 = 먼 윤곽(위 → 아래) + 가까운 쪽(아래 → 위). 닫힌 Catmull-Rom, k 0.1.
   - **입술과 턱 혹이 윤곽에 생기는 것은 θ ≥ 60°(C)뿐이다.**
5. **눈.**
   - 눈꺼풀은 u ∈ [0, 1] 곡선이다. s = ±lerp(si, so, u)·ws, 윗꺼풀 y = 기준 − hu·sin(π·u^0.85), 아래꺼풀 y = 기준 + hl·sin(π·u^1.2). 깊이 d는 안쪽 27.7 → u 0.4에서 29.7 → 바깥 23.4.
   - 홍채 중심은 (±11.3·ws, −0.6, 29.3)을 투영한 점이다. rx = ri·max(0.42, cosθ), 먼 눈은 0.82배 더 좁히고 +0.5 바깥으로. ry = 1.04·ri. 흰자로 자른다.
   - 옆얼굴(θ > 50)에서는 가장 앞의 윗꺼풀 점부터 바깥 눈꼬리까지만 쓴다.
6. **눈썹.** 머리 (±6.6ws, −7.4+by, 32.7), 정점 (±13.8ws, −10.1+by, 31.2), 꼬리 (±19ws, −8.3+by, 24.6)를 투영한다. 머리에서 굵고 꼬리에서 0이다. 3/4의 먼 눈썹은 0.85배.
7. **코, 입, 귀, 그늘 면, 결의 챙 그림자, 윤곽 붓, 머리선 커튼.** 부록 A의 함수와 3D 점표를 그대로 쓴다.
8. **초상 배치(160 상자).**
   - A·B: 배율 1.58. 머리 원점을 (80 − xc·1.58, 76)에 둔다. xc = 두 눈동자 x의 평균 − (A일 때 1).
   - C: 배율 1.42. 원점을 (80 − xc·1.42, 78)에 둔다. xc = 가까운 눈동자 x − 10.
   - 합격 범위: 두 눈의 중점(C는 눈)이 원 중심에서 가로 ±6, 눈선은 원 중심보다 2~6 위.
9. **그리는 순서.**
   1. 배경
   2. 몸과 옷깃
   3. 머리 뒤 소품(결의 묶은 머리, 월의 댕기·쪽·비녀, 독의 매듭 끝)
   4. 두개골·머리 덩어리(타원)
   5. 목 그림자 띠(목으로 자름)

## 부록 A. AD 구성 코드 (검증됨)

`ad-sheet3.png`, `ad-final-4x.png`를 그린 계산과 같다. kit-artist는 구조(부피 · 투영 · 윤곽 · 눈 · 눈썹 · 코 · 입 · 귀 · 그늘 · 챙 그림자 · 커튼)를 그대로 쓴다. 머리카락의 결, 옷, 소품, 표정은 이 지시서대로 새로 그린다.

`clip(d)`는 호출마다 고유 id의 `<clipPath>`를 defs에 넣고 `clip-path="url(#…)"`를 돌려주는 도우미다(구현은 자유). **defs는 그림을 다 만든 뒤에 출력한다.** AD가 순서를 거꾸로 해서 클립이 빠진 일이 있었다.

const spl = (P, k = 6) => {            // 열린 점열 Catmull-Rom 샘플링
  const n = P.length, o = [], g = (i) => P[cl(i, 0, n - 1)];
  for (let i = 0; i < n - 1; i++) for (let j = 0; j < k; j++) {
    const t = j / k, a = g(i - 1), b = g(i), c = g(i + 1), d = g(i + 2), t2 = t * t, t3 = t2 * t;
    o.push([0, 1].map((z) => 0.5 * (2 * b[z] + (c[z] - a[z]) * t + (2 * a[z] - 5 * b[z] + 4 * c[z] - d[z]) * t2 + (3 * b[z] - a[z] - 3 * c[z] + d[z]) * t3)));
  }
  o.push(P[n - 1]); return o;
};
const brush = (P, W) => {              // 가변 폭 붓: W(t), t = 길이 비율
  const n = P.length, L = [], R = [], cum = [0];
  for (let i = 1; i < n; i++) cum.push(cum[i - 1] + Math.hypot(P[i][0] - P[i - 1][0], P[i][1] - P[i - 1][1]));
  const tot = cum[n - 1] || 1;
  for (let i = 0; i < n; i++) {
    const a = P[Math.max(0, i - 1)], b = P[Math.min(n - 1, i + 1)], dx = b[0] - a[0], dy = b[1] - a[1], l = Math.hypot(dx, dy) || 1, h = Math.max(0.06, W(cum[i] / tot) / 2);
    L.push([P[i][0] - dy / l * h, P[i][1] + dx / l * h]); R.push([P[i][0] + dy / l * h, P[i][1] - dx / l * h]);
  }
  return 'M ' + L.concat(R.reverse()).map(P2).join(' L ') + ' Z';
};
const tw = (w, a, b, p = 0.6) => (t) => w * Math.pow(cl(Math.min(t / a, (1 - t) / b), 0, 1), p);
const kf = (Q) => (y) => {             // y 방향 1차원 Catmull-Rom 키프레임
  const n = Q.length; if (y <= Q[0][0]) return Q[0][1]; if (y >= Q[n - 1][0]) return Q[n - 1][1];
  let i = 0; while (y > Q[i + 1][0]) i++;
  const g = (j) => Q[cl(j, 0, n - 1)][1], t = (y - Q[i][0]) / (Q[i + 1][0] - Q[i][0]), a = g(i - 1), b = g(i), c = g(i + 1), d = g(i + 2), t2 = t * t, t3 = t2 * t;
  return 0.5 * (2 * b + (c - a) * t + (2 * a - 5 * b + 4 * c - d) * t2 + (3 * b - a - 3 * c + d) * t3);
};

function model(ch) {
  const S0 = kf(BASE.S), Ds = kf(BASE.Ds), Df = kf(BASE.Df), Pw = kf(BASE.Pw);
  const Y = (y) => (y > 0 ? y * ch.ky : y), W = (y) => ch.ws * (y <= 8 ? 1 : 1 + (ch.jw - 1) * Math.min(1, (y - 8) / 12));
  const rings = [];
  for (let y = -26; y <= 32.6001; y += 1.3) {
    const yy = Math.min(y, 32.6), S = S0(yy) * W(yy), ds = Ds(yy), df = Df(yy), p = Pw(yy);
    rings.push([Y(yy), [0, 0.15, 0.3, 0.45, 0.58, 0.7, 0.8, 0.88, 0.94, 1].map((u) => [S * u, ds + (df - ds) * (1 - Math.pow(u, p))])]);
  }
  const n = ch.nose;
  const N = { root: [0, -3, 32.6], ridge: [0, Y(4), 33.4 + 2 * (n - 1)], tip: [0, Y(12 + 2 * (n - 1)), 32.4 + 5 * n], bot: [0, Y(13.6 + 2 * (n - 1)), 31.6 + 4.2 * n],

  return { rings, N, Y };
}
function outline(C, M) {
  const far = [], near = [];
  for (const [y, P] of M.rings) {
    let mx = -1e9, mn = 1e9;
    for (const [s, d] of P) for (const ss of [s, -s]) { const x = ss * C.c + d * C.s; mx = Math.max(mx, x); mn = Math.min(mn, x); }
    far.push([mx, y]); near.push([mn, y]);
  }
  const at = (L, y) => { for (let i = 0; i < L.length - 1; i++) if (y >= L[i][1] && y <= L[i + 1][1]) { const t = (y - L[i][1]) / ((L[i + 1][1] - L[i][1]) || 1); return L[i][0] + (L[i + 1][0] - L[i][0]) * t; } return y < L[0][1] ? L[0][0] : L[L.length - 1][0]; };
  const N = M.N, ins = [N.root, N.ridge, N.tip, N.bot, N.col, N.sub].map(C.p).filter((p) => p[0] > at(far, p[1]) + 0.4);
  let F = far;
  if (ins.length) { const y0 = ins[0][1], y1 = ins[ins.length - 1][1]; F = far.filter((p) => p[1] < y0 - 0.01 || p[1] > y1 + 0.01).concat(ins).sort((a, b) => a[1] - b[1]); }
  return { F, N: near, at: (y) => at(F, y), face: sm(F.concat(near.slice().reverse()), true, 0.1) };
}

function curtain(C, ch, OL, line, E) {   // 앞머리: 가르마 → 양쪽 머리선 → 두개골 타원 호. 먼 쪽은 얼굴 윤곽에 닿는 점에서 끊는다
  const P = C.p, ws = ch.ws, ang = (p) => Math.atan2((p[1] - E.y) / E.ry, (p[0] - E.x) / E.rx) / Rd;
  const near = line.map(([s, y, d]) => P([-s * ws, y, d])), fa = line.map(([s, y, d]) => P([s * ws, y, d]));
  let far = fa;
  if (C.th > 15) { let cut = fa.length - 1; for (let i = 1; i < fa.length; i++) if (fa[i][0] >= OL.at(fa[i][1]) - 0.6) { cut = i; break; } far = fa.slice(0, cut + 1); }
  if (C.th > 60) far = [near[0]];
  let an = ((ang(near[near.length - 1]) % 360) + 360) % 360, af = ((ang(far[far.length - 1]) % 360) + 360) % 360;
  if (an < 90) an += 360; if (af < an) af += 360; if (af - an > 300) af -= 360;
  const arc = []; for (let i = 0; i <= 24; i++) { const a = (an + (af - an) * i / 24) * Rd; arc.push([E.x + E.rx * Math.cos(a), E.y + E.ry * Math.sin(a)]); }
  return fp(sm(far.slice().reverse().concat(near.slice(1)), false, 0.14) + ' L ' + arc.map(P2).join(' L ') + ' Z', K.ink);
}

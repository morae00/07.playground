**세 가지 형식**
1. **고정 크기 조각(stamp)**: 투사체, 낫, 장판 중심 물체, 폭발 중심, 오라, 팝, 표식. 공통 팩에 `skill/<group>/<part>/<frame>`으로 굽고, 렌더러가 시뮬 좌표에 회전해서 찍는다.
2. **매개 도형(SPEC)**: 판정 반지름·폭에 맞춰야 하는 테, 채움, 빔 띠, 연쇄 선, 고리, 소용돌이 팔. 렌더러가 캔버스로 그리고, 숫자는 `PN.skillVfx.SPEC`(데이터)에서 읽는다. 킷은 같은 규칙으로 `draw()` 참고 그림(골든)을 그린다.
3. **분신 프레임**: 주인공 스프라이트 21장을 담묵 선 사본으로 바꾼 것. 주인공과 같은 상태·프레임 번호를 쓴다.

**핵심 결정 4가지**
1. **빔 띠의 반폭 = `width`** (판정과 같게).
   - 판정은 `distancePointToSegment < enemy.radius + width`다(`GameEngine.ts:2412`, `:2483`).
   - 지금 렌더러는 `lineWidth = width`로 그려 판정 띠의 절반만 보인다(`GameRenderer.ts:652`). 렌더 `a2d-proto-beam-width`에서 축에서 25 떨어진 stalker가 판정 안(25 < 15 + 12)인데 빗나가 보였다(확인).
2. **아군 진행 표시 = 바느질.**
   - 12시에서 시계 방향으로 꿰매 나간다. 판정 원 전체는 첫 프레임부터 가는 안내선으로 보인다.
   - 적 예고(붓 점선 + 호박 해칭 + 방사 눈금)와 모양으로 갈린다. 지금 골분 박격 착탄 예고는 적 문법인 방사 눈금 8개를 쓴다(`GameRenderer.ts:788`, `:832-843`, 확인).
3. **오래 남는 소용돌이 장판의 청록 망점은 테 안쪽 띠에만 둔다.** 원 전체에 깔면 검은 태양 각성(r228)이 화면에 큰 청록 원판이 된다. 띠에만 두면 안쪽의 적 탄·예고·먹귀가 잘 읽힌다(렌더 `a2d-proto-zones`, `a2d-proto-zones2`, 확인).
4. **거울 분신과 일식 잔상 = 주인공 프레임의 담묵 선 사본.** SVG 필터로 만들 수 있고, 주인공 프레임이 바뀌면 따라 바뀐다(렌더 `a2d-proto-clone-filter`, 확인).

## 1. 모듈 공통 계약

### 1.1 파일·의존·id
- `art/concept-kit/k-skills-vfx.js` 하나에 `window.PN.skillVfx`를 만든다. 모든 선언은 IIFE 안에 둔다.
- 의존
  - `lib.js`(`PN.rng`, `PN.taper` 등)
  - **거울 분신 프레임만** `PN.heroKit.sprite`를 부른다. 굽기와 리뷰에서 `k-hero.js`가 먼저 읽힌다(`scripts/art-review-sheet.mjs:30-31`). 다른 모듈은 부르지 않는다. `PN.vfx`·`PN.icons`의 도우미가 필요하면 복사한다.
- id 접두사는 호출마다 `ksv<N>_`(모듈 카운터)다. 루트는 `<g class="ksv ksv-<id>">`이고 자기 `<defs>`를 둔다. 분신 프레임 안의 `hk<N>_` id는 주인공 킷이 만든다.
- 글자를 넣지 않는다(`<text>` 0). 글자처럼 읽히는 기호도 넣지 않는다(§1.7).
- 결정적이어야 한다. `Math.random`·`Date`를 쓰지 않고 `PN.rng(seed)` 또는 `SPEC.jit`을 쓴다(굽기는 바이트 단위로 같아야 한다, `docs/art/pipeline.md:15`).
- 기존 모듈과 원본은 고치지 않는다.

### 1.2 단위·좌표·회전 기준
- **단위 = 월드 단위 = 1440×900(줌 1.0)의 1x px.** 조각은 `scale: 1`로 @2x에 굽는다.
  - 리뷰 `--scale 1`은 1440×900 실제 크기, `--scale 0.8`은 1024×720이다.
- 조각은 로컬 박스 [0, w] × [0, h]에 그린다. 앵커는 박스 안의 한 점이고 **그 점이 시뮬 좌표에 놓인다**(투사체 중심, 낫 중심, 장판 중심, 빔 시작점, 주인공 발).
- 원과 띠는 위에서 본 **참 원**이다. 위험지형과 같다(바이블 §7.2 "판정 반경과 정확히 같은 원"). 발밑 표식(감속·속박 표식, 일식 원반, 동전 열병 오라)만 발 그림자처럼 ry = 0.42·rx 타원이다.
- 회전 기준(`rotate`)

| 값 | +x 방향 | 쓰는 곳 |
|---|---|---|
| `vel` | 속도 방향 `atan2(vy, vx)` | 투사체. 부채 단검 귀환도 속도 방향이다. 지금의 +π 관례(`GameRenderer.ts:614`)는 버린다 |
| `beam` | 빔 방향(x1,y1 → x2,y2) | 빔 시작 조각 |
| `radial` | 중심(주인공·폭발 중심)에서 바깥 | 궤도 낫, 폭발 가루, 갑편 |
| `tangent` | 바느질이 나아가는 시계 방향 접선 | 바느질 머리 |
| `ray` | 광선의 바깥 방향 | 일식 베기 획 |
| `face` | 회전 없음, 주인공처럼 좌우 반전만 | 분신 몸 |
| `none` | 회전·반전 없음 | 장판 중심, 오라, 팝, 표식 |

### 1.3 공개 API
```
window.PN.skillVfx = {
  version: '1.0',
  K: { ink:'#121110', ink700:'#2B2926', ink500:'#46423D', ink300:'#8C8579', ink100:'#BCB4A5',
       p50:'#FAF6EC', paper:'#F3EEE2', p300:'#D8D0C0', ally:'#00A8C6', allyD:'#007C94', allyG:'#CFF6FF' },
  ids: [ 게임과 같은 SkillId 17개 ],                 // src/game/engine/worldTypes.ts:8-25
  groups: [ ...ids, 'common' ],                     // 굽는 조각 묶음('common' = 바느질 머리)
  META: { [id]: { name, kind: 'active'|'passive', shape, stages: { normal: [...], awakened: [...] },
                  main, cell: [w, h], origin: [x, y] } },
  SIZES: { [id]: { ... } },                          // §2 표의 사본
  SPEC: { ... },                                     // §1.5, 토큰 이름과 숫자만
  parts(group)  → [ { part, frames, drive, fps, window, box:[w,h], anchor:[x,y], rotate, layer, lod, still } ],
  stamp(group, part, { frame })  → string,           // 굽는 조각(로컬 박스)
  draw(id, stage, opts)  → string,                   // 참고 합성 그림(리뷰·골든). 로컬 원점은 §3 각 절
  hit(id, stage, opts)   → { circles: [[x,y,r]], capsules: [[x1,y1,x2,y2,halfWidth]] },  // draw와 같은 좌표계
};
```
- `draw` opts
  - `level` 1~5(기본 5), `awakened`, `frame`, `progress` 0~1(그 단계 안 진행률), `t`(초: 궤도 위치·소용돌이 각)
  - `radius`·`width`·`length`·`points`(덮어쓰기. 없으면 `SIZES`의 레벨 값)
  - `reduced`(감소 모션), `lod` `'full'|'minimal'`
- 반환은 늘 그림이 있는 문자열이다. 빈 문자열과 빈 그룹은 안 된다(`--check`가 "nothing painted"로 잡는다).
  - `META[id].stages.normal`에 없는 단계를 받으면 가장 가까운 평상 단계를 그린다.
- `META[id].main`은 판정 모양이 가장 잘 보이는 단계다. 리뷰 장면 명령이 쓴다.
- `META[id].cell`과 `origin`은 작업자가 정한다. 그 스킬의 L5 각성 그림 전체가 칸 안에 4 이상 여백으로 들어가야 한다(C7이 검사).
- **각성에서만 쓰는 조각은 이름이 `-awakened`로 끝난다.**

### 1.4 조각 메타(`parts`) 필드

### 1.5 매개 도형 SPEC (렌더러가 캔버스로 똑같이 그린다)
- 색은 **토큰 이름**으로 적는다: `ink`, `ink700`, `ink300`, `p50`, `paper`, `p300`, `ally`, `allyD`, `allyG`.
  - 렌더러가 `palette.ts`(`NEUTRAL`, `SIGNAL`)로 바꾼다. `ink700`은 inkSoft, `ink300`은 inkMuted, `p50`은 paperBright, `p300`은 paperShadow다.
  - `ink500`과 `ink100`은 `palette.ts`에 아직 없는 신규 토큰이라(바이블 §19 A-11) 매개 도형에 쓰지 않는다. 조각 안에서는 써도 된다.
- 층은 `[토큰, 굵기]`를 아래에서 위 순서로 적는다. 한 층의 굵기는 선의 전체 폭이다.

| 키 | 그리는 것 | 값 |

### 1.6 색·명도·선·질감
- **쓸 색은 `K`의 11개뿐이다**(6자리 hex). 마스크·필터 정의 안에서만 #FFFFFF·#000000을 쓴다.
  - 산호·호박·자수정·연두·장 재질색(spot·accent·deep)은 0이다(V2, 바이블 §5.3, handoff §0).
  - "중립처럼 보이지만 신호색 쪽으로 기운 색"도 금지다. 예: 지금 레지스트리의 보라 기운 먹 #2a2134와 분홍 종이 #fff0ed(`visualRegistry.ts:198`, `:205`, `:206`). `palette.test.ts`의 채도 0.3 기준은 통과하지만 흑백과 색각 이상에서 정예 보라·적 산호 쪽으로 읽힌다.
  - 이름 색(`white`), `rgb()`, `hsl()`도 쓰지 않는다.
- **샌드위치(§5.3)**: 청록은 늘 먹 위에 얹는다. 먹(또는 먹·종이 몸) 없이 바닥에 닿는 청록 선이나 면은 금지다.
- **명도(P1, §12.1 "밝은 채움")**
  - 아군 채움은 p50 α 0.25다.
  - 장판 원 안의 먹 면(소용돌이 팔 + 중심 물체)은 원 넓이의 35% 이하다.
  - 빔 띠 안의 먹 심은 띠 폭의 40% 이하다.
- **선 굵기(1x px = 월드 단위)**

| 대상 | 굵기 |
|---|---|
| 투사체·낫 몸 외곽 | ink 1.5 (바이블 §3 "아군 투사체 먹 1.5") |
| 실(바늘 실, 회복 실, 분신 탄 실) | [ink 2.6, ally 1.6, allyG 0.5] |
| 장판 테, 고리, 띠 가장자리 | §1.5 |
| 조각 안 내부선 | 0.6~1.0 |
| 최소 | 정보를 전하는 선 1.2 이상. 장식선 0.6 이상이고 조각 안에서만 |

- **망점**: 청록 점만 쓰고, 피치는 6 이상이다(0.8배 화면에서 4.8px). 띠 폭이 3피치(18) 미만인 곳에는 망점을 두지 않는다. 좁은 띠의 망점은 점선으로 읽힌다(K1 검수 R7).
- **해칭 0**: 평행선 묶음은 적 예고 전용이다(P4, §6-5). 속도선·끌림 획은 2획 이하이고 길이와 각도를 다르게 한다. `PN.speedLines`의 평행 획은 쓰지 않는다.
- **발광·블러·그라데이션·혼합 모드 0**(§6-1, §6-9).
  - 투사체 심의 청록 후광(§6-9 예외)도 블러 없이 납작한 α 원 두 겹으로만 그린다: ally α ≤ 0.35, 반지름 ≤ 6.
- **종이결(grain) 0**(§6-8).
- 녹아웃 헤일로는 적 전용이다(§6-6). VFX에는 두르지 않는다.

### 1.8 감소 모션·섬광 감소·LOD (§13, V5)
- **판정 모양은 어느 설정에서도 그대로다**: 테, 띠, 고리, 낫의 위치, 투사체.
  - 궤도 낫은 감소 모션에서도 시뮬 위치대로 움직인다(`worldRenderer.ts:1202`, BUG-15).
- **감소 모션**(`reduced:true`)
  - `loop` 조각은 `still` 장으로 멈춘다.
  - 매개 도형의 움직임을 멈춘다: 소용돌이 회전 0, 펄스는 확장 없이 반지름 60에서 사라짐, 연쇄 떨림은 한 seed로 고정, 갑편 비행은 마지막 자리(140)에 바로.
  - `prog` 조각은 그대로 재생한다. 시간과 진행을 알려 주는 정보다(§13 "프레임 애니메이션 유지").
  - 팝은 크기 변화 없이 α로만 나타나고 사라진다.
- **섬광 감소**
  - 렌더러가 `flash` 조각만 α × 0.5로 그린다.
  - 다른 조각은 한 장에서 종이 섬광 면적을 조각 넓이의 30% 이하로 둔다.
- **LOD minimal**(적 160 이상)
  - `deco` 조각, 가루, 꼬리는 뺀다. `loop`는 `still`로 둔다.
  - 매개 도형(테, 띠, 채움, 멈춘 소용돌이)은 그대로 둔다.
- `draw(…, {reduced:true})`와 `{lod:'minimal'}`은 위 규칙을 그대로 보여 주는 참고 그림이다. `hit()` 겹침이 평상과 같아야 한다(C3).

## 4. 얼굴

- 이 모듈은 **얼굴을 새로 그리지 않는다.** 분신과 일식 잔상은 주인공 프레임을 필터로 바꾼 것이다. 얼굴 구조(한 시점 약 45°, 대각 그림자, 눈빛 한 점)는 K0 결과(`API-hero.md` §1.1, §2)를 그대로 물려받는다.
- 선 사본에서 2×2 눈빛과 흉터가 사라지는 것은 괜찮다(1x에서 분신은 몸의 선으로 읽힌다).
- 얼굴만 따로 덧그리지 않는다. 따로 그리면 원본과 시점이 어긋나 입체파 얼굴이 다시 생긴다.
- 그 밖의 조각(팝, 표식, 중심 물체, 코로나)에 눈·입처럼 읽히는 배치를 만들지 않는다(§1.7).

## 5. 작업 순서 (권장)

1. **뼈대**: `K`, `ids`, `groups`, `META`, `SIZES`, `SPEC`, `parts`, `stamp`, `draw`, `hit`. 매개 도형(`stitch`, `guide`, `fill`, `dots`, `thread`, `band`, `bolt`, `tether`, `swirl`)을 `draw`에 먼저 넣는다. 빈 조각으로 C1·C6·C7을 먼저 통과시킨다.

4. **패시브 6종**: 팝 12장 → 오라와 발동 그림 → 각성.
5. **선택**: 감속·속박 표식, 파편, `spearCopy`, `orbitTrail`, 합성 6종을 기존 그림으로 확인.

## 6. 합격 기준과 확인 명령

- 명령은 모두 한 줄이다. `--expr`는 작은따옴표로 감싸고 안에서는 큰따옴표만 쓴다(훅 규칙). `<id>`는 바꿔 넣는다(꺾쇠가 남으면 훅이 막는다).
- 렌더 이름은 `k4-`로 시작한다.
- 아래 틀은 `PN.skillVfx`와 같은 모양의 임시 객체로 돌려 문법과 `--check` 통과를 확인했다(2026-10-03, `a2d-cmdtest-*`).
- 다른 작업자의 모듈이 작업 중 오류를 내면 `--check`가 "kit error"로 실패할 수 있다. 자기 모듈 오류가 아니면 납품서에 적고, 자기 그림의 `ok` 줄을 따로 적는다.

### C1 굽는 조각 전부 (`--check` ok, 앵커 점 확인)
```
node scripts/art-review-sheet.mjs expr --name k4-c1-stamps --scale 2 --check --expr '(function(S){var s="",x=0,y=0,row=0;S.groups.forEach(function(id){S.parts(id).forEach(function(p){for(var f=0;f<p.frames;f++){var b=p.box;if(x+b[0]>900){x=0;y+=row+6;row=0}s+="<g transform=\"translate("+x+" "+y+")\"><rect width=\""+b[0]+"\" height=\""+b[1]+"\" fill=\"#B8AC93\"/>"+S.stamp(id,p.part,{frame:f})+"<circle cx=\""+p.anchor[0]+"\" cy=\""+p.anchor[1]+"\" r=\"1\" fill=\"#ff00ff\"/></g>";x+=b[0]+6;row=Math.max(row,b[1])}})});return "<g>"+s+"</g>"})(PN.skillVfx)'
```
- 자홍 점(앵커)이 투사체는 판정 중심(바늘 앞쪽), 낫은 날 중심, 장판 중심 물체는 중심, 오라는 주인공 발, 팝·표식은 아래 가운데에 있다.

### C2 스킬별 단계 시트 (행: L1, L5, 각성, 각성 + 감소 모션, 각성 + minimal)
```
node scripts/art-review-sheet.mjs expr --name k4-<id>-stages --scale 1 --check --expr '(function(S,id){var m=S.META[id],w=m.cell[0],h=m.cell[1],s="";[{level:1},{level:5},{level:5,awakened:true},{level:5,awakened:true,reduced:true},{level:5,awakened:true,lod:"minimal"}].forEach(function(o,r){(o.awakened?m.stages.awakened:m.stages.normal).forEach(function(st,c){s+="<g transform=\"translate("+(c*w)+" "+(r*h)+")\"><rect width=\""+w+"\" height=\""+h+"\" fill=\"#B8AC93\" stroke=\"#8C8579\"/><g transform=\"translate("+m.origin[0]+" "+m.origin[1]+")\">"+S.draw(id,st,o)+"</g></g>"})});return "<g>"+s+"</g>"})(PN.skillVfx,"<id>")'
```
- 17종 모두 돌린다. `--scale 0.8`로도 본다.
- 합격 기준
  - 단계마다 모양이 다르고, 평상과 각성이 색 없이도 구별된다(§3 각 절의 각성 차이).

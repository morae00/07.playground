# 흑백 타격 생존전 1.0 릴리스 노트 (초안)

> **초안이다.** 출시 후보 빌드에서 확정한다. 그림은 모두 컨셉 킷 잠정본이고 음악(D-16)은 아직 없어서 아래 '알려진 한계'에 적었다. R4 종료 조건 5에 따라 원작(0.1.0) 대비 규칙 변경을 모두 공개한다. 규칙의 정의는 `src/game/rules.ts`이고, 출시 빌드는 리마스터 규칙만 쓴다(원작 규칙은 비교 측정용으로 시험 도구에만 남는다).

## 1. 한눈에

- 주인공 결과 5개 장(먹선 골목, 철문 예배당, 무채 운하, 시계 무덤, 일식 관문)이 먹극화 그림으로 다시 그려졌다.
- 적은 역할(추적·돌진·사격·방패)마다 다르게 움직이고, 보스의 모든 공격은 먼저 예고된다.
- 적이 훨씬 많아지고 폭탄병이 섞이며, 보스는 훨씬 단단해졌다.
- 캐릭터 8명이 저마다 시작 무기와 특성을 지닌다. 무기 44종이 드래프트에 더해졌고, 무기마다 각성 기믹이 하나씩 있다.
- 스테이지마다 목표와 보너스 목표, 별 3개, 도감, 업적, 꾸미기, 패시브 트리가 생겼다.
- 무한 경쟁은 5개 장을 돌며, 날짜 시드(일간·주간)로 같은 판을 겨룬다.
- 진행 중인 런은 저장되어, 앱을 닫거나 튕겨도 이어 할 수 있다.
- 설정에서 섬광 감소와 모션 감소를 따로 켜고, 이동 키를 바꾸고, 전체 화면을 고를 수 있다.

## 2. 원작(0.1.0) 대비 규칙 변경 전체 목록

0.1.0의 저장은 그대로 넘어온다(G17). 기록판과 다시 보기는 규칙 버전(`RULES v2`)별로 따로 쌓여서, 원작 규칙의 기록과 섞이지 않는다.

## 3. 화면과 접근성

- 섬광 감소: 맞은 적이 반전되어 번쩍이지 않고, 흰 번쩍임과 피격 빛이 절반이 된다. 모션 감소와는 따로 켠다(UI-08). 0.1.0에서 섬광 감소를 켜 둔 저장은 모션 감소도 켠 채로 넘어온다.
- 모션 감소: 맥동, 회전, 흔들림, 튀어오름을 멈춘다. 운영체제의 동작 줄이기 설정을 따른다.
- 이동 키: 설정에서 네 방향 키를 바꾼다. 자판 위치 기준이라 한글 입력 상태에서도 그대로 동작한다. 방향키는 언제나 이동에 쓰인다.
- 화면 모드: 데스크톱 앱에서 창과 전체 화면을 고르고, 다음 실행에도 그대로 열린다.
- 스크린리더: HUD 효과는 시작하거나 끝날 때만 읽힌다.
- 색이 유일한 단서인 곳이 없다: 등급은 ◆ 개수와 이름, 스테이지 상태는 글·인장·점선, 효과는 +·! 표식으로도 구분한다.
- 게임패드로 모든 화면을 조작하고, 프롬프트는 쓰는 장치(키보드, Xbox, PlayStation)의 글리프로 나온다.

## 4. 저장

- 0.1.0의 저장은 첫 실행에 그대로 옮겨진다. 옮기기 전 원본은 백업 파일로 남는다(TEC-15).
- 설정 > 세이브에서 저장을 텍스트로 내보내고 가져올 수 있다.
- 진행 중인 런은 일시정지·종료·강제 종료 뒤에도 이어진다(CON-04).

## 5. 알려진 한계

- 그림은 모두 컨셉 킷이 그린 잠정본이다. 중간 보스(2~5장)와 필드 보스, 보스 공격·쓰러짐 포즈, 스킬 VFX 17종(D-14), 무기 44종의 아이콘과 효과, 위험지형, 캐릭터 8명, 이야기 패널 20장(D-15의 손그림 자리 6장 포함)이 모두 킷 그림으로 들어가 있다. 2026-10-23 결정으로 스타일 바이블 §15를 고쳐 킷 그림을 출시 에셋으로 쓰고, 에셋마다 출처를 기록한다. 사람 클린업(머리 모델 시트, 64px 다듬기 등)은 할 수 있는 범위에서 이어 간다.
- 흑백 0.3초 판독 테스트(스타일 바이블 §14, 참가자 8명 이상)를 아직 하지 않았다.
- 음악은 아직 없다(D-16의 9곡). 2026-10-23 결정으로 사람 작곡가에게 의뢰한다. 재생 코드(AUD-03)는 준비되어 있어 곡이 오면 팩만 더한다. 효과음과 장별 앰비언스는 합성 v0이다.
- 2~5장 중간 보스 4종은 페이즈 무브가 아직 없다(SYS-05). 페이즈가 바뀌면 기본 패턴이 빨라지기만 한다. 필드 보스의 2페이즈 무브도 없다.
- 한글 웹폰트는 내려받기 허락을 기다린다(D-17). 그동안 시스템 글꼴을 쓴다.
- macOS 개발자 ID 서명과 공증을 아직 하지 않았다(D-27, 인증서 준비 전).
- Windows판은 R4 스파이크 뒤에 정하기로 했고(D-26) 스파이크를 아직 하지 않았다. 지금은 macOS 12 이상만 지원한다.

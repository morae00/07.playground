# 흑백 타격 생존전 1.0 릴리스 노트 (초안)

> **초안이다.** 출시 후보 빌드에서 확정한다. 아트(D-14·D-15)와 음악(D-16)은 외주가 진행 중이라 아래 '알려진 한계'에 적었다. R4 종료 조건 5에 따라 원작(0.1.0) 대비 규칙 변경을 모두 공개한다. 규칙의 정의는 `src/game/rules.ts`이고, 출시 빌드는 리마스터 규칙만 쓴다(원작 규칙은 비교 측정용으로 시험 도구에만 남는다).

## 1. 한눈에

- 주인공 결과 5개 장(먹선 골목, 철문 예배당, 무채 운하, 시계 무덤, 일식 관문)이 먹극화 그림으로 다시 그려졌다.
- 적은 역할(추적·돌진·사격·방패)마다 다르게 움직이고, 보스의 모든 공격은 먼저 예고된다.
- 스테이지마다 목표와 보너스 목표, 별 3개, 도감, 업적, 꾸미기, 패시브 트리가 생겼다.
- 무한 경쟁은 5개 장을 돌며, 날짜 시드(일간·주간)로 같은 판을 겨룬다.
- 진행 중인 런은 저장되어, 앱을 닫거나 튕겨도 이어 할 수 있다.
- 설정에서 섬광 감소와 모션 감소를 따로 켜고, 이동 키를 바꾸고, 전체 화면을 고를 수 있다.

## 2. 원작(0.1.0) 대비 규칙 변경 전체 목록

0.1.0의 저장은 그대로 넘어온다(G17). 기록판과 다시 보기는 규칙 버전(`RULES v2`)별로 따로 쌓여서, 원작 규칙의 기록과 섞이지 않는다.

### 2.1 공정성 수정

| 무엇이 바뀌었나 | 플레이어가 느끼는 차이 |
|---|---|
| 히트스톱 예산 (BUG-07) | 타격 정지가 1초에 쓸 수 있는 양을 넘지 않는다. 처치는 강타로 친다. 스테이지 시계는 정지 중에 느려지지 않는다 |
| 연출 전용 번호 (BUG-08) | 파티클과 숫자가 게임 결과에 영향을 주지 않는다. 사격 적이 도는 방향은 등장 때 정해진다 |
| 고정 논리 화면 (BUG-09) | 적 등장과 화면 끝 공격이 창 크기가 아닌 1600×900 논리 화면을 기준으로 한다. 큰 창이 유리하지 않다 |
| 예고된 돌진 (BUG-10) | 보스 돌진은 보이는 준비 자세 동안 방향을 고정하고, 쫓아오며 꺾지 않는다 |
| 일식 벽 (BUG-11) | 일식 벽이 화면 끝에서 들어오고, 늘 피할 줄이 하나 있다 |
| 공정한 지형 (BUG-13) | 속박 덫은 한 번 들어갈 때 한 번만 묶고 그 뒤 잠시 면역이다. 시작 지점 근처에는 고정 위험지형이 없다 |
| 거울 분신 각성 (BUG-16) | 거울 분신의 각성이 흑선 레일 없이도 분신 사격을 더한다 |
| 믿을 수 있는 자동 조준 (SYS-01) | 움직이는 적을 앞질러 쏘고, 벽 너머 적은 건너뛰고, 세 번 빗나가면 목표를 바꾸며, 화면 안의 적만 노린다 |
| 스킬 순환 (SYS-11) | 침묵은 새 발동만 막는다(쿨다운, 회전 칼날, 자석 맥동은 계속 돈다). 침묵이 풀리면 준비된 스킬이 0.1초 간격으로 하나씩 나간다 |

### 2.2 속도와 흐름

| 무엇이 바뀌었나 | 플레이어가 느끼는 차이 |
|---|---|
| 스테이지 길이 (CON-02) | 일반 스테이지 8분, 보스 광폭화까지 10분, 1장 1스테이지는 5분. 연습 속도 선택이 생겼다 |
| 조우 문법 (SYS-03) | 처음 45초는 적이 천천히 늘고(0.4배→1배), 그 뒤 압박·숨 고르기·정예 박자로 등장 리듬과 방향이 바뀐다. 숨 고르기에는 보상이 있다 |
| 참을성 있는 줍기 (SYS-09) | 떨어진 보상은 60초(원작 30초) 뒤에 저절로 날아오고 75초(원작 45초)에 정산된다. 잃는 것은 없고, 돌아가며 줍는 쪽이 더 빨리 보상받는다 |
| 난이도 곡선 (SYS-07) | 방어는 일정 비율을 깎은 뒤 비율로 줄이는 혼합식이라 맞는 피해가 늘 1이 되지 않는다(최소 15%). 장마다 적 피해가 7%씩 오르고, 보스 스테이지의 잡몹은 15% 적다 |

| 무엇이 바뀌었나 | 플레이어가 느끼는 차이 |
|---|---|
| 스테이지 목표 (CON-03, D-04) | 일반 스테이지마다 목표(적 구성 변화, 더 많은 등장·지형, 원거리 적, 강해진 필드 보스 등)와 보너스 목표가 있다. 필드 보스 목표는 나타난 뒤 60초 안에 처치해야 센다. 보너스를 채우면 금과 별을 준다 |

## 3. 화면과 접근성

- 섬광 감소: 맞은 적이 반전되어 번쩍이지 않고, 흰 번쩍임과 피격 빛이 절반이 된다. 모션 감소와는 따로 켠다(UI-08). 0.1.0에서 섬광 감소를 켜 둔 저장은 모션 감소도 켠 채로 넘어온다.
- 모션 감소: 맥동, 회전, 흔들림, 튀어오름을 멈춘다. 운영체제의 동작 줄이기 설정을 따른다.
- 이동 키: 설정에서 네 방향 키를 바꾼다. 자판 위치 기준이라 한글 입력 상태에서도 그대로 동작한다. 방향키는 언제나 이동에 쓰인다.
- 화면 모드: 데스크톱 앱에서 창과 전체 화면을 고르고, 다음 실행에도 그대로 열린다.
- 스크린리더: HUD 효과는 시작하거나 끝날 때만 읽힌다.
- 색이 유일한 단서인 곳이 없다: 등급은 ◆ 개수와 이름, 스테이지 상태는 글·인장·점선, 효과는 +·! 표식으로도 구분한다.
- 게임패드로 모든 화면을 조작하고, 프롬프트는 쓰는 장치(키보드, Xbox, PlayStation)의 글리프로 나온다.

## 4. 저장

- 0.1.0의 저장은 첫 실행에 그대로 옮겨진다. 옮기기 전 원본은 백업 파일로 남는다(TEC-15).
- 설정 > 세이브에서 저장을 텍스트로 내보내고 가져올 수 있다.
- 진행 중인 런은 일시정지·종료·강제 종료 뒤에도 이어진다(CON-04).

## 5. 알려진 한계

- 중간 보스(2~5장)와 필드 보스의 그림, 보스 공격·쓰러짐 포즈, 스킬 VFX 대부분은 외주 진행 중이다(D-14). 그동안 벡터 도형으로 그린다.
- 이야기 패널은 킷 조합 임시본이다(D-15).
- 음악은 아직 없다. 효과음과 장별 앰비언스는 합성 v0이다(D-16).
- 한글 웹폰트는 내려받기 허락을 기다린다(D-17). 그동안 시스템 글꼴을 쓴다.
- 캐릭터는 결 한 명이다. 해금 캐릭터 2종은 1.1에서 온다(D-13).

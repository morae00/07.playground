| 도구 | `npm run measure:loudness`(파일), `npm run measure:mix`(게임 믹스 녹음), 측정기 `src/game/audio/loudness.ts` |

## 1. 도구

- `src/game/audio/loudness.ts`: ITU-R BS.1770-4 K-가중(48 kHz에서 표준에 인쇄된 계수와 일치)과 게이팅(−70 LUFS 절대, −10 LU 상대)의 통합 라운드니스, 모멘터리(400 ms)·숏텀(3 s) 최대, EBU Tech 3342 라운드니스 범위(LRA), 4배 오버샘플 트루 피크. 1 kHz 0 dBFS 사인이 모노 −3.01 LUFS, 스테레오 0 LUFS로 읽히는지, −20/−30 LUFS 각 20초가 LRA 10 LU인지 단위 테스트로 확인한다. 게임은 이 모듈을 불러오지 않는다(앱 JS 0 B).
- `npm run measure:loudness [-- 파일·폴더]`: WAV마다 위 값들과, 팩 파일이면 게임이 트는 수준(큐의 재생 이득 × 버스 기본 옵션, 마스터 볼륨 제외)을 표로 낸다. 인자가 없으면 효과음 팩과(있으면) 음악 팩을 잰다. `--json`도 된다.
- `npm run measure:mix`: 개발 빌드를 Chromium에서 돌려 GOD으로 장면을 플레이하고, 믹서의 버스(music, sfx, ui, ambience)를 마스터 볼륨 앞에서, 리미터 출력을 뒤에서 녹음해 잰다. 장면과 길이는 `RECORD_SCENES="1-1:60,3-5:45"`, 녹음 전 플레이는 `RECORD_WARMUP`(초), `RECORD_WAV=1`이면 녹음을 `artifacts/audio/`에 남긴다(무시 대상). 보고서는 `artifacts/audio/mix-report.json`.

## 2. 측정 (기본 옵션: 마스터 0.32, 음악 0.8, 효과음 1)

### 2.1 게임 믹스 (버스별, 마스터 볼륨 앞)

## 3. 읽은 것

1. **앰비언스가 효과음보다 14~18 LU 크다.** 큐 시트가 바란 "효과음 아래의 조용한 바닥"과 반대다. 최종 출력의 대부분이 앰비언스다(최종 통합이 앰비언스 − 9.9 dB, 곧 마스터 0.32 만큼과 일치).
2. **최종 출력이 작다.** 기본 볼륨에서 −33~−36 LUFS이고, 앰비언스를 바닥으로 내리면 효과음만으로 약 −50 LUFS가 된다. PC·콘솔 게임의 흔한 목표(−24~−18 LUFS 통합)보다 15 dB 이상 작다. 플레이어가 볼륨을 올리면 지금은 앰비언스가 함께 올라간다.
3. **음악 시작값 0.12는 효과음 위에 앉는다.** −16 LUFS 스테레오 마스터를 0.12 × 0.8로 틀면 음악 버스 −36.4 LUFS로, 측정한 효과음 흐름(−40 LUFS)보다 4 LU 크다. 큐 시트 §5.1의 의도(효과음 아래)와 어긋난다.
4. 장별 앰비언스 파일 수준이 6.7 LU 차이 난다(ch2 −12.0 ~ ch4 −18.7). 하나의 `AMBIENCE_LEVEL`로는 장마다 바닥 높이가 달라진다.

## 4. 제안 (팀 결정 필요)

### A. 효과음은 두고 앰비언스·음악만 내린다 (코드 상수 두 개)

- 목표: 앰비언스 버스 ≈ 효과음 − 10 LU(−50 LUFS, 스테레오 기준), 음악 버스 ≈ 효과음 − 4 LU(−44 LUFS).
- 장별 앰비언스 수준(`AMBIENCE_LEVELS`, 큐 시트 §5.2가 제안한 형태): ch1 0.019, ch2 0.011, ch3 0.013, ch4 0.024, ch5 0.012(지금 0.3).
- `MUSIC_LEVEL` 0.05(지금 0.12, −16 LUFS 마스터 가정).
- 결과: 기본 볼륨의 최종 출력이 약 −49 LUFS로 더 작아진다. 2번 문제는 그대로 남는다.

### B. 믹스 전체를 올리고 비율을 맞춘다 (권장, 소리 설계 검토 필요)

- 효과음을 약 +16 dB(`SYNTH_PEAK` 0.055 → 약 0.35, 합성음과 샘플 모두), 앰비언스·음악은 A의 비율을 지키며 같은 만큼 올린다(앰비언스 ch1 약 0.12, 음악 약 0.3).
- 마스터 기본값 0.32 → 0.8 안팎. 그러면 기본 볼륨의 최종 출력이 약 −26 LUFS(음악이 들어오면 약 −25)로, 흔한 목표 범위(−24~−18)의 조금 아래에 든다. 버스 합은 효과음 −24.5, 음악 −28.5, 앰비언스 −34.5 LUFS로 어림했다.
- 리미터가 효과음 몰림을 실제로 잡기 시작하므로, 보이스 상한(16)·리미터 설정을 귀로 확인하고 `measure:mix`로 트루 피크(−1 dBTP 아래)를 다시 잰다.
- 기존 세이브의 볼륨 옵션은 그대로라, 업데이트 직후 소리가 크게 바뀐다. 릴리스 노트에 적는다.

### 공통

- 두 안 모두 수준을 바꾼 뒤 `npm run measure:mix`로 다시 재고, 이 문서의 표를 갱신한다.
- 음악 곡이 들어오면 `npm run measure:loudness -- public/assets/packs/music`로 마스터를 검수하고(`music-brief.md` §2.2·§2.3), 장면 녹음에 음악 버스가 함께 잡힌다.
- 측정 장면은 GOD·제자리라 실제 플레이(이동, 줍기, 더 많은 처치)보다 효과음이 적을 수 있다. 효과음 흐름이 2~3 LU 더 클 수 있다는 여유를 두고 정한다.

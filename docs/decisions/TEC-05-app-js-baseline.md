## 1. 맥락

- 정책: 앱 JS는 기준선 대비 +15%에서 경고, +25%에서 빌드 실패다. vendor가 아닌 JS 청크 전부를 gzip으로 합산한다. `index-*.js`, 지연 로드되는 `App-*.js`, 아틀라스 매니페스트 청크가 여기에 들어간다.
- 기준선 이력
  1. 53,565 B: R0 이전, 174eb99.
  2. 60,407 B: R0 마일스톤, 0e53a01. 713d503에서 옮겼고 리뷰가 필요하다.
  3. 75,381 B: 이 기록. R1 중간, b762892.
- b762892의 앱 JS는 75,381 B로, 실패선 75,508 B까지 127 B만 남았다. 다음 항목(SYS-04d 보스 공격 문법·Ch1 무브)을 넣으면 빌드가 실패한다.
- R1 증가분은 계획된 기능이다(§4). 그래서 R1 중간 시점으로 기준선을 옮기고, 항목별 비용을 한곳에 모아 리뷰에 올린다.

## 2. 측정 방법

각 커밋의 트리를 따로 풀어 그 커밋의 `vite.config.ts`로 `vite build`를 돌리고, 그 커밋의 `scripts/check-bundle-budget.mjs`가 보고한 appJs 바이트를 기록했다. 커밋된 보고서가 있는 커밋(713d503, c1b30b9, b762892 등)은 값이 서로 일치한다. vendor JS는 R1 내내 60,279 B로 변하지 않았다.

## 4. 해석

- 합계: +14,974 B(+24.8%). 기능으로 +18,428 B가 늘었고, 절감 두 건으로 −3,454 B가 줄었다.
- 큰 항목 네 가지(TEC-03, TEC-14, SYS-02, TEC-12)가 증가분의 60%다.
  - TEC-03 스프라이트 +3.6 KB: 아틀라스 로더와 캐릭터 스프라이트 경로.
  - TEC-14 오류 복원력 +3.4 KB: 부팅 가드, 복구 화면, 오류 로그. Vite의 동적 import 프리로드 도우미 약 0.8 KB가 포함된다.
  - SYS-02 역할 행동 +2.5 KB.
  - TEC-12 레이어 계약 +1.4 KB.
- 이미 적용한 절감: 빌드 타깃 ES2022(−1.1 KB), 빌드에서 로드 시 콘텐츠 검증 제외(−2.3 KB).

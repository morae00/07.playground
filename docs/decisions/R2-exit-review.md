### 1.2 골든

- 15d7c9d의 개발자 빌드로 조합 128개(뷰포트 4 × DPR 2 × 모션 2 × 상태 8)를 캡처했다. 합계 132 MB다.
- 같은 빌드로 한 번 더 돌려 그 골든과 비교했다. 128/128이 통과했다.
  - 차이가 있는 캡처는 8장이다. 가장 큰 것은 1024×720 정산 화면의 0.27%다(허용치 0.5%, 화소 허용 24).
  - 원인은 대화상자의 입력 가드 막대다. CSS 애니메이션이 멈춰 둔 페이지 시계와 상관없이 실제 시간으로 돈다. 나머지 7장은 레벨업 배너의 글자 몇 화소다.
- 캡처를 화소까지 같게 만들려고 두 가지를 시험했다.
  - 캡처 직전에 애니메이션을 끝 상태로 고정했다.
  - DOM 변경과 네트워크 요청이 멈출 때까지 기다렸다.
  - 기다리는 동안 React가 보스 칭호 카드를 띄우기도 해서 차이가 9%까지 커졌다. 그래서 되돌렸다.
- 저장소에 넣을지는 팀이 정한다(§4). 132 MB이므로 git LFS나 별도 저장소가 필요하다.
- 재생성 방법은 §5에 있다.

## 2. R2 끝 밸런스

- 기준선은 3c94023에 있다(3d0c5d3에서 측정, 지문 fa29bc029e7815cd). 클리어율은 R1 끝 41.1%에서 42.0%가 됐다.
- 챕터 곡선은 여전히 거꾸로다(Ch1 30%, Ch5 82%). SYS-07(R3)이 맡는다.
- 보스전이 길어졌다. 클리어 시간 p50이 222초에서 251초가 됐다. 2~5챕터 최종 보스가 무브를 쓰기 때문이다.
- 재측정에서 R2 결함 하나가 드러났다. 고정(anchor) 이동 보스를 피하면 전투가 끝나지 않았다.
  - 1ad7113에서 고쳤다. 플레이어가 720 밖으로 나가면 보스가 따라가서 다시 자리를 잡고, 광폭화하면 고정이 풀린다.
  - 해당 3개 Stage 파일럿에서 달라진 것은 그 교착 1건뿐이었다. 5-10의 가장 긴 클리어는 805초에서 445초로 줄었다.
- 남은 시간 초과는 2건이다. 둘 다 survivor 페르소나가 위쪽 가장자리에 붙은 경우다. 가까운 무리를 먼저 쏘는 자동 조준 때문에 보스를 치지 못한다(**[팀]** §4).

## 2. R3 끝 밸런스

- c63b996에 기준선이 있다(3171af0에서 측정). 클리어율은 R2 끝 42.0%에서 29.2%가 됐다.
- 뒤집힌 챕터 곡선이 펴졌다. 페르소나 3종의 챕터별 클리어율은 30 / 47 / 30 / 40 / 47%다. R2 끝에는 30 / 50 / 48 / 70 / 82%였다.
- 종료 조건 3의 네 목표를 모두 만족한다.

| 목표 | 기준 | R3 끝 |
|---|---|---|
| 인접 챕터 간 일반 스테이지 클리어율 차이 | ±25%p | +15.4 / −13.7 / +5.8 / +3.8%p (30.0 / 45.4 / 31.7 / 37.5 / 41.2%) |
| 1 피해 판정 비율 | 20% 이하 | 0.1% (160,066회 중) |
| max 메타 Ch5 최저 HP 중앙값 | 70% 이하 | 54% (Ch5 10스테이지 × 10시드, 클리어 72%) |
| 신규 메타 1-1 클리어 | 40~70% | novice 50% (20시드). 고정 사각 보행인 fresh는 500판 중 1판 |

- 시간 초과는 1건이다. 이미 알려진 survivor의 위쪽 가장자리 고착이다(5-10, 보스 체력 98%). R2의 5-10 striker 교착은 1ad7113 뒤로 사라졌다.
- 스테이지 단위로는 챕터 평균보다 크게 떨어지는 곳이 있다(QUALITY_GATES "Balance"의 A/B 표).
  - 4-3(거인 목표, 랜드마크): 3%. 스테이지 목표를 끄면 40%다. 대형 15%p 증가가 Ch4의 방패 수문장(SYS-02)과 랜드마크 장애물에 겹친다.
  - 3-9, 4-8(덫 목표): 7%, 13%. 4-8은 난이도 곡선을 끄면 43%다.
  - 5-7(덫 목표, 갈라진 개기): maxed 10%. 지형이 두 배가 되고 5장의 무음 지대는 속도 42%의 감속 지대가 되어, 시작부터 감속 27곳과 불 13곳이 가장 빽빽한 랜드마크의 장애물 39개 사이에 깔린다.
  - 조정안: Ch3부터 거인의 비율 변화를 줄이기, 랜드마크 스테이지에는 거인·덫을 두지 않기, 감속 지형이 있는 챕터의 덫 배수 낮추기 **[팀]**.

## 3. App JS 예산

- 102,366 B(3171af0)다. R3 중간 기준선 92,420 B 대비 +10.8%로, 경고선 106,282 B까지 3,916 B, 실패선 115,525 B까지 13,159 B가 남았다.
- R3 항목별 증가는 TEC-05 결정 기록 §8 표에 있다. 새 콘텐츠 표와 문구(목표, 빌드 깊이, 도감, 업적, 코스메틱, 정예, 이야기)는 앱 JS가 아니라 JSON 데이터다.
- TEC-05 [확인] 6(R3 종료 때 다시 측정해 출시 기준선으로 확정)은 팀이 정한다. 이 측정값을 출시 기준선으로 쓸지, terser([확인] 3)를 먼저 넣을지 함께 본다.

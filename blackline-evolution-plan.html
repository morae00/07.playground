Executive brief

현재 프로토타입은 “완성된 게임 한 판”의 폭은 갖췄지만, 대규모 그래픽 개선을 바로 얹기에는 로직 결합도와 회귀 위험이 높습니다. 첫 2주는 버그 수정과 엔진 기반 정리, 이후 시각·콘텐츠 고도화를 병렬화하는 순서가 가장 효율적입니다.

핵심 판단
리디자인부터 시작하지 않습니다. P0 게임 결함, 결정론적 시뮬레이션, 입력·저장·테스트 경계를 먼저 고정해야 그래픽 개선이 플레이 감각을 망가뜨리지 않습니다.

고대비 흑백 먹선

02 / CORE LOOP

이동 + 자동공격 생존

입력 부담이 낮고 빌드 선택이 중심인 생존전의 즉시성은 그대로 둡니다.

03 / IMPACT

짧고 강한 타격감

히트스톱, 흔들림, 파편의 감각은 유지하되 판독성과 접근성 모드를 분리합니다.

01

Current evidence

현재 화면은 브랜드의 원형을 이미 보여줍니다. 문제는 스타일의 부재가 아니라, 모든 요소가 같은 강도로 말하고 있다는 점입니다.

Keep

2px 검정선, 각진 박스, 하드 섀도, 인쇄물 질감, 패턴 기반 희귀도, 큰 제목.

Amplify

챕터별 공간 문법, 플레이어 실루엣, 공격 예고 단계, 보스 연출, 수치 변화 피드백.

Replace

모든 패널의 동일한 강조, 플레이 중 상시 설정 노출, 모바일 최소 캔버스 강제, 불투명도만으로 표현한 잠금.

05

Experience design

핵심 흐름은 더 짧게, 정보는 필요할 때 더 깊게 보여줍니다. 메뉴는 선택과 비교, 전투 화면은 생존과 위험 판독에만 집중합니다.

메뉴 / Stage 선택

Chapter rail → Stage map → Loadout summary → Start챕터 카드와 10개 트리를 한 흐름으로 합치고, 시작 버튼은 하단 sticky action bar로 유지합니다. 기본 스펙은 핵심 5개만 노출하고 상세는 펼침으로 전환합니다.

전투 / HUD

Survival → Threat → Build상단은 HP·레벨 / 시간·보스 / 즉시 명령의 3구역으로 축소합니다. 코인·킬·적은 한 줄, 설정은 아이콘 버튼, 나머지는 탭 drawer로 이동합니다.

Draft / 선택

비교 가능한 숫자와 변화량현재→다음 수치, 역할 태그, 시너지 1줄을 먼저 보여줍니다. 각성은 실루엣과 테두리 단계로 명확히 분리하고 키보드 1~4 선택을 지원합니다.

모바일 / Touch

상단 1줄 + 하단 drawer실제 ResizeObserver 크기와 logical viewport를 일치시키고 safe-area를 적용합니다. 이동 영역과 UI hit target을 분리하며 최소 터치 타깃은 44px입니다.

09

First sprint

첫 5영업일의 목표는 화면을 바꾸는 것이 아니라, 이후 모든 화면 변경을 안전하게 만드는 것입니다.

Vitest + deterministic clock/RNG 도입실행 결과를 seed로 재현할 수 있게 합니다.
P0 재현 테스트 먼저 작성shock, reward race, vortex, pierce, dead entity를 실패 상태로 고정합니다.
Run FSM과 이벤트 큐 추출draft/settlement/gameOver 전환을 하나의 원자적 흐름으로 만듭니다.
Fixed timestep + swept collision배속과 FPS에 무관한 전투 결과를 확보합니다.
입력·timer·audio 수명 정리폼 입력 격리, blur clear, dispose 취소를 구현합니다.
Versioned save schema검증, migration, clamp, 손상 복구 경로를 만듭니다.
성능 측정 HUD와 soak harnessFPS, frame time, entity, pickup, heap 기준선을 수집합니다.
디자인 토큰 1차 확정paper/ink/gray, border, shadow, type, spacing을 변수화합니다.
HUD 정보 우선순위 wireframesurvival/threat/build 3구역과 drawer 구조를 검증합니다.
Release metadata backlog 생성appId, icon, CSP, scheme allowlist, signing/notarization을 추적합니다.

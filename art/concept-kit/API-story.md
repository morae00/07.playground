# API — `k-story.js` · `PN.story` v1.0 (K6 3차: 검수 2차 수정분 반영)

이야기 패널 6장(D-15 (b))의 SVG 문자열 생성기다. 대상은 prologue-1~4, ending-2, ending-4이고, 나머지 14장은 기존 킷 합성(`art/ui-art-spec.mjs` `STORY_PANELS`)을 그대로 쓴다.
지시서는 `docs/art/briefs/story-panels.md`(B4, §12 검수 1차 정정, §13 검수 2차 정정 포함)다. 기준은 스타일 바이블 §2.2·§3·§4·§5·§6·§9·§10.1·§15, R4 얼굴 리뷰 §2.1·§2.5, API-hero v2.1 §1·§1.1이다.

> **상태(2026-10-16).** 1차(부품·연구·명도 러프) → 2차(검수 1차 A1~A9·B1~B11, 배경 세부, 비백, 종이결 옵션, C1~C13) → 3차(검수 2차 M1~M5, 권장 R1·R2·R5). 3차에서 바뀐 것: P3 선반 판·묶음 배치(M1), P4 담 갓돌 높이 1.0 m(M2), P1·P2 뒷벽 기둥·벽 칸·붓걸이 자리(M3), E2 공백 가장자리 세 점(M4), 종이결 크기와 α(M5), E4 지평선으로 오르는 먹선의 꺾임과 마른 끝(R1), E4 안개 단 윗변(R2). 잠정 아트다(바이블 §15). 사람 원화가 할 일은 맨 끝 '사람 클린업 목록'에 있다.

## 머리-배경 규칙 (지시서 §13-3)
결과 스승의 머리 실루엣(머리채, 탕건, 흑립, 옆얼굴 윤곽)과 배경의 먹 띠(기둥, 선반 판, 담 갓돌, 처마, 붓걸이, 선반 묶음의 윗변)는 서로 닿거나 나란히 붙지 않는다. 띠가 머리 뒤를 지나야 하면 실루엣에서 12 px(1배) 넘게 떨어진 높이로 지나거나 앞의 코트·목도리 뒤로 숨긴다. 비스듬히 가로지르는 것은 괜찮다. 명도 차가 작은 면 경계(벽 칸, 안개 단)에는 권장이다. 이 모듈의 배치:

| 패널 | 머리 | 피한 방법 |
|---|---|---|
| P1·P2 | 결 뒷머리(P1 x 345~415, P2 437~507), 스승 탕건(P1 885~945, P2 760~870 망점 테 포함) | 뒷벽 기둥을 원고장 오른쪽 끝(X −600, x ≈ 561~576, 장 윗면 아래는 장이 가림)과 문 쪽 모서리(X 549, x ≈ 985~1000)로 옮김. 벽 칸 경계도 X −600을 따름. 붓걸이를 X −480~−220(x ≈ 613~709)으로 옮기고 붓 5자루의 끝을 y ≤ 262에 둠 → 모든 머리에서 25 px 넘게, P2 두 손 틈(635~700, 300~345)에서 30 px 넘게 위 |
| P3 | 흑립 챙 아래 얼굴(y 70~215)과 목도리 위아래 변(y ≈ 196, 262) | y 58~278에는 먹 판도 묶음 윗변도 없음. 그 높이는 깊은 그늘(ink3)의 키 큰 칸 하나이고 머리 뒤(x 90~480)는 빈 선반. 판은 y 292·410 |

## 로드 순서와 의존
```html
<script src="kit/lib.js"></script>        <!-- PN.taper, PN.rng -->
<script src="kit/k-hero.js"></script>     <!-- PN._hk, PN.heroKit -->
<script src="kit/k-enemies.js"></script>  <!-- PN.enemies (1장 art LOD) -->
<script src="kit/k-env.js"></script>      <!-- PN.env 도우미 -->
<script src="kit/k-story.js"></script>    <!-- window.PN.story -->
```
- 다른 모듈은 **함수를 부를 때만** 읽는다. 로드할 때 계산하는 META도 순수 계산(`rng`)뿐이라 다른 모듈의 id 카운터와 출력이 바뀌지 않는다(C12 `hero=1mssadj len=1095256 enemies1=t520u1 len=125079 env15=u5ixvn len=223097` 그대로).
- 읽기만 하는 것:
  - `PN._hk`: `Ctx`, `side`, `frame`, `ORDER`, `head34`, `neck34`, `hat34`, `scarfWrap`, `scarfTails`, `pony`, `arm`, `hand`, `foot`, `limbPath`, `crescent`, `rim`, `contourStrokes`, `coatPart`, `hemLine`, `V`
  - `PN.enemies`: `draw(1, role, {lod:'art', halo:false, shadow:false})`, `meta(1, role)`
  - `PN.env`: `ctx`, `poster`, `voronoi`, `rectSlabs`(정정 §12-6), `grainDef`(종이결 옵션)
  - `PN.taper`(lib)
- 쓰지 않는 것: `PN._hk.needle()`(발광이 들어간 비행 바늘), `PN._hk.bandolier()`(대신 같은 끝점·고리 위치·바늘 방향을 따르는 `strapBelt`), `Math.random`, `<text>`·`<image>`·`<foreignObject>`·`<style>`, 외부 참조.
- id: 호출마다 `kst<n>_` 접두를 쓰고 되감지 않는다. 결·스승·환경 부품은 각 모듈의 `Ctx`(`hk<n>_`)·`ctx`(`ev…_`)가 고유성을 지킨다.

## 호출
```
PN.story.ids            → ['prologue-1','prologue-2','prologue-3','prologue-4','ending-2','ending-4']
PN.story.SIZE           → [1200, 675]
PN.story.panel(id, opts) → '<g class="pn-story" data-id="…"><defs>…</defs>…</g>'   // 1200×675 로컬 박스
PN.story.META[id]       → 아래 META 표
PN.story.sheet(opts)    → 검토용: 6장 0.4배, 1줄 P1 P2 P3 / 2줄 P4 E2 E4, 간격 16 → 1472×556
PN.story.strip(which, opts) → 검토용: 'prologue'(4장) | 'ending'(2장) 이야기 순서 한 줄, 0.25배, 간격 12
PN.story.partsSheet()   → 검토용 1200×760: §2 부품 견본
PN.story.studies()      → 검토용 1600×860: 결 머리, 모자 벗은 뒷머리, 스승 두 모습
PN.story.version        → '1.0'
```

| opts | 기본 | 뜻 |
|---|---|---|
| `guides` | `false` | 검토 오버레이(색 `#E83E8C` 한 가지, `pointer-events="none"`): 3분할선, 24 px 바깥 여백, 자막 예비 띠(y 585~675), 지평선, 소실점(원 + 십자), 후퇴선과 소실점까지의 연장 점선(META `recede`), 초점 원(첫째 굵게), 시선 흐름(화살표 점선) |
| `layer` | `'all'` | `'bg'`·`'mid'`·`'fig'`·`'fx'` 중 한 층만 그린다. 모르는 층 이름은 오류 |
| `grain` | `false` | 종이결(바이블 §6-8 키아트 예외, 지시서 §1.7·§13-4). 배경 층에만 `PN.env.grainDef(gid, 4, 0.36)` 반점을 불투명도 0.055로 얹는다. 합성 패널의 결(`PN.env.landmark`: 480×270 단위에 주파수 0.9, α 0.055 → 굽기에서 알갱이 ≈ 2.5 px)과 같은 크기다(1200×675 박스에서 0.9 / 2.5 = 0.36). 인물·얼굴·바늘·공백·여백(E4의 x > 1080) 위에는 없다. `pointer-events="none"`이라 C7 표본에 잡히지 않는다. **켤지는 메인 세션이 정한다**: 여섯 장을 모두 결을 켜고 구워 장당 400 KiB 이하일 때만 `STORY_PANELS` 여섯 키에 `grain: true`(섞지 않는다) |

- 모르는 id: `throw new Error('story: unknown panel <id>')`.
- `sheet`·`strip`·`partsSheet`·`studies`는 각 칸을 `<pattern>` 타일로 채운 사각형으로 그린다. 그래서 패널 밖으로 뻗은 도형이 렌더 경계를 넓히지 않는다(굽기는 `panel()`만 쓰므로 영향 없음).

## 공용 문법 (§2, `partsSheet`가 보여 준다)
| 부품 | 함수(내부) | 규칙 |
|---|---|---|
| 바늘 | `needle(eye, tip, w, {state, fill, thread})` | 종이 몸통 + 먹 외곽, 끝 30% 먹, 뒤쪽 청록 바늘귀(먹 테 + 청록 + allyG 심), 이름 새김 띠 = 귀 쪽에서 22~48%, 폭 = 몸통의 60%. `named`: 굵기가 조금 흔들리는 먹 한 획 / `empty`: p300 홈 + 먹 테, 테 3곳이 끊김, 안은 빔 / `filling`: 귀 쪽부터 68%까지 먹, 앞 끝은 둥글게. 발광 없음 |
| 탄띠 | `kitStrap(P)` + `strapBelt(a, b, sw, T, items)` | **킷과 같은 끈**(검수 1차 A1): 먼 어깨 `frame(P).at(0.04, 26)` → 가까운 엉덩이 `.at(0.9, −27)`, 고리 t 0.14·0.30·0.46·0.62·0.78, 바늘은 끈 법선 바깥쪽에서 14° 돌려 귀를 바깥 끝에(`k-hero.js:634-637`). 먹 끈 + 종이 고리, 고리 띠를 바늘 위에 그린다 |
| 실·땀 | `thread()`, `stitches(x0, x1, y0, y1)` | 실 = 먹 5 · 청록 2.8 · allyG 0.9(킷 비율). 땀 = 경계를 넘는 비스듬한 고리 하나, 35~50°, 길이 34~42, 간격 40±6(고르지 않게), 양 끝에 바늘 구멍 먹 자국. X·십자·점선 없음 |
| 매듭 | `knot(x, y, s)` | 8자 매듭(B2): 실 샌드위치의 고리 둘이 허리에서 위·아래로 엇갈리고(이음매는 겹침 밑에 숨김), 실 끝 2가닥이 아래로 늘어진다. 1배 ≈ 20 × 34 px |
| 공백 | `voidEdge(c, edge, {close})` | p50 평면, 외곽선 없음. 전이띠 14~30 px(가장자리 법선 방향): 평면 → 종이 망점 42% → 20% → 없음(마스크). 먹 조각 3~12 px가 0~60 px 안에서 작아지며 흩어짐. 장면은 clipPath로 자르므로 공백 안에는 칠이 남지 않는다. 소실점 공백(P4)은 같은 문법의 닫힌 자리(`p4Void`) |
| 마른 선 끝 | `dryTail()`, `dryStroke()` | 공백으로 들어가는 선은 가닥으로 갈라지며 마르다 끊긴다(비백). P2 보·벽 밑선·바닥 이음, P3 선반 윗틀·윗판, P4 골목 선 넷 |
| 끊긴 선 | `bandBreak`(P4 안) | 처마·배수로·담 갓돌·담 밑단의 띠가 한 구간 지워지고 양쪽 끝이 가닥으로 마른다(4곳 이상, B8) |

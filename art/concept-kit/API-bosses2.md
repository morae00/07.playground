## 로컬 박스 · 피벗 · 표시 크기 (세 보스 공통)
| 항목 | 값 (로컬 단위) | 비고 |
|---|---|---|
| 로컬 박스 | **384 × 384** | bible §7.3 중간·최종 보스 원화 셀 @2x |
| **pivot (판정 원 중심)** | **(192, 252)** | 판정 r54@1x = **r108** 로컬 |
| feet (발 = 판정 원 하단) | (192, 360) | 치마·바퀴·로브 하단 윤곽은 끊지 않는다 |
| 발밑 그림자 = 판정 표시 | 중심 (192, 311), rx 108, ry 44 | pivot + 0.55r, 폭 = 판정 지름 |
| 실루엣 세로 범위 | empress 30→360 · herald 30→360 · balance **10→360** | balance는 저울대가 머리 공백 위로 떠 있어야 해서 가장 높다(시각 전용 돌출) |
| **인게임 표시** | `scale(0.5)` → **156px** (1x) | `detail:'game'`과 함께 쓴다 |
| 시트 일러스트 | `scale(1.36~1.45)` → 약 480~500px | `detail:'art'` (기본값) |
| 48px 실루엣 | `scale(0.154)` + `mono:true` | k-bosses1(`scale 0.123`)과 같은 156→48 비율 |

- 기본 방향은 **오른쪽(3/4 정면)**이다. 반전은 `translate(2*pivotX, 0) scale(-1, 1)`. **몸은 자전하지 않는다.** 도는 것은 바퀴·톱니(`spin`)와 천칭 대(`windup` 기울기)뿐이다.
- 배치: `<g transform="translate(x - 192*k, y - 360*k) scale(k)">…</g>`는 발(feet)을 (x, y)에 둔다. 판정 원 중심에 맞출 때는 `y - 252*k`.
- 시각 돌출: 천칭 대(x 128~352), 먹 접시 오른쪽 끝 x≈385, 전령 나팔 종구(idle x≈345, windup y≈5), 여제 베일(x≈40). 아틀라스 셀은 위로 약 40u, 오른쪽으로 약 8u 여유를 둔다.

## `PN.bossesB.draw(id, opts) → string`
`<g class="kb2 kb2-{id}">`를 돌려주고, 그 안에 호출마다 고유 id의 `<defs>`가 들어간다(접두사 `kb2_{n}_`). 144개 변형(3 id × art/game × 페이즈 3 × windup × enraged × mono)에서 중복 id 0건, 끊긴 `url(#…)`·`href` 참조 0건을 확인했다.

| opt | 기본값 | 의미 |
|---|---|---|
| `phase` | `1` | `1` 기본. `2`(66%): **굵은 종이색 균열**(paper.100, game 6.4u = 1x 3.2px, 길이 ≥50u) + 페이즈 표식 1개. `3`(33%): 블랙 스팟이 흘러내리고 코어가 드러남. 아래 표 참고 |
| `windup` | `false` | 준비 자세(텔레그래프 1단계) + 호박 '!'. 아래 표 참고 |
| `enraged` | `false` | 먹 불꽃(검은 불 + 종이 심), 백열 눈, **바깥 윤곽에만 산호 펄스 2px**(먹 링으로 샌드위치). 투명 구멍·바퀴 살 틈·후광 안쪽·부채 칼라 틈·천칭 사슬에는 펄스가 돌지 않는다 |
| `detail` | `'art'` | `'art'`: 비백, 거친 먹선 필터, 망점 피치 4.4. `'game'`: 외곽선 ×2.5, 내부선 ×1.8, 망점 피치 **6u = 3px@1x**, 미세 디테일 제거, 공백 접시 테는 고정 7.4u(속이 열려 보이게) |
| `halo` | 챕터 base | 녹아웃 헤일로 색(§5-6). `false`면 끈다. empress `#ADB4AA`, herald `#BBAE94`, balance `#ABA5AC` |
| `mono` | `false` | 단색 먹 실루엣(48px 색 제거 테스트). 투명 구멍은 구멍으로 남는다 |
| `monoColor` | `ink` | 실루엣 색 |
| `spin` | `0` | herald 바퀴·후광 톱니 회전(도) |
| `shadow` | `true` | 발밑 그림자 타원(판정 폭) |
| `hitbox` | `false` | 판정 원 오버레이(점선 r108 + pivot 십자 + feet 점). §16.2 제출용 |

### rev 3 얼굴 (K3-1, 입체파 얼굴을 피하는 규칙)
얼굴은 각도 하나에 맞춘다. 두 눈은 같은 평면·같은 기울기에 두고, 크기·높이 차이로 원근을 흉내 내지 않는다. 얼굴 밖에 "원 + 가운데 점", "고리 + 원판", "점 두 개 나란히"를 두지 않는다.

**여제 눈(F-B1, 사용자 결정 Q4 정정판).** 좌표는 머리 템플릿 기준(`rotate(9 190 132)`을 걸기 전).

| 요소 | 값 |
|---|---|
| 두 눈 | 같은 크기, 같은 높이. 중심 (185, 99)·(201, 99). 눈선이 얼굴 축에 수직이다(머리 좌표 Δy 0) |
| 눈 모양 | 먹 타원 rx 6.0 · ry 4.6(game) / rx 5.8 · ry 4.4(art) |
| 종이 고리 | 같은 중심에서 (0, +0.08ry) 내린 타원, 크기 ×0.6, paper.50 획 game 2.0(1x 1px) / art 1.4. 눈 모양으로 clip |
| 윗눈꺼풀 | 눈 clip 안의 먹 뚜껑. 아래 경계는 (cx, cy − 0.15ry)를 지나는 직선이고, 코 쪽 끝이 0.35ry 낮고 바깥 끝이 0.35ry 높다: 엄한 반쯤 감은 눈 |
| 동공·하이라이트 | 따로 그리지 않는다. 고리 안의 먹이 동공이다. **흰 점 0** |
| 광폭 | `eyeBubble(…, hot, false)`를 두 중심에 같은 크기(r = 눈 rx: game 6.0 / art 5.8)로. 후광은 두 눈이 **하나**를 나눠 쓴다: `<g opacity="0.35">` 안에 (185,99)·(201,99) r = rx × 2.1 paper.50 원 두 개(K3-1f R5. 따로 그린 두 후광은 겹친 곳이 밝은 렌즈가 되어 "고글"로 읽혔다) |
| 눈물 | 왼눈 바깥 아래 (180.5, 104)에서 아래로 `taper` 'end'(폭 art 2 / game 2.4), 끝 방울 (180.4, 113.8) r 1.6 / 2.0. 길이 ≤ 12, 정중선 x 193에서 12 떨어짐 |

| 기포 | game 기포 고리(182,81) 삭제(눈 고리와 같은 도형이라 세 번째 눈이 된다). art 기포 3개는 눈에서 4 이상: (181,83) r2.4 · (185,76) r1.6 · (203.5,88) r1.9(rev 2의 (207,91)은 오른눈에서 2.7이라 옮겼다) |
| art 이중 테 | rev 2 art 눈의 바깥 0.9 고리(r + 2.4)는 없앴다. 눈 + 고리 + 바깥 고리가 겹고리 눈알로 읽힌다 |

### 공백 천칭의 투명 컷아웃 (P1 5곳 · P3 7곳)
`<mask>`로 뚫은 **진짜 투명 영역**이며, 뒤의 바닥이 그대로 보인다.
1. **머리 자리**: 가위 컷이 두건 정수리(y 72)보다 위(y≈54)까지 올라가서 **실루엣 윗선 자체를 끊는다.** 두건은 왼쪽 뒷자락 조각과 오른쪽 가는 조각만 남는다. 저울대는 PIV y 40으로 떠 있어서 공백을 다시 닫지 않는다.
2. 공백 접시(뒤의 몸까지 지움)
3. 로브 **왼쪽 윤곽을 가로지르는** 찢긴 띠(y≈317~337)
4. 가까운 종 소매를 가로질러 **오른쪽 윤곽까지** 끊는 띠
5. 로브 중앙의 지운 자국

P3에서는 가슴과 먼 소매 한 입이 더해진다.
- **먹테 규칙**: 테는 굵은 먹(art 4~5.6u, game ×2.5)으로 그리고, 몸의 원래 알파로 마스크한다(`rims`). 그래서 컷이 바깥 윤곽을 넘는 곳에서는 바닥 위에 먹선이 그려지지 않는다. 안쪽 종이 절단선은 없앴고, art에서만 1u ink300 선이 남는다.
- 눈가림 끝자락은 `over` 층에 둔다. 지워지지 않고 떠 있으며, 망점 없는 평면 paper.300 + 먹 테다(§5-4).

### 레이어 모델 (`B.parts[id]`가 돌려주는 것 — 새 보스를 추가할 때 참고)
`under`(바닥 FX) · `back`+`fig`(몸 = raw) · `holes`(투명 마스크) · `rims`(raw 알파로 마스크) · `over`(지워지지 않는 소품: 공백 접시 테·사슬·눈가림·광폭 불꽃) · `solid`(광폭 펄스용 채움 실루엣에만 더하는 경로) · `front`('!'·음파).
광폭 펄스는 "잘린 몸을 dilate한 것 − (raw + solid) 채움 실루엣"이다.

## `PN.bossesB.fx.*` — 시그니처 공격 (호출한 쪽 좌표계, **1x 화면 px** 기준 선 굵기)
| 함수 | 설명 |
|---|---|
| `saw(x, y, r=15, {rot, tail:[dx,dy], noGlow})` | 적 톱니탄(§12.4). 먹 톱니 코어 + **산호 날끝** + 먹 외곽 + 종이 광점, `tail` 방향으로 먹 속도선. 표시 지름 2r ≥ 30px |
| `gridTrap(x, y, cell, cols, rows, {state, progress})` | 여제의 격자 속박 덫. `state`는 문자열이거나 `(col,row) => 'preview'|'imminent'|'active'|null`. preview는 호박 해칭 피치 10과 2px 점선 테, imminent는 피치 5, 5px 테, 호박 눈금, active는 산호 α0.55 + 먹 망점 테. 칸마다 **걸쇠 기호**(원형인 설계자 덫과 구분). `progress<1`이면 붓 머리가 창살을 그려 나간다 |
| `nullZone(x, y, r, {state, progress, squash})` | 천칭의 짝 null 지대. `void.paper` 평면 + 먹 밑선 5.4px + **호박 점선 테 3px(round cap, 대시 3/6) — 모든 상태에서 점선**. 진행률은 `<mask>` 속 실선 호로 드러낸다. active는 안쪽에 먹 3px + **산호 1.5px** 링을 더한다. ⊘ 기호 |
| `lane(x0, y0, x1, y1, w, {state, progress})` | 적 해칭 레인(톱니 궤도 예고). preview/imminent |
| `brushHead(x, y, angleRad, s)` | "붓이 그려 나가는 예고"의 붓 머리 |
| `exclaim(x, y, s)` | 호박 '!'(먹 + 호박 + 종이 심 샌드위치) |
| `hatchDefs(prefix)` | 호박 해칭 10/5 + 먹 망점 패턴 defs |

## 토큰 · 기타
- `PN.bossesB.K`: `ink #0E0E10`, `ink700 #2B2926`, `ink500 #46423D`, `ink300 #8C8579`, `paper50/paper/paper300`, `voidPaper #E2DBCB`, 신호색 5종, `ch3/ch4/ch5 {light, base, deep, spot}`(bible §3.3).
- 신호색 소속: 보스 몸에 신호색은 없다. 예외는 광폭화 산호 외곽 펄스와 준비 자세 호박 '!'뿐이다. 톱니탄 날끝과 판정 채움은 산호다. 청록과 자수정은 이 모듈에 나오지 않는다(시트 인셋의 침묵 아이콘 청록 테는 **플레이어 상태 표시**라 시트 쪽 코드).
- 블랙 스팟 설계(§5-2): 보스마다 좌상단 ink500 명부는 쐐기·초승달 2~3개만 쓰고, 우하단은 ink900으로 비운다. 여제 치마 초승달·보디스 쐐기, 전령 망토 지그재그 3개, 천칭 로브 휘는 쐐기 2개가 그 예다. 펄럭이는 천(베일·망토·깃발·눈가림)에는 망점이 없다.
- `PN.bossesB.BOX`, `CH`, `ids`, `_`(내부 헬퍼: `ctx`, `gearPath`, `latch`, `dry`, `drip`, `crack`, **`pcrack`**(P2 굵은 균열), `flame`, eye 3종 등), `_emp`/`_her`/`_bal`(보스별 형상 상수)을 제공한다.
- rev 3: `_.eyeEclipse(X, x, y, r, hot = false, core = 0.1)` — 끝에 선택 인자 `core`(코어의 +x 오프셋, r 비율)를 더했다. 생략하면 rev 2와 같은 출력이다. 천칭만 0.22를 넘긴다.
- K3-1f: `_.eyeBubble(X, x, y, r, hot = false, glow = true)` — 끝에 선택 인자 `glow`를 더했다. `false`면 hot 후광 원(r × 2.1, α 0.35)을 그리지 않고 호출부에 맡긴다. 생략하면 이전과 같은 출력이다. 여제 광폭만 `false`를 넘긴다.
- 크기: 한 번 호출한 결과는 art 53~66KB, game 42~47KB. 인게임에서는 bible §7.2에 따라 **로드할 때 1회 ImageBitmap으로 굽고** 1:1 blit한다. 필터(거친 먹선·헤일로·dilate 펄스)는 매 프레임 SVG 렌더링용이 아니다.

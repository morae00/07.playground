# API — k-bosses3.js · `window.PN.bossesC`

2~5장 중간 보스(St5) 4종. 작업 지시서 K1(`docs/art/briefs/bossesC.md`)의 산출물이며, 모든 함수는 **SVG 마크업 문자열**을 돌려준다.
호출 형식은 `PN.bossesB`와 같다(`draw(id, opts)`, `anchors(id, opts)`, 옵션 이름 공통). 새로 더한 것은 `pose`·`frame`·`move`·`clone` 옵션, `cut` 레이어(5장 좁은 투명 틈)와 그 보조 `cutKeep`·`cutT`·`solidT`, `META`다.

> 검수 1차·2차(2026-10-02~03, `docs/art/deliveries/K1-bossesC.md`) 반영본. 1차 F1~F9, R1·R4~R8과 2차 §5(폭군 원판↔다리 틈)를 고쳤다. 바뀐 값은 각 절에 적었고, 검수 항목 밖에서 바뀐 출력은 맨 아래 "개정 기록"에 모았다. 미룬 R2·R3·R10은 K5def(2026-10-27)에서 반영했고, R9(원장 대기 muzzle)도 메인 세션 결정에 따라 자 위 끝 [130,136]으로 반영했다(개정 기록 K5def).

| id (`BossBody`) | 게임 id | 이름 · 칭호 | 장 · 스테이지 · 패턴 | 상징 소품 = 발사원 | 얼굴 = 약점(초점) |
|---|---|---|---|---|---|
| `'bishop'` | `s2-mid-clones` | 유리 주교 · 거울 설교의 주교 | 2장 St5 · clones | 거울 지팡이(머리 = 어두운 유리 거울) | 금 간 거울(종이 면) + 충격점 눈 둘(먹 별 소켓 + 종이백 눈빛) |
| `'tide-king'` | `s3-mid-tide` | 무채 조수왕 · 색을 씻는 조수왕 | 3장 St5 · tide | 우산 삼지창(갓의 갈빗대 끝 5개, 미늘 창끝 3개) | 입체 머리의 기포 눈 둘 + 무채로 씻긴 주둥이 면 |
| `'tyrant'` | `s4-mid-clock` | 시계 폭군 · 멈춘 시간의 폭군 | 4장 St5 · clock | 등의 시계탑 문자판(12발) · 진자 대검 | 문자판 머리(종이 면) + 태엽 구멍 눈 둘, 콧수염 = 바늘 |
| `'director'` | `s5-mid-eclipse` | 일식 원장 · 일식 극장의 원장 | 5장 St5 · eclipse | 긴 자(오선 7줄, 다섯째 비움) · 지휘봉 · 일식 광배 | 초승 가면(종이 면) + 일식 고리 눈 하나 |

## 불러오는 순서
```html
<script src="kit/lib.js"></script>        <!-- 필수: PN.taper, PN.rng -->
<script src="kit/k-bosses3.js"></script>  <!-- PN.bossesB를 런타임에 부르지 않는다 -->
```
- `lib.js`에만 의존한다. `k-bosses2.js`의 `ctx`·도우미·조합기는 이 파일에 **복사**해 두었다(`PN.bossesC._`). 굽기 순서에서는 `k-bosses2.js` 뒤에 둔다.
- 모든 선언은 IIFE 안에 있어 다른 모듈과 최상위 이름이 겹치지 않는다. 각 호출이 자기 `<defs>`를 넣고, id는 호출마다 `kb3_<n>_` 접두사를 붙인다.

- 배치: `<g transform="translate(x - 192*k, y - 360*k) scale(k)">…</g>`는 발을 (x, y)에 둔다.

## `PN.bossesC.draw(id, opts) → string`
`<g class="kb3 kb3-{id}">`(분신이면 `kb3-clone` 클래스 추가)와 그 호출의 `<defs>`를 돌려준다. 모르는 id는 주석만 든 빈 `<g>`다.

| opt | 기본 | 뜻 |
|---|---|---|
| `phase` | `1` | 파손 층만 정한다(1 · 2 종이 균열 + 페이즈 표식 · 3 블랙 스팟 흘러내림 + 코어). 포즈와 따로다. 1~3으로 반올림·잘라 쓴다 |
| `windup` | `false` | `pose:'idle'`일 때 준비 자세 + 호박 '!' |
| `pose` | `'idle'` | `'idle'` \| `'attack'` \| `'death'`. attack은 그 무브의 공격 순간 1장('!' 없음, windup 무시) |
| `frame` | `0` | death 0~3(범위 밖은 잘라 쓴다). 3이 먹 웅덩이 |
| `move` | 페이즈별 | `'base'` \| `'p2'` \| `'p3'`. 준비·공격 포즈의 무브. 기본은 phase 1→base, 2→p2, 3→p3. **SYS-05 전에는 `move:'base'`로 굽는다**(phase 2·3 + base 조합 확인됨) |
| `enraged` | `false` | 먹 불꽃(검은 불 + 종이 심), 백열 눈, 바깥 윤곽에만 산호 펄스(먹 링 샌드위치) |
| `clone` | `false` | `'bishop'` 전용 유리 분신 미끼. 다른 id에서는 무시 |
| `detail` | `'art'` | `'game'`: 외곽 ×2.5, 내부선 ×1.8, 망점 피치 6(3px), 작은 디테일 생략(재드로잉) |
| `halo` | 장 base | 녹아웃 헤일로 색. 2장 `#ABADB4` · 3장 `#ADB4AA` · 4장 `#BBAE94` · 5장 `#ABA5AC`. `false`면 끈다 |
| `mono`, `monoColor` | `false`, ink | 단색 실루엣. `front`(‘!’, 포즈 FX)와 `under`(지면 FX)는 빠진다. 투명 틈(`cut`)은 남는다 |
| `shadow` | `true` | 발밑 그림자 |
| `hitbox` | `false` | 점선 r108 @pivot + pivot 십자 + feet 점(bossesB와 같음) |

- death는 `phase`·`windup`·`enraged`·`move`·`clone`을 무시하고 P3 파손에서 시작한다(산호·호박 없음).
- 분신(`clone:true`)은 같은 포즈 옵션을 받고 '!', 광폭, 페이즈 파손이 없다. 단색에서는 진짜와 같은 실루엣이다.
- 상태 수: 보스마다 22장(페이즈 3 × {대기, 준비, 공격} × {평상, 광폭} 18장 + 처치 4장) × `detail` art·game, 그리고 `mono`. 주교는 `clone`이 더 있다.

## 레이어 모델 (`C.parts[id](X, S)`가 돌려주는 것)
`under`(지면 FX, 단색 제외) · `back`+`fig`(몸 = raw) · `holes`(mask 투명 구멍) · `rims`(raw 알파로 마스크, 주교 분신의 납선 격자도 여기) · `over`(지워지지 않는 소품·조각) · `solid`(광폭 펄스용 채움에만 더하는 경로) · `front`('!', 포즈 FX, 단색 제외) · **`cut`**(새로 더함).
- `cut`: 좁은 투명 틈을 **그림자 쪽 먹 복제·광폭 펄스·헤일로를 모두 지난 뒤** 뚫는다. bossesB처럼 raw에만 구멍을 내면 오프셋 먹 복제(game 4,5)가 폭 4~10짜리 틈을 거의 메우기 때문이다. 원장만 쓴다: 광배 왼쪽 위 다이아몬드 링 틈(150°~300°, art r58~62 / game r55~63), p3의 +자 틈(원판 중심, 가로·세로 팔 둘), 꼬리 사이 틈, P3 광배 한 입, 처치 f0 코로나 3조각. 같은 영역은 `solid`에도 넣어 산호가 틈 안쪽에 돌지 않는다.
- `cutKeep`(새로 더함): cut 마스크에 흰색으로 다시 칠하는 모양 목록. 항목은 경로 문자열이거나 `{ d, tf, sw }`(경로, 변환, 외곽선까지 덮는 흰 획 폭)이다. 한 모양에 `<path>` 하나라 겹쳐도 감김 방향으로 지워지지 않는다. 원장 p3: 머리 `ell(208,92,28,34)`, 가면 `ell(216,94,27,31)`, 연미복 `D.TORSO` + 흰 획(art 7 / game 16), 공격 p3에서 위로 든 지휘봉(흰 획 art 12 / game 18, 화면 좌표). 그래서 +가 머리·가면·어깨 뒤로 지나간다(검수 F4).
- `cutT` · `solidT`(새로 더함): cut 경로와 solid 경로에 거는 변환. 원장은 광배·꼬리를 몸 기울기 전단(`lt`) 안에서 그리므로 cut·cutKeep(몸 쪽)·solid도 같은 `lt`로 그린다. 공격 base(+4°)·p3(−3°)에서 틈과 채움이 그려진 원판에서 어긋나지 않는다. 화면 좌표 소품에 붙는 solid는 `R.Li`로 몸 좌표로 옮겨 넣는다.
- `solid`는 하위 경로(`M …`)마다 따로 `<path>`로 그린다. 감김 방향이 반대인 다각형이 겹쳐도 서로 지우지 않는다.

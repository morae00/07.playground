# API — `k-hero.js` · `PN.heroKit` v2.0 (결(結) · 먹선 사냥꾼)

주인공 결의 SVG 문자열 생성기다. 전신 일러스트 8포즈, 64px 인게임 스프라이트(4상태 × 프레임), HUD 초상 6표정을 만든다.
기준은 바이블 §8(주인공), §6(비례), §7.3(크기·앵커), §4–5(선·음영), §3(팔레트), §12.3/12.5(아군 FX·피드백), §13.2(HUD)다.
시트는 `concept/out/hero-sheet.png`(1600×1000)이고 `hero-sheet@2x.png` 사본이 있다. 소스는 `concept/work/hero/sheet.html`(+ `sheet-a/b/c.js`)다.

**v1 → v2 호환성:** 함수 이름, 인자, 로컬 박스, pivot, 옵션은 모두 그대로다. 호출 코드는 고치지 않아도 된다. 바뀐 것은 그림과 추가 필드뿐이다(아래 §7 변경 기록 참고).

## 로드 순서
```html
<script src="kit/lib.js"></script>     <!-- 필수: PN.taper, PN.rng, PN.halftone, PN.speedLines -->
<script src="kit/k-hero.js"></script>  <!-- window.PN.heroKit -->
```
- `hero.js`, `sprites.js`, `boss.js`, `PN.defs()`에는 의존하지 않는다.
- 패턴(망점 20/40/60 · 청록 망점 · 종이 망점), 클립, 마스크, 필터(rough · glow · 외곽선 · X-ray · 잔상)는 **호출마다 고유 id**(`hk<N>_…`)로 만들어 결과 문자열 안의 `<defs>`에 넣는다.
  - 스모크 테스트(`work/hero/v2/smoke.js`): 59회 호출, id 686개, 중복 0, 끊긴 `url(#)` 참조 0.
- `k-hero.js`는 빌드 산출물이므로 직접 고치지 않는다. 원본은 `concept/work/hero/src/*.js`(각 15KB 미만)이고 `build.sh`가 이어 붙인 뒤 문법을 검사한다.
  - `00-core` 토큰·Ctx·기하·먹 스민 끝단·구슬·바늘 / `10-head` 3/4 머리·흑립·표정 / `12-headfb` 정면·후면 머리
  - `15-limb` **유기적 팔다리**(관절을 지나는 한 줄 윤곽, 테이퍼, 관절 꺾임 ≥ 15° 보정, 그림자 쪽 초승달 먹, 주름 쐐기)
  - `20-parts` 팔·다리·장화·탄띠·실패·먹침검·목도리 매듭 / `22-glove` 장갑 7종 / `25-scarf` 꼬이는 목도리 꼬리 2가닥
  - `30-side` 3/4 조립기(휜 척추, 어깨·골반 역기울기, 코트 한 벌) / `40-poses` `full()` + threeQuarter / `41-actions` throw·run / `42-actions` dash·hurt·levelup
  - `50-frontback` 정면·후면 / `60-sprite`·`61-sprite` 스프라이트 / `70-portrait` 초상 / `80-api` 배치 헬퍼
- 색은 바이블 §3 토큰을 그대로 쓴다: `ink.900 #121110`, `ink.700 #2B2926`, `paper.50 #FAF6EC`, `paper.100 #F3EEE2`, `paper.300 #D8D0C0`, `sig.ally #00A8C6 / deep #007C94 / glow #CFF6FF`.

## 1. `PN.heroKit.full(pose, opts) → string` — 전신 일러스트
- **로컬 박스 400 × 640**. **pivot = (200, 600)** = 지면 접점 중앙이다. 지면선 y = 600, 오른쪽을 본다.
- 6.5등신(흑립 포함 7), 머리 단위 79u(`FULL_BOX.headUnit`). 흑립 정수리 ≈ y 45, 턱 ≈ 168, 허리띠 ≈ 300, 옷단 ≈ 505. 턴어라운드 3면이 같은 높이선을 쓴다.
- 팔다리는 관절을 지나는 **한 줄 윤곽**이다. 팔은 어깨 1.0 → 팔꿈치 0.8 → 손목 0.55, 다리는 허벅지 1.0 → 무릎 0.8 → 발목 0.52로 좁아진다. 팔꿈치와 무릎은 완전히 펴져도 15° 이상 꺾인다(`ensureBend`). 그림자 쪽(우하) 윤곽은 +40% 굵은 붓 획을 겹친다.
- 장갑은 엄지가 분리되고 손가락 덩어리가 2~3개다. `hold`는 **정확히 3개의 바늘**을 손가락 마디 사이에 끼워 −11° / 0° / +11°로 편다.

| pose | 내용 | FX가 박스를 넘는 범위 |
|---|---|---|
| `'front'` | 정면. 대각 흑립 그림자, 코 그림자 쐐기 + 콧구멍, 한쪽 입꼬리, 뾰족한 턱. **사선 여밈**(ink.900 깃 + paper.50 동정, 깃 → 옷단), 옆트임 + 먹 안감, 겹친 자락이 긴 비대칭 옷단, 팔 6~8° 벌림. 목도리 꼬리는 시청자 오른쪽 어깨 **뒤로** 떨어져 사선으로 흐른다 | — |
| `'threeQuarter'` | **주 시점**. 가까운 손은 먹침검 손잡이, 먼 손은 바늘 3. 무게는 앞발 | — |
| `'back'` | 후면. 낮게 묶은 흑발, 등 뒤 허리의 먹침검, 탄띠 끈, 뒤트임 먹 안감. 꼬리는 목덜미에서 어깨뼈 위로 사선 낙하 | — |
| `'throw'` | 키아트 런지. **동세선 C자**(뒷발꿈치 → 척추 → 던지는 손), 상체 앞 20°, 어깨선 대 골반선 22° 역기울기, 앞 무릎이 발끝 위. 반대 손은 탄띠 끝(뒤 허리)으로 당긴다. 코트는 뒷다리 뒤로 한 벌로 날리고 끝단이 뒤집힌 곳에 먹 안감 쐐기 2개. "슉!" | 바늘 x → 514 |
| `'run'` | 앞 12°, 팔다리 교차(가까운 다리 + 먼 팔 앞). 코트 끝단이 늦게 따라오며 말린다. 속도선·먼지 | 목도리 x → 0 |
| `'dash'` | 일식 보법. 뒤쪽 절반(코트 + 뒷다리)이 **붓 한 획**(약 1.5 몸길이)으로 풀린다. 획 중심에 청록 실(먹 · 청록 · glow), 마스크로 뚫은 비백 틈 3줄, 꼬리에서 갈라지는 붓털. 앞쪽 절반(흑립·얼굴·앞다리)은 선명하다. 검은 칼집에 꽂힌 채이고 무기 호는 없다 | x −110 … 460 |
| `'hurt'` | 뒤로 젖힘. **종이 잔상**(paper.50 평면 + 먹 외곽선만, 넉백 방향 −14, −4), 코트에 먹 튐 3곳, 산호 받은 피해 숫자 `-18` | 잔상 x −14 |
| `'levelup'` | 청록 → 종이 원상(ensō) 한 획, 떠오르는 바늘 4, 종이 가루 | 원상 x 18…390 · y 132…504 |

| opts | 기본 | 의미 |
|---|---|---|
| `scaleHint` | – | 표시 배율. 망점 피치를 `max(6, 3.2 / scaleHint)`로 잡아 **1x 피치 ≥ 3px**을 지킨다 |
| `pitch` | 6 | 망점 피치 직접 지정(scaleHint보다 우선) |
| `rough` | 0.9 | 손맛 흔들림 세기. **v2부터 최대 1.0**, 고주파(0.9)라 서브픽셀 흔들림만 남는다(흑립 동심선 계단 현상 제거). 0이면 끈다 |
| `ground` | true | 발밑 그림자 타원 |

권장 표시 배율: 턴어라운드 0.76(≈ 420px), 액션 0.34(≈ 190px), 키아트 1.0 이상.
- `PN.heroKit.FULL_BOX = { w: 400, h: 640, pivot: [200, 600], groundY: 600, headUnit: 79 }`
- `PN.heroKit.POSES`: 포즈 데이터. 직접 만든 객체도 `full()`에 넘길 수 있다.
  - v1 필드: `neck`, `hip`, `head{p, rot, expr, tilt, s}`, `aN/aF[어깨, 팔꿈치, 손목]` + `hN/hF{type, rot, mirror, scale}`, `lN/lF[골반, 무릎, 발목, 발끝]`, `scarf[척추점]`, `scarfW`, `pony`, `sword{p, deg, len}`, `skirt`(= `coat`의 별칭), `front`, `under/over(c)`, `negative`(→ 기본 잔상 [−14, −4]).
  - v2 추가: `bow`(척추 휨, + = 등 볼록), `shTilt`/`hipTilt`(어깨·골반 기울기 °), `coat{pts, tone, tone40, spots, folds, hem, hemH, waist, edge, lining}`(lining = 먹 안감 쐐기), `scarf2`(짧은 꼬리 척추점, 생략 시 긴 꼬리의 1/1.6을 자동 생성), `scarfO{swing, twA, twB}`, `order`(그리는 순서), `aNw/aFw`(팔 굵기), `aNpref/aFpref/lNpref/lFpref`(관절 꺾임 방향 ±1), `aNbend/aFbend`(최소 꺾임 °), `echo[dx, dy]`(피격 잔상), `behind`(문자열 또는 함수).
  - 장갑 `type`: `fist | grip | relax | open | hold | point | sign`.

## 2. `PN.heroKit.sprite(state, frame, opts) → string` — 인게임 64px
- **로컬 박스 96 × 96(1x px)**. **pivot = (48, 60) = 판정 원 중심(골반), r = 15.** (v1과 같다)
- 흑립 정수리 ≈ y 12(pivot − 48, 외곽선 포함 − 49), **발 y 75(pivot + 15 = 판정 원 하단)**, 높이 64px. 흑립 챙 40 × 11px, 대우(모자 통)는 v1보다 25% 낮은 6.1px. 몸통 폭 23px, 뒤로 쓸린 옷자락 끝까지 35px(바이블 30~34보다 1px 넓다. 실루엣 2요소를 위해 옷자락만 넘긴다).
- 얼굴: 챙 아래 13 × 8px가 보인다. 대각 그림자 속 가까운 눈에 **paper.50 2 × 2px 눈빛**(`SPRITE.eye` = pivot 기준 (1, −31), 사방 1px 이상 먹 여백이 있어 1x 최근접 확대에서도 살아남는다), 가까운 뺨에 **1px 먹 흉터**, 뒷머리 덩어리는 v1보다 40% 줄였다.
- 발밑 그림자는 pivot + 8.25 중심 **30 × 13** 타원(ink α0.3). **청록 4분할 링**(`ring: true`)은 rx 24 / ry 10.3, 호 4개 각 0.7rad, `aim`으로 회전. 샌드위치는 먹 5.2(α0.8) → deep 4.2 → ally 2.6 → glow 0.7이다.
- 외곽선은 feMorphology로 굽는다(빛 쪽 1.1, 그림자 쪽 1.5 + (0.75, 0.75)). 바깥에 **paper.50 白邊 1.5px**. 망점은 쓰지 않는다. 코트 음영은 `paper.300` 평면이다.
- 목도리 꼬리는 **한 가닥**이다. 매듭 쪽 4.8px → 끝 2px, 제비꼬리, deep 밑면 띠, glow 심, 종이 땀 한 점. 프레임마다 S파가 다르다(±2px).
- 모든 프레임은 오른쪽을 본다. `flip`으로 반전하고, 자전은 없다.

| state | 프레임 | 권장 fps | 연출 |
|---|---|---|---|
| `idle` | 6 | 8 | 호흡 bob 0~1px, 목도리 S파(프레임마다 다름), 옷자락이 **뒤로 쓸린 삼각형**(주름선 2줄) |
| `run` | 8 | 14 | 상체 전체 **12° 앞 기울임**(transform). 접지·통과 프레임에 행전 흰 띠 3줄이 달린 장화가 옷단 앞/뒤로 4~6px 나온다. 옷단은 다리보다 한 프레임 늦게 ±3px 흔들린다. 통과 프레임에 1.5px 올라가고(bob), 접지 프레임 scale 1.03 / 0.94, 통과 0.98 / 1.04(발 기준). 뒤 자락이 들리면 먹 안감 쐐기가 보인다 |
| `throw` | 4 | 16 | 팔 오버레이 `draw` → `wind` → `snap`(바늘 + 청록 실 꼬리) → `follow`(먹선 잔획) |
| `hurt` | 3 | 12 | f0·f1 **네거티브 플래시**(먹↔종이, 청록 유지) + 흑립 −14/−10° 기울임, f2 원색 + 코트 먹 튐 |

| opts | 기본 | 의미 |
|---|---|---|
| `ring` | true | 청록 4분할 발밑 링 |
| `aim` | 0 | 조준각(rad, 월드 기준, 0 = 오른쪽). 링과 **투척 팔 + 바늘 오버레이**를 어깨(pivot + (−2.6, −21)) 기준으로 회전한다. throw에서는 팔이 aim × 0.35만큼 기운다 |
| `flip` | false | 좌향. pivot x축으로 반전하고, `aim`은 월드각 그대로 넘긴다(내부에서 π − aim으로 바꾼다) |
| `mode` | `'ready'` | idle/run 팔 포즈: `ready`, `draw`, `wind`, `snap`, `follow` |
| `shadow` / `halo` | true | 판정 그림자 타원 / paper.50 白邊 |
| `xray` / `xrayOnly` | false | 보스·warden에 가렸을 때 청록 X-ray 외곽 2px를 최상위에 추가 / 외곽만 그림 |
| `noOutline` | false | 외곽선 필터 없이 그린다(면적 측정용) |

- `PN.heroKit.SPRITE` = `{w: 96, h: 96, pivot: [48, 60], r: 15, height: 64, top: −49, feet: 15, shadow{…}, ring{…}, frames{…}, fps{…}, eye: [1, −31]}`
- 프레임은 `animationFrameAt(elapsed, fps, count)`로 고른다(바이블 §8.6). 아틀라스는 현재 줌으로 1회 리샘플한다(§7.2).
- **면적 실측**(`work/hero/v2/meas.py`, idle f0, `noOutline` 채움, **흑립 챙 포함**): **종이 50.3 · 먹 39.2 · 청록 6.2** · 중간톤(안티에일리어싱·챙 동심선) 4.4. 외곽선까지 포함하면 37 · 55 · 5다.
  - 바이블 §3.5/§8.3 목표(종이 55~60 / 먹 30~35)와의 차이는 **바이블 개정 제안**으로 올린다. 챙 40 × 11px 하나가 채움 면적의 약 27%라서, 챙을 포함하면 55 · 35를 동시에 맞출 수 없다. 제안: 64px 스프라이트는 "챙 포함 종이 ≥ 50 · 먹 ≤ 40", 키아트는 현행 유지.

## 3. `PN.heroKit.portrait(expr, opts) → string` — HUD 초상
- **로컬 박스 160 × 160.** **pivot = (80, 80) = 원 중심**. 클립 원 r 74, 먹 테 6px, 바깥 종이 링 r 78.5 (v1과 같다).
- v2 구도: 머리 배율 1.72(`PORTRAIT.headScale`, v1 1.34)로 얼굴 쪽에 다가가 흑립 윗부분을 잘랐다. **얼굴이 원 면적의 42%**(v1 약 30%). 목 음영은 망점 20%로 가볍게 했고, 목도리 매듭이 원 아래에 보인다.
- 표정은 **모양으로 구분한다**(배경은 보조). 84px 원·배경 없음·최근접 확대에서 6개 모두 구분됨을 확인했다(`work/hero/v2/t-port84-nn.png`).

| expr | 모양 | 배경·테 |
|---|---|---|
| `calm` | 정면 각도, 둥근 눈빛 한 점, 무표정 | 종이 + 담묵 망점 비네트 |
| `focus` | 머리 +7° 숙임, **흑립·그림자 3.4u(≈ 6px) 내림**, 가까운 눈 = 가로 틈 눈빛, 먼 눈 = 눌린 윗꺼풀 + 코 쪽으로 꺾인 굵은 눈썹, **입 일자** | 먹 집중선 |
| `hurt` | 머리 −10° 젖힘, 흑립 −10°, 먼 눈 **V자로 질끈**, 벌린 입, 뺨 먹 튐 | 먹 반전 배경 + 종이 튐·균열 |
| `lowhp` | 머리 +8° 떨굼, 처진 눈꺼풀, 땀 2방울, 끝단 먹 번짐 증가 | 망점 20% + `sig.hostile.deep` 점선 테 |
| `awakened` | 가까운 눈빛이 청록 실빛으로 번짐, 먼 눈 청록 홍채 | 청록 실 호 3줄 + 청록 점선 테 |
| `victory` | **흑립 −8° 들림 + 그림자 위로 → 두 눈이 다 보임**, 한쪽 입꼬리 웃음, 흑립 챙 아래를 올리는 **검은 장갑 검지**(point) | 종이 반짝이 별 |

| opts | 기본 | 의미 |
|---|---|---|
| `frame` | true | 원형 먹 테 + 종이 링 |
| `bg` | true | 표정별 배경. false면 투명 원(흉상만) |

- `PN.heroKit.PORTRAIT = {w: 160, h: 160, pivot: [80, 80], r: 74, exprs: […], headScale: 1.72}`

## 4. 배치 헬퍼 (pivot 기준, v1과 같음)
```js
PN.heroKit.placeSprite('run', f, x, y, 1, {aim});     // (x, y) = 판정 원 중심
PN.heroKit.placeFull('throw', x, y, 0.34);            // (x, y) = 지면 접점, scaleHint 자동
PN.heroKit.placePortrait('lowhp', cx, cy, 84);        // 지름 84px 원
```
`PN.heroKit.version = '2.0'`.

## 5. 신호색 사용 (소속 검수)
- **청록(sig.ally)**: 목도리(몸의 유일한 청록 면), 바늘귀, 바늘 실 꼬리, 발밑 링, 원상, 대시의 실 심, 각성 눈빛, X-ray 외곽. 모두 먹테 + 청록 + 종이/glow 심 샌드위치다. **시트 주석 글자에는 청록을 쓰지 않는다**(범례 칩만 허용).
- **산호(sig.hostile)**: `full('hurt')`의 받은 피해 숫자 하나뿐이다. `sig.hostile.deep`: `portrait('lowhp')` 저체력 테.
- 호박·연두·자수정 사용 0. 해칭 0(망점·바느질 점선만).
- 먹 흐름: 주인공은 소매·옷단·어깨 덮개 끝이 **위로 스민다**(`inkHem` / `hemLine`).

## 6. 알려진 한계
- 스프라이트는 측면(3/4) 1방향 + 반전만 있다. 바이블 §8.5의 하 / 상 방향 프레임은 아직 없다.
- 64px 면적 계약은 위 §2의 개정 제안이 받아들여져야 "충족"이다(현행 55 · 35 대비 종이 −5, 먹 +4).
- death / victory(전신 애니) / rooted / silenced 상태와 거울 분신은 미구현이다.
- 전신 포즈는 절차형 리그라서 옷주름과 손가락 수는 사람 원화보다 단순하다. 최종 원화 발주 때 포즈·실루엣·먹 배치 가이드로 쓰라.

## 7. 변경 기록 v1 → v2 (아트 디렉터 리뷰 반영)
- 팔다리를 캡슐 + 팔꿈치 원에서 **관절을 지나는 한 줄 테이퍼 윤곽**으로 바꿨다. 관절 꺾임 ≥ 15°, 그림자 쪽 굵은 붓 획, 초승달 먹, 주름 쐐기를 넣었다.
- 장갑을 벙어리장갑에서 **엄지 + 손가락 덩어리 2~3개**로 바꿨다. 3/4의 바늘은 정확히 3개이고 10~12°로 편다.
- 몸통: 휜 척추(`bow`)와 어깨·골반 역기울기(`shTilt/hipTilt`)를 넣고 가슴 볼륨과 지그재그 먹 그림자를 더했다. 코트는 한 벌로 뒤로 날리고, 먹 안감은 대칭 자락이 아니라 디자인한 쐐기 2~3개로 그린다.
- throw는 C자 동세, 넓은 보폭, 앞 무릎이 발끝 위, 반대 손은 탄띠 쪽으로 당긴다. run은 팔다리가 교차한다.
- 목도리 꼬리: 길이 1 : 1.6인 2가닥, 폭 100% → 35%, 가닥마다 꼬임(밑면 deep), 제비꼬리, paper.50 땀 점선. 정면·후면에서는 어깨 뒤로 사선으로 떨어진다.
- dash: 앞쪽 청록 초승달(무기 호)을 없앴다. 붓 한 획 + 청록 실 심 + 비백 틈으로 바꿨다. hurt: 반전 잔상(−34px)을 종이 평면 잔상(14px)으로 바꾸고 코트에 먹 튐을 넣었다.
- 정면: 코 쐐기, 뾰족한 턱, 한쪽 입꼬리, 사선 여밈, 옆트임, 비대칭 옷단, 팔 벌림을 넣었다.
- rough 필터는 scale ≤ 1, 주파수 0.9로 바꿨다(흑립 동심선 계단 현상 제거).
- 스프라이트: 대우 25% 낮춤, 얼굴 확대, 2 × 2 눈빛, 1px 흉터, 뒷머리 −40%, 벨트·조끼·탄띠 −30%, 코트 확대, run 12° 기울임·다리 교차·bob·squash, idle 삼각 옷단, 꼬리 한 가닥.
- 초상: 1.15배 이상 확대(얼굴 42%), 표정별 머리 각도·흑립 높이·눈·입·손을 따로 설계했다.

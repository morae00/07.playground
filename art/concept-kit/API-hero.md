# API — `k-hero.js` · `PN.heroKit` v2.1 (결(結) · 먹선 사냥꾼)

주인공 결의 SVG 문자열 생성기다. 전신 일러스트 8포즈, 64px 인게임 스프라이트(4상태 × 프레임), HUD 초상 6표정을 만든다.
기준은 바이블 §8(주인공), §6(비례), §7.3(크기·앵커), §4–5(선·음영), §3(팔레트), §12.3/12.5(아군 FX·피드백), §13.2(HUD)다.
시트는 `concept/out/hero-sheet.png`(1600×1000)이고 `hero-sheet@2x.png` 사본이 있다. 소스는 `concept/work/hero/sheet.html`(+ `sheet-a/b/c.js`)다.

**v1 → v2 호환성:** 함수 이름, 인자, 로컬 박스, pivot, 옵션은 모두 그대로다. 호출 코드는 고치지 않아도 된다. 바뀐 것은 그림과 추가 필드뿐이다(아래 §7 변경 기록 참고).

**v2 → v2.1 호환성(R4 얼굴 리뷰 `docs/art/reviews/R4-faces.md` H1~H7):** 함수 이름, 인자, 로컬 박스, pivot, 판정, 기존 옵션은 그대로다. 추가된 것은 `full()`의 `fine`·`lettering` 옵션뿐이다. **기본 출력은 바뀐다**: 3/4 머리·정면 머리·초상·스프라이트 머리를 다시 그렸고, `full('throw')`·`full('hurt')`의 글자는 기본으로 빠지며, `SPRITE.eye` 값이 [1, −31]에서 [5, −31]로 바뀌었다(§7.1). 굽기 결과(아틀라스 `common-0`, 초상·키아트 시트, 이야기 패널)와 화면 검사가 달라진다.

## 1. `PN.heroKit.full(pose, opts) → string` — 전신 일러스트
- **로컬 박스 400 × 640**. **pivot = (200, 600)** = 지면 접점 중앙이다. 지면선 y = 600, 오른쪽을 본다.
- 6.5등신(흑립 포함 7), 머리 단위 79u(`FULL_BOX.headUnit`). 흑립 정수리 ≈ y 45, 턱 ≈ 168, 허리띠 ≈ 300, 옷단 ≈ 505. 턴어라운드 3면이 같은 높이선을 쓴다.
- 팔다리는 관절을 지나는 **한 줄 윤곽**이다. 팔은 어깨 1.0 → 팔꿈치 0.8 → 손목 0.55, 다리는 허벅지 1.0 → 무릎 0.8 → 발목 0.52로 좁아진다. 팔꿈치와 무릎은 완전히 펴져도 15° 이상 꺾인다(`ensureBend`). 그림자 쪽(우하) 윤곽은 +40% 굵은 붓 획을 겹친다.
- 장갑은 엄지가 분리되고 손가락 덩어리가 2~3개다. `hold`는 **정확히 3개의 바늘**을 손가락 마디 사이에 끼워 −11° / 0° / +11°로 편다.

| pose | 내용 | FX가 박스를 넘는 범위 |
|---|---|---|
| `'front'` | 정면. 형태를 감는 흑립 그림자(v2.1: 보는 사람 오른쪽 눈썹 위 → 콧등 뿌리의 빛 홈 → 왼쪽 눈 아래 → 광대 → 옆면), 코는 아래 60%만 그림자 쐐기 + 코끝 아래 악센트 하나 + 콧구멍, 턱 옆면·턱 밑·목은 종이 그늘 평면(얼굴·목 안 망점 없음), 그림자 속 눈빛은 3/4 머리와 같은 타원(rx 1.2 · ry 1.5, −20°)이 아래 눈꺼풀에 붙는다, 한쪽 입꼬리, 뾰족한 턱. **사선 여밈**(ink.900 깃 + paper.50 동정, 깃 → 옷단), 옆트임 + 먹 안감, 겹친 자락이 긴 비대칭 옷단, 팔 6~8° 벌림. 목도리 꼬리는 시청자 오른쪽 어깨 **뒤로** 떨어져 사선으로 흐른다 | — |
| `'threeQuarter'` | **주 시점**. 가까운 손은 먹침검 손잡이, 먼 손은 바늘 3. 무게는 앞발 | — |
| `'back'` | 후면. 낮게 묶은 흑발, 등 뒤 허리의 먹침검, 탄띠 끈, 뒤트임 먹 안감. 꼬리는 목덜미에서 어깨뼈 위로 사선 낙하 | — |
| `'throw'` | 키아트 런지. **동세선 C자**(뒷발꿈치 → 척추 → 던지는 손), 상체 앞 20°, 어깨선 대 골반선 22° 역기울기, 앞 무릎이 발끝 위. 반대 손은 탄띠 끝(뒤 허리)으로 당긴다. 코트는 뒷다리 뒤로 한 벌로 날리고 끝단이 뒤집힌 곳에 먹 안감 쐐기 2개. 효과음 글자 "슉!"은 `lettering: true`일 때만 | 바늘 x → 514 |
| `'run'` | 앞 12°, 팔다리 교차(가까운 다리 + 먼 팔 앞). 코트 끝단이 늦게 따라오며 말린다. 속도선·먼지 | 목도리 x → 0 |
| `'dash'` | 일식 보법. 뒤쪽 절반(코트 + 뒷다리)이 **붓 한 획**(약 1.5 몸길이)으로 풀린다. 획 중심에 청록 실(먹 · 청록 · glow), 마스크로 뚫은 비백 틈 3줄, 꼬리에서 갈라지는 붓털. 앞쪽 절반(흑립·얼굴·앞다리)은 선명하다. 검은 칼집에 꽂힌 채이고 무기 호는 없다 | x −110 … 460 |

권장 표시 배율: 턴어라운드 0.76(≈ 420px), 액션 0.34(≈ 190px), 키아트 1.0 이상.
- `PN.heroKit.FULL_BOX = { w: 400, h: 640, pivot: [200, 600], groundY: 600, headUnit: 79 }`
- `PN.heroKit.POSES`: 포즈 데이터. 직접 만든 객체도 `full()`에 넘길 수 있다.
  - v1 필드: `neck`, `hip`, `head{p, rot, expr, tilt, s}`, `aN/aF[어깨, 팔꿈치, 손목]` + `hN/hF{type, rot, mirror, scale}`, `lN/lF[골반, 무릎, 발목, 발끝]`, `scarf[척추점]`, `scarfW`, `pony`, `sword{p, deg, len}`, `skirt`(= `coat`의 별칭), `front`, `under/over(c)`, `negative`(→ 기본 잔상 [−14, −4]). v2.1: `over`는 두 번째 인자로 `full()`의 opts를 받는다(`over(c, opts)`, `lettering` 판단용).
  - v2 추가: `bow`(척추 휨, + = 등 볼록), `shTilt`/`hipTilt`(어깨·골반 기울기 °), `coat{pts, tone, tone40, spots, folds, hem, hemH, waist, edge, lining}`(lining = 먹 안감 쐐기), `scarf2`(짧은 꼬리 척추점, 생략 시 긴 꼬리의 1/1.6을 자동 생성), `scarfO{swing, twA, twB}`, `order`(그리는 순서), `aNw/aFw`(팔 굵기), `aNpref/aFpref/lNpref/lFpref`(관절 꺾임 방향 ±1), `aNbend/aFbend`(최소 꺾임 °), `echo[dx, dy]`(피격 잔상), `behind`(문자열 또는 함수).
  - 장갑 `type`: `fist | grip | relax | open | hold | point | sign`.

### 1.1 3/4 머리 구조 (v2.1, `head34` — threeQuarter·throw·run·dash·hurt·levelup, 초상 6표정이 함께 쓴다)
머리 좌표계: 원점 = 두개골 중심, 챙 중심 (0, −34), 턱 끝 y ≈ +32.5, 오른쪽을 본다. 전신은 `POSES[*].head{p, rot, s}`로, 초상은 `PORTRAIT.headScale`로 놓는다(둘 다 v2와 같다).
- **한 시점(약 45°)에 모든 이목구비를 맞춘다.** 두개골 원 + 얼굴 정중선 + 가로선(눈썹 −8, 눈 −3.5, 코밑 10, 입 17.5, 턱 32.5)으로 짰다. 정중선은 눈 높이에서 x ≈ 20, 코끝은 그보다 앞(x ≈ 34)으로 나온다.
- **먼 윤곽**은 관자 (31, −20) → 먼 눈썹뼈 (31.4, −12.5 … 31.6, −8.6) → 먼 눈확 오목 (29.8, −3.6) → 먼 광대 (32.2, 3.2)이고, **코끝 (34, 6.4)~(34.4, 7.8)만** 광대선 밖으로 2u 나온다. 그 아래로 콧방울-뺨 (29.6, 11.2), 윗입술 (30.6, 13.8), 먼 입꼬리 (29.2, 16.8), 아랫입술 (29.8, 19), 턱 홈 (27.6, 23.6), 턱 앞 (27.2, 29)~(25.4, 30.8), 턱 밑 (17.6, 32.4). 이마-콧등-입술이 한 줄인 옆얼굴 구간은 없다.
- **눈**: 가까운 눈(폭 약 10.4, x 2.8~13.2)은 챙 그림자 속에서 **아래 눈꺼풀 종이 획 + 눈빛 한 점**(타원 (9.4, −3) rx 1.1 ry 1.4, −20°)만 보인다. 먼 눈(폭 6 = 가까운 눈의 0.57)은 빛 속 아몬드이고 콧등 너머·먼 윤곽 안에 있다. 홍채는 아몬드로 잘라 윗꺼풀이 위를 덮는다. 먼 눈은 지시 좌표보다 0.8u 콧등 쪽(x 21.8~27.8)에 그려 바깥 끝과 윤곽 획 사이에 약 1u를 남긴다.
- **코**: 콧등은 두 눈 안쪽 끝 사이(그림자 경계가 콧등 뿌리 x ≈ 20을 타고 내려옴)에서 시작한다. 아래쪽 콧등 선 (25.4, 1.2) → (32.4, 6.4), 가까운 콧방울, 콧구멍, 코 옆면 종이 그늘 평면, 코끝 아래 먹 쐐기 악센트 하나.
- **그림자**: 덩어리 하나. 아래 경계가 먼 눈썹 모양(이 경계가 곧 먼 눈썹) → 콧등 뿌리에서 꺾여 내려옴 → 가까운 눈 아래 → 가까운 광대 (−1.4, 6.6)에서 꺾임 → 옆면을 타고 턱각으로. 경계는 날카롭고 직선 구간은 8u 이하다. victory는 `shadowDy`를 주지 않으면 −11, `shadowRot` −5를 써서 두 눈이 모두 빛 속에 든다(전신 levelup).
- **명도 3단**: 종이 / 종이 그늘(paper.300 평면: 옆면 띠, 먼 뺨 띠, 코 옆면, lowhp·hurt의 눈 밑 평면) / 먹. 얼굴 안 망점은 없다.
- **흉터**: 가까운(오른) 뺨 앞쪽 빛 속, (1.5, 13.8) → (11, 10.2) 1.1u + 바늘땀 2개.
- **입**: 가까운 입꼬리 (17.4, 18) → 정중선 (24.6, 18) → 먼 입꼬리 (29.2, 16.8, 먼 윤곽 위). focus는 꼬리 없는 일자, victory는 가까운 입꼬리만 올린다.
- **윤곽**: FACE는 채움만 하고 윤곽은 FACE 점열을 그대로 따르는 붓 획 3개로 긋는다. 이마~먼 광대~코끝 3.0u(먼 눈확에서 0.7배로 가늘어짐), 코밑~턱 앞 2.2 → 4.2u(아래로 갈수록 눌림), 턱 끝 5.2u에서 턱밑을 따라 사라짐. **턱밑에서 목까지는 획이 없다**: 목 그림자 띠(`neck34`)가 턱선 바로 아래에서 시작해 경계가 된다.
- **챙**: `hat34` 기본 기울기 −3°(v2: +5°). 머리 기준으로 가까운 쪽이 같거나 낮아 그림자 경계와 같은 쪽으로 기운다.
- **bold**(초상 1.25)는 이목구비 선 굵기 배수일 뿐이다. 위치·크기는 키우지 않는다.

## 2. `PN.heroKit.sprite(state, frame, opts) → string` — 인게임 64px
- **로컬 박스 96 × 96(1x px)**. **pivot = (48, 60) = 판정 원 중심(골반), r = 15.** (v1과 같다)
- 흑립 정수리 ≈ y 12(pivot − 48, 외곽선 포함 − 49), **발 y 75(pivot + 15 = 판정 원 하단)**, 높이 64px. 흑립 챙 40 × 11px, 대우(모자 통)는 v1보다 25% 낮은 6.1px. 몸통 폭 23px, 뒤로 쓸린 옷자락 끝까지 35px(바이블 30~34보다 1px 넓다. 실루엣 2요소를 위해 옷자락만 넘긴다).

## 5. 신호색 사용 (소속 검수)
- **청록(sig.ally)**: 목도리(몸의 유일한 청록 면), 바늘귀, 바늘 실 꼬리, 발밑 링, 원상, 대시의 실 심, 각성 눈빛, X-ray 외곽. 모두 먹테 + 청록 + 종이/glow 심 샌드위치다. **시트 주석 글자에는 청록을 쓰지 않는다**(범례 칩만 허용).
- **산호(sig.hostile)**: `full('hurt', { lettering: true })`의 받은 피해 숫자 하나뿐이다. v2.1 기본 출력에는 산호가 없다. `sig.hostile.deep`: `portrait('lowhp')` 저체력 테.
- **그림 속 글자**: 기본 0(v2.1). throw "슉!"·hurt "-18"은 `lettering: true`일 때만 그린다.
- 호박·연두·자수정 사용 0. 해칭 0(망점·바느질 점선만).
- 먹 흐름: 주인공은 소매·옷단·어깨 덮개 끝이 **위로 스민다**(`inkHem` / `hemLine`).

## 6. 알려진 한계
- 스프라이트는 측면(3/4) 1방향 + 반전만 있다. 바이블 §8.5의 하 / 상 방향 프레임은 아직 없다.
- 64px 면적 계약은 위 §2의 개정 제안이 받아들여져야 "충족"이다(현행 55 · 35 대비 종이 −5, 먹 +4).
- death / victory(전신 애니) / rooted / silenced 상태와 거울 분신은 미구현이다.
- 전신 포즈는 절차형 리그라서 옷주름과 손가락 수는 사람 원화보다 단순하다. 최종 원화 발주 때 포즈·실루엣·먹 배치 가이드로 쓰라.
- 얼굴(v2.1)은 한 시점 구조와 명도 설계까지만 킷이 맡는다. 눈꺼풀 두께 변화, 입술 볼륨, 광대 아래 면의 미세한 꺾임, 머리카락 결, 실제 붓 비백은 절차형 테이퍼로 낼 수 없다. 사람이 그린 머리 모델 시트(정면·3/4·옆·뒤 턴어라운드 + 6표정)가 먼저 있어야 한다(R4 리뷰 §5).
- 64px 스프라이트 얼굴은 줌 리샘플(0.8×·1.0×·1.2×)마다 눈빛·흉터·입 3표식의 픽셀이 달라진다. 배율별 사람 픽셀 클린업이 필요하다.
- 3/4 머리의 "빛 쪽 이마 틈"(바이블 §3 허용 조항)은 넣지 않았다. 이 설계에서 이마는 챙과 그림자 속이라 틈이 보이지 않는다.
- 전신 throw·run·dash는 머리 자체가 숙여져(rot 10·8·24) 화면 기준으로는 챙이 앞쪽으로 기운다. 머리 기준 챙(−3°)과 그림자 방향은 threeQuarter와 같다.

## 7. 변경 기록 v1 → v2 (아트 디렉터 리뷰 반영)
- 팔다리를 캡슐 + 팔꿈치 원에서 **관절을 지나는 한 줄 테이퍼 윤곽**으로 바꿨다. 관절 꺾임 ≥ 15°, 그림자 쪽 굵은 붓 획, 초승달 먹, 주름 쐐기를 넣었다.
- 장갑을 벙어리장갑에서 **엄지 + 손가락 덩어리 2~3개**로 바꿨다. 3/4의 바늘은 정확히 3개이고 10~12°로 편다.
- 몸통: 휜 척추(`bow`)와 어깨·골반 역기울기(`shTilt/hipTilt`)를 넣고 가슴 볼륨과 지그재그 먹 그림자를 더했다. 코트는 한 벌로 뒤로 날리고, 먹 안감은 대칭 자락이 아니라 디자인한 쐐기 2~3개로 그린다.
- throw는 C자 동세, 넓은 보폭, 앞 무릎이 발끝 위, 반대 손은 탄띠 쪽으로 당긴다. run은 팔다리가 교차한다.
- 목도리 꼬리: 길이 1 : 1.6인 2가닥, 폭 100% → 35%, 가닥마다 꼬임(밑면 deep), 제비꼬리, paper.50 땀 점선. 정면·후면에서는 어깨 뒤로 사선으로 떨어진다.
- dash: 앞쪽 청록 초승달(무기 호)을 없앴다. 붓 한 획 + 청록 실 심 + 비백 틈으로 바꿨다. hurt: 반전 잔상(−34px)을 종이 평면 잔상(14px)으로 바꾸고 코트에 먹 튐을 넣었다.
- 정면: 코 쐐기, 뾰족한 턱, 한쪽 입꼬리, 사선 여밈, 옆트임, 비대칭 옷단, 팔 벌림을 넣었다.
- rough 필터는 scale ≤ 1, 주파수 0.9로 바꿨다(흑립 동심선 계단 현상 제거).
- 스프라이트: 대우 25% 낮춤, 얼굴 확대, 2 × 2 눈빛, 1px 흉터, 뒷머리 −40%, 벨트·조끼·탄띠 −30%, 코트 확대, run 12° 기울임·다리 교차·bob·squash, idle 삼각 옷단, 꼬리 한 가닥.
- 초상: 1.15배 이상 확대(얼굴 42%), 표정별 머리 각도·흑립 높이·눈·입·손을 따로 설계했다.
